### LEVEL 1 · 녹스 다섯 창 검사를 준비한 기록


7차의 공개 본문 자료는 **녹스 _5개 _설치 전 진단.json과 녹스 _5개 _진행 상태.txt 두 파일**이며 README가 안내합니다.

녹스는 컴퓨터에서 Android 환경을 실행하는 에뮬레이터이고 인스턴스는 각각 따로 켜는 Android 창입니다.

이 자료는 앱 소스 차수가 아닙니다.

기록 당시 녹스가 발견되지 않았고 저장 공간 조건 때문에 설치와 5개 동 시 실행 검사를 시작하지 않았습니다.

실제 기록의 미실행 상태를 그대로 읽어야합니다.

### LEVEL 1 · 제안 설정과 적용 결과를 구분하기


Android12 64비트, 창마다 CPU2개와 메모리 2048MB, 화면 720×1520, DPI280, 20FPS는 **적용하지 않은 제안값**입니다.

CPU는 계산 자원, 메모리는 실행 중 사용할 공간, 화면 크기는 가로·세로 픽셀 수, DPI는 화면 밀도, FPS는 초당 화면 갱신 횟수입니다.

예를 들어 20FPS라는 계획 값이 있어도 실제 20FPS로 동작했다고 말할 수 없습니다.

입력은 두 보존 파일이며 처리와 출력은 설치 전 조건·계획·미검증 범위를 읽어 설명하는 것입니다.

### LEVEL 1 · 읽기와 확인 순서


JSON과 텍스트 편집기로 진단 파일과 진행 상태 파일을 순서대로 여십시오.

설치 발견 여부와 저장 공간 조건을 먼저 확인하고 설정 제안과 적용 여부를 나눠 읽습니다.

다섯 창의 독립 실행, 창마다 완료 수가 따로 보이는지, 한 창을 멈춰도 다른 창이 계속 하는지는 확인할 계획입니다. fiveInstanceExecutionVerified =false는 **다섯 창 동시 실행을 검증하지 않았음**을 나타냅니다.

Java·Gradle 전체 소스나 APK가 있는 자료가 아니므로 여기서 앱을 재빌드하지 않습니다.

### LEVEL 1 · 기존 공통 안내와 파일 비교 읽기


원문에는 예제 schema·type·text·source·failure를 읽고 사용법과 검사 장치 범위를 대조하는 공통 안내도 남아 있습니다.

이를 이 두 진단 파일에 매크로 동작 필드나 실제 사용법/기기 성공이 있다는 뜻으로 읽지 않습니다.

현재 화면과 예제의 문구·영역·인식 방식이 다를 수 있다는 제약 역시 보존하며 가상 기기와 실물 기기의 검증은 구별합니다.

아래 비교는 두 파일의 추가·바이트·행 수와 전체 해시를 보여 줍니다.

설치 성공 수나 실행 성능이 아닙니다.

### LEVEL 2 · 설치 진단에서 실행 계획까지


7차는 녹스의 5개 인스턴스 검증을 준비하는 설치 전 기록입니다.

공개 내용 두 파일과 README 안내가 있으며 앱 구현 소스는 아닙니다.

녹스 미 발견과 저장 공간 조건이 설치/동시 실행 검사 시작을 막았습니다.

따라서 **환경 진단→설정 제안→실행 검사 계획**은 연결되지만 실제 설치·실행 결과까지 이어지지 않았습니다.

진단 JSON과 진행 상태 텍스트를 입력으로 당시 조건과 미검증 범위를 설명하는 자료입니다.

### LEVEL 2 · 제안값과 검증 항목의 관계


Android12 64비트·인스턴스당 CPU2개/메모리 2048MB·720×1520·DPI280·20FPS는 미적용 설정 제안입니다.

자원/화면 제안과 독립 실행 검증은 다른 단계입니다.

독립 실행, 창별 완료 수, 한 창 정지 후 다른 창 계속 실행을 확인할 계획이며 fiveInstanceExecutionVerified =false가 현재 증거 상태를 고정합니다.

제안 자원 합계나 창 수에서 실제 처리량을 만들어 내지 않습니다.

### LEVEL 2 · 보존 파일을 읽는 준비와 순서


텍스트/JSON 편집기로 설치 전 진단과 진행 상태를 읽고 설치 발견·공간 조건, 제안 값, 실행 여부를 연결하십시오.

원문 공통 안내의 schema/type/text/source/failure와 사용법 대조 절차는 부분 자료를 읽는 틀이며 실제 파일의 키와 종류를 우선 합니다.

예제와 현재 화면의 문구/영역/방식은 별도 정합 조건이고 가상/실물 기기 구분도 유지합니다.

전체 Java·Gradle/APK가 없으므로 일반 앱 재빌드/설치 과정으로 확장하지 않습니다.

### LEVEL 2 · 결과와 차이의 해석


산출물은 당시 설치 준비와 미검증 상태의 기록이지 새 환경 재현 결과가 아닙니다.

두 파일의 추가는 1034바이트/+36 행과 1842바이트/+27 행으로 아래 표에 보존합니다.

패치와 파일별 SHA-256은 공백·주석·개 행을 포함한 자료 변화와 동일성 확인용입니다.

계획만 존재하는 상태를 성공으로 바꾸거나 다른 차수 앱의 기능을 7차에 옮겨 설명하지 않습니다.

### LEVEL 3 · 열람 준비와 입력 자료


JSON·텍스트 편집기를 준비하고 README, 녹스 _5개 _설치 전 진단.json, 녹스 _5개 _진행 상태.txt를 읽으십시오.

실제 공개 내용 두 파일은 설치 전 진단/진행 기록이며 앱 소스나 APK가 아닙니다.

출력은 준비 상태·제안·미검증 범위의 대조이며 실제 설치를 이 문서 작업에서 수행하지 않습니다.

### LEVEL 3 · 설정과 실행 여부 대조


제안 값 Android12 64비트, 인스턴스당 CPU2개, 메모리 2048MB, 720×1520, DPI280, 20FPS를 원문과 대조하고 **모두 미적용 제안**으로 기록하십시오.

독립 실행/창별 완료 수/한 창 정지 시 타 창 계속 실행은 예정 검사이며 fiveInstanceExecutionVerified =false입니다.
