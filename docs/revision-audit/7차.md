<a name="-핵심-기능과-보존-범위"></a>
## 핵심 기능과 보존 범위

| 항목 | 이 차수에서 확인할 내용 |
|---|---|
| 1 | 공개 자료는 녹스_5개_설치전진단.json과 녹스_5개_진행상태.txt 두 파일입니다. 앱 소스 차수가 아닙니다. |
| 2 | 기록 당시 녹스가 발견되지 않았고 저장 공간 조건 때문에 설치와 5개 동시 실행 검사를 시작하지 않았습니다. |
| 3 | Android 12 64비트·인스턴스당 CPU 2개·메모리 2048MB·720×1520·DPI 280·20FPS는 미적용 제안값입니다. |
| 4 | 독립 실행·창별 완료 수·한 창 정지 시 다른 창 계속 실행 등을 확인할 계획이며 fiveInstanceExecutionVerified=false입니다. |

<a name="-처리-결과와-출력-읽기"></a>
## 처리 결과와 출력 읽기

사용법에 기록된 제품 동작과 실제 보존 예제를 대조할 수 있습니다. 과거 검증 기록을 새 장치에서 재현한 결과로 읽지 않습니다.

<a name="️-제약과-문제-해결"></a>
## 제약과 문제 해결

| 상황 | 확인할 내용 |
|---|---|
| 제품 소스 또는 APK가 없음 | 공개 부분본에서 제공하는 예제·기록 범위를 사용합니다. |
| 예제와 실제 화면이 다름 | 대상 문구·검색 영역·인식 방식은 실제 화면과 별도로 대조해야 합니다. |
