# 21차 전체 비교

21차의 제품 기능 기준은 19차입니다. 직전 차수 20차는 장시간 시험 도구이므로 제품 소스 비교와 보관 폴더 비교를 따로 제공합니다. 각 차수를 보존했으며 이전 폴더에만 있는 파일을 제품 기능 삭제로 해석하지 않습니다.
