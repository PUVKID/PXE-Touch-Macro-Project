# 27차 변경 기록 · 캡처 대기와 상태 표시 정리

26차를 보존하고 27차를 추가했습니다. **기본 매크로·오프라인 한글 OCR을 유지**하며 캡처 전 두 기다림을 겹치고 같은 문구의 불필요한 재설정을 줄였습니다.

| 변경 | 실제 내용 | 유지한 조건 |
|---|---|---|
| 캡처 | 덮개 숨김 뒤 안정화와 캡처 간격 대기 중첩 | 150ms·API30 1100ms/API31 이상 500ms·재시도·정지·오래된 결과 폐기 |
| 화면 갱신 | 동일 글자·동일 표시 상태의 재설정 생략 | 실제 내용 변경은 갱신 |
| 디자인 | 흑백·차분한 파란 포인트, 구분선·간격·선택·연결 표시 | 기존 배치·라이트/다크·나눔고딕 Bold |

| 공개 첫 화면 | 현재 27차와 같은 수준 5개 연결, 이전 설명 접기 | 기존 차수·실질 설명·앵커·자료 보존 |
