# 차수별 문서 작성 기준

2026년 11월 20일 사용자 직접 정정에 따라 PXE 프로젝트에 적용합니다.

| 문서 | 포함할 내용 |
| --- | --- |
| 프로젝트 첫 화면 | 현재 제품·핵심 기능·설치와 사용 안내·전체 차수 탐색 |
| 각 차수 상세 | 그 차수의 목적·기능·설정·실행·실제 결과·한계 |
| 바뀐 점·차이점 | 직전 차수와의 기능·설정·결과·파일 비교 |
| 최종 안내 | 현재 납품 버전·파일·사용법·확인 범위 |
| 변경 기록 | 차수별 변경 항목과 상세 링크 |

- 다른 차수의 설명과 결과를 해당 차수 본문에 반복해서 붙이지 않습니다. 이전 차수는 바뀐 점·차이점에서 비교하고 원래 차수로 연결합니다.
- 현재 결과가 확정되면 준비 중·대기·이전 납품 유지 문구를 현재 안내에 남겨 두지 않습니다. 개발 과정과 실패 원문은 해당 차수의 기록과 Git 이력에서 보존합니다.
- 이전 내용을 보존한다는 이유로 현재 본문 아래에 예전 안내와 새 확정표를 반복 추가하지 않습니다.
- 다섯 읽기 수준과 같은 수준 연결은 유지합니다. 결과·파일 지문은 해당 차수의 공통 근거로 연결하고 서로 다른 분모를 합치지 않습니다.
- 사용자에게는 README·차수 상세·사용 안내처럼 읽기용 페이지를 안내합니다. 커밋 변경 화면은 변경 근거용으로만 연결합니다.
- 문서 정리를 새 앱 빌드나 기능 개선으로 표시하지 않습니다. 공개 가능한 문서만 반영하고 개인 지침·운영 원문·키·시범 자료는 공개하지 않습니다.


## 차수와 납품 파일

- 문서의 정리·오탈자·설명 수정만으로 새 차수를 만들지 않습니다. 해당 제품 차수의 문서를 수정합니다.
- 현재 앱과 문서는 모두 24차입니다. 문서 정리만을 이유로 앱 버전을 올리거나 APK를 다시 빌 드하지 않습니다.
- 새 차수 생성과 재빌드는 실제 앱 변경 및 명시된 작업 범위에 맞춰 진행합니다.
- APK·압축파일·사용안내는 해당 차수 폴더에 함께 두고 최종 폴더에는 현재 납품 파일만 둡니다.

## 필요한 확인만 수행

문서 수정은 바뀐 부분과 저장 상태만 확인합니다. 같은 파일의 검사를 반복하거나 앱 테스트·별도 검증자·전수 게시 검사를 문서 정리만을 이유로 추가하지 않습니다. 기존 검사 근거가 유효하면 그대로 사용합니다.
