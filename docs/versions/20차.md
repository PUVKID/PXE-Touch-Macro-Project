### LEVEL 1 · 자료의 목적·입력과 확인 순서

20차는 **19차 제품1.9.0/versionCode19를 그대로 쓰는 시험 도구**입니다. 새 제품APK를 만든 차수가 아닙니다. 입력은19차 제품·지정 시험 장치·OCR 반복 시험 계약이고 출력은 상태·로그·검사 자료입니다. Canvas(그림을 그리는 화면)에 글자를 표시해 실제 캡처와OCR로 두 글자 동작을15회 수행하고, 뒤로가기·같은 항목 중복 차단·실제 부재와 재등장을 반복하도록 구성했습니다.

먼저19차APK와 대상 장치·ADB·검사 조건을 확인하고 source/docs의24시간 실제OCR 시험계획과 source/tools의 장치·빌드 준비를 읽습니다. 기존19차 제품과 시험APK/도구의 역할이 다릅니다. 공개 파일만 내려받아 바로 장치 시험을 시작하는 구성도 아닙니다. 보존된 시작/중간 기록과 종료 판정을 구분하며 **이 시험은 이후 사용자 요청으로 중단됐고24시간 통과가 아닙니다.** 현재 설명을 읽는 일이 시험 재개를 뜻하지 않습니다.

### LEVEL 1 · 세부 조건과 오류 확인

사전 시험은 장치392.176초·완료 사이클4개·반복60회·OCR486회였습니다. 사이클은15회 반복을 끝낸 한 묶음이므로 횟수와 화면 읽기 수는 다른 값입니다. 본시험 시작은2026-11-02 16:14:52.516834+09:00, 당시16:20:00.327432+09:00 관측은OCR380회·15회 사이클3개·장치300.8초입니다. 최초 안내의 ‘진행 중’은 이 시점 기록입니다. 최소 판정 예정은2026-11-03 16:14:52.516834+09:00 이후였고 **86,400초와 완료 경계를 확인하기 전에 통과가 아니었습니다.** 이후 시험 중단 안내가 추가돼 실제24시간 완료/통과로 보지 않습니다.19→20 비교는 최초17개 보관 자료 기준이라 중단 안내가 추가된 현재 폴더와 시점도 다릅니다.

### LEVEL 1 · 연속성·오류 기록과 중단

호스트는 장치를 감시하는PC 쪽 프로그램입니다. PID는 프로세스 번호,boot는 부팅 식별,세대는 실행 구분값입니다. 이 값과 장치/호스트 실제 경과를 대조하며 재시작 전후 시간을 이어 붙이지 않습니다. 고정work/20차_24시간검증/status.json은 최신 요약이고 고유run폴더에는 시작/예정종료·PID/boot/세대·호스트 실제경과·30초heartbeat(살아 있다는 주기 신호)·실제OCR/완료횟수·자원추세·원문로그를 남깁니다. 독립 조회 전에 장치 원문을 저장하고 조회 이력은 크기를 제한해 순환 보존합니다.

실행 중에는 같은PID가 살아 있어야 합니다. 정상 종료 뒤에는 최종 장치상태·PID/boot연속성·실제정지·정상계측종료를 함께 확인합니다. 운영파일·개인로컬경로는 공개소스에 넣지 않습니다. 호스트의SYSTEM_REQUIRED는 자기프로세스의 일시 요청이며finally에서 해제하고 전역 전원설정은 바꾸지 않습니다.

오류일지는 원문·해시·관측시각과 첫/최신원문을 보존합니다. 시작 후 첫 관측이 기준이므로 그 이전 오류를 새 오류로 세지 않습니다. 추가 줄/변화는 관측 사이 차이이고 중간에 회전해 사라진 모든 기록을 복원하는 값은 아닙니다. 경고는 연속 실행 판정과 구분하며 일지 수집 실패는 근거가 끊긴 실패입니다. **연속PASS도 오류0 보장이 아닙니다.**

중단 안내는 소유PXE19의 정지버튼 또는 지정SDK adb의-P5043·emulator-5598 대상을 사용하도록 적었습니다. 다른serial/기본ADB5037로 대체하지 않습니다. 사용자 실제 게임·플레이어·휴대폰은 시험 대상이 아닙니다. 완료·정체·수면·시간 기준은 상세 계약을 따릅니다.

원문에 보존된 중단 명령이며 이 문서 작성에서 실행하지 않았습니다.

```powershell
& 'SDK의adb실행파일' -P 5043 -s emulator-5598 shell am force-stop kr.yunseok.touchmacro
```

run_soak.py의옵션은`--seconds`,`--run-id`, start_background.py는`--run-id`입니다. 기본값·필수값·부작용은각main과인자정의를함께확인합니다. 검증_기동요약.json은기동관측이며24시간종료결과가아닙니다.

### LEVEL 1 · 보존 범위와 전체 비교

전체 비교는 무엇이 추가·수정·삭제됐는지 보여 주는 기록입니다. 아래 ‘+’는 늘어난 행, ‘−’는 없어진 행이며 기능 개수나 성능 점수가 아닙니다. 주석·공백·줄바꿈도 차이에 포함됩니다. 실행 코드처럼 줄로 비교하기 어려운 파일은 크기와 해시로 같은 파일인지 확인합니다. 설명에 없는 과거 차수나 측정 결과를 채워 넣지 않습니다.

### LEVEL 1 · 이 자료에서 쓰는 용어

CLI는 명령어와 옵션을 입력해 프로그램을 실행하는 방식입니다. OCR은 화면 이미지 속 글자를 텍스트로 읽는 처리이고, APK는 Android 기기에 설치하는 앱 패키지 파일입니다. 접근성 서비스는 사용자가 기기 설정에서 별도로 허용한 뒤 화면 정보와 조작 기능을 이용하는 Android 기능입니다. 이 용어 풀이는19차 제품을 시험하는20차 자료의 조건을 읽기 위한 설명이며, 중단한24시간 시험의 재개나 완료 결과를 뜻하지 않습니다.

### LEVEL 2 · 자료의 목적·입력과 확인 순서

20차는19차1.9.0/versionCode19 제품을 고정한 채 관측 도구를 결합한 차수입니다. 시험 입력은 제품·지정 장치·계약이고 준비→상태/종료 조건/중간 증거 수집→로그/검사자료로 이어집니다. Canvas 화면의 실제 캡처/OCR와 두 글자 동작15회, 뒤로가기·중복 차단·부재/재등장은 반복 기능을 관측하기 위한 연결입니다.

**제품 버전과 시험 도구 차수는 다른 축**입니다.19차APK·대상/ADB·조건을 확인하고 source/docs의 계약과 source/tools의 준비를 함께 읽습니다. 고정 환경과 로컬 운영 상태가 별도로 필요하므로 공개 자료만으로 즉시 실행 가능한 배포본은 아닙니다. 초기 기동·중간 관측은 완료 근거가 아니며 이후 중단 안내가 현재 상태를 설명합니다.24시간 통과나 새APK 출시로 해석하지 않습니다.

사전 시험은 장치 392.176초·완료 사이클 4개·반복 60회·OCR 486회로 완료한 원래 기록을 보존했습니다. 본시험은 2026-11-02 16:14:52.516834+09:00에 시작했고, 16:20:00.327432+09:00 관측에서 실제 OCR 380회·15회 사이클 3개·장치 경과 300.8초를 확인한 시작 자료입니다. 본시험은 진행 중이며 최소 판정 시각은 2026-11-03 16:14:52.516834+09:00 이후입니다. 실제 86,400초와 완료 경계를 확인하기 전에는 24시간 통과로 표시하지 않습니다.

### 이후 상태 · 사용자 요청으로 중단

위 내용은 최초 기동 때의 기록입니다. [시험 중단 안내](../../20%EC%B0%A8/%EC%8B%9C%ED%97%98_%EC%A4%91%EB%8B%A8%EC%95%88%EB%82%B4.md)를 추가했으며 24시간 완료·통과가 아닙니다. 기존 19→20 전체 비교는 최초 17개 보관 자료 기준이며 중단 안내가 추가된 현재 폴더와 시점을 구분합니다.

<a name="-관측과-중단"></a>
### 관측과 중단

고정 `work/20차_24시간검증/status.json`은 최신 상태 요약입니다. 고유 run 폴더에 시작·예정 종료·PID/boot/세대·host 실제 경과·30초 heartbeat·실제 OCR/완료 횟수·자원 추세·원문 로그를 따로 남깁니다. 독립 조회 전에 장치 원문을 저장하고 조회 이력은 제한된 회전 기록으로 보존합니다. 실행 중에는 살아 있는 동일 PID를 요구합니다. 정상 종료 뒤에는 최종 장치 상태·기존 PID/boot 연속성·실제 정지 관측·정상 계측 종료를 함께 검증합니다. 운영 파일과 개인 로컬 경로는 공개 소스에 포함하지 않습니다. host는 자기 프로세스에서만 일시적인 SYSTEM_REQUIRED를 요청하고 finally에서 해제하며 전역 전원 설정을 변경하지 않습니다.

중단하려면 소유 PXE19 제어창의 정지 버튼을 누르거나, 확인한 SDK의 adb 실행파일로 다음 명령을 사용합니다. 시험은 연속 성공으로 처리하지 않으며 원문과 중단 상태를 보존합니다. 다른 serial이나 기본 ADB5037을 사용하지 않습니다.

각 관측에서 오류 일지 원문·해시·관측 시각을 제한된 회전 기록에 보존하고 첫 원문과 최신 원문을 별도 저장합니다. 최초 기준은 실행 시작 후의 첫 관측이므로 그 이전에 생긴 오류를 새 오류로 분류하지 않습니다. 이후 변화·추가 줄 수는 관측 간 차이이며 관측 사이에 회전해 사라진 모든 기록을 복원하는 값은 아닙니다. 기존 복구 경고나 새 일지 변화는 경고로 표시하고 연속 실행 판정과 구분합니다. 일지 수집 실패는 근거 단절로 실패하며, 연속 PASS를 오류 0 보장으로 확대하지 않습니다.

```powershell
& 'SDK의adb실행파일' -P 5043 -s emulator-5598 shell am force-stop kr.yunseok.touchmacro
```

사용자 실제 게임·플레이어·휴대폰은 이번 시험 대상이 아닙니다. [상세 시험 계약](../../20%EC%B0%A8/source/docs/2026-11-02_24%EC%8B%9C%EA%B0%84_%EC%8B%A4%EC%A0%9COCR_%EC%8B%9C%ED%97%98%EA%B3%84%ED%9A%8D.md)의 완료·정체·수면·시간 기준을 유지합니다.

이 폴더는 당시 고정한 시험 환경의 도구 보관본입니다. 기존 19차 제품·SDK·빌드 입력과 로컬 운영 상태를 별도로 준비해야 하며, 공개 파일만 내려받아 바로 장치 시험을 시작하는 구성은 아닙니다. 진행 중인 시험의 조작은 이 자료 정리에서 수행하지 않습니다.
