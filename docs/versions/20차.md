# ⏱️ PXE 20차 · 실제 OCR 장시간 시험 도구

19차 제품 APK를 그대로 사용하는 시험 도구와 초기 기동 자료를 보관합니다. 제품 버전은 1.9.0 / versionCode 19이며 새 APK를 만든 차수가 아닙니다.

Canvas 시험 화면에서 실제 캡처·OCR로 두 글자 동작을 15회 수행하고, 뒤로가기·같은 항목 중복 차단·실제 부재와 재등장 흐름을 반복하도록 구성했습니다. 호스트 판정기는 PID·부팅·실행 세대·장치와 호스트의 실제 경과를 대조하고, 중간 재시작 시간을 이어 붙이지 않습니다. 오류 일지의 기존 기록과 이후 관측 변화도 구분합니다.

## 관측 시점과 한계

사전 시험은 장치 392.176초·완료 사이클 4개·반복 60회·OCR 486회로 완료한 원래 기록을 보존했습니다. 본시험은 2026-11-02 16:14:52.516834+09:00에 시작했고, 16:20:00.327432+09:00 관측에서 실제 OCR 380회·15회 사이클 3개·장치 경과 300.8초를 확인한 시작 자료입니다. 본시험은 진행 중이며 최소 판정 시각은 2026-11-03 16:14:52.516834+09:00 이후입니다. 실제 86,400초와 완료 경계를 확인하기 전에는 24시간 통과로 표시하지 않습니다.

이 관측은 전용 Android 31 계측 화면의 범위이며 사용자 블루스택·게임·휴대폰의 24시간 운용이나 전체 구간 오류 0건을 증명하지 않습니다. 소스 README의 기동 전 설명과 이후 실제 시작 안내의 시점을 구분합니다.
