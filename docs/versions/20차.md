### LEVEL 1 · 실제 동작을 따라 읽기

19차 제품 APK를 그대로 사용하는 시험 도구와 초기 기동 자료를 보관합니다. 제품 버전은 1.9.0 / versionCode 19이며 새 APK를 만든 차수가 아닙니다.

Canvas 시험 화면에서 실제 캡처·OCR로 두 글자 동작을 15회 수행하고, 뒤로가기·같은 항목 중복 차단·실제 부재와 재등장 흐름을 반복하도록 구성했습니다. 호스트 판정기는 PID·부팅·실행 세대·장치와 호스트의 실제 경과를 대조하고, 중간 재시작 시간을 이어 붙이지 않습니다. 오류 일지의 기존 기록과 이후 관측 변화도 구분합니다.

사전 시험은 장치 392.176초·완료 사이클 4개·반복 60회·OCR 486회로 완료한 원래 기록을 보존했습니다. 본시험은 2026-11-02 16:14:52.516834+09:00에 시작했고, 16:20:00.327432+09:00 관측에서 실제 OCR 380회·15회 사이클 3개·장치 경과 300.8초를 확인한 시작 자료입니다. 본시험은 진행 중이며 최소 판정 시각은 2026-11-03 16:14:52.516834+09:00 이후입니다. 실제 86,400초와 완료 경계를 확인하기 전에는 24시간 통과로 표시하지 않습니다.

CLI는 명령어와 옵션을 입력해 프로그램을 실행하는 방식입니다. OCR은 그림에 있는 글자를 텍스트로 읽는 처리입니다. APK는 안드로이드 기기에 설치하는 앱 패키지입니다. 접근성 서비스는 기기의 별도 허용을 받아 화면 조작을 수행하는 안드로이드 기능입니다.

입력 — 19차 제품·지정 시험 장치·OCR 반복 시험 계약

처리 — 시험 준비 → 실행 상태·종료 조건·중간 증거 수집

출력 — 장시간 시험의 상태·로그·검사 자료

#### LEVEL 1 · 관측과 중단

고정 `work/20차_24시간검증/status.json`은 최신 상태 요약입니다. 고유 run 폴더에 시작·예정 종료·PID/boot/세대·host 실제 경과·30초 heartbeat·실제 OCR/완료 횟수·자원 추세·원문 로그를 따로 남깁니다. 독립 조회 전에 장치 원문을 저장하고 조회 이력은 제한된 회전 기록으로 보존합니다. 실행 중에는 살아 있는 동일 PID를 요구합니다. 정상 종료 뒤에는 최종 장치 상태·기존 PID/boot 연속성·실제 정지 관측·정상 계측 종료를 함께 검증합니다. 운영 파일과 개인 로컬 경로는 공개 소스에 포함하지 않습니다. host는 자기 프로세스에서만 일시적인 SYSTEM_REQUIRED를 요청하고 finally에서 해제하며 전역 전원 설정을 변경하지 않습니다.

중단하려면 소유 PXE19 제어창의 정지 버튼을 누르거나, 확인한 SDK의 adb 실행파일로 다음 명령을 사용합니다. 시험은 연속 성공으로 처리하지 않으며 원문과 중단 상태를 보존합니다. 다른 serial이나 기본 ADB5037을 사용하지 않습니다.

각 관측에서 오류 일지 원문·해시·관측 시각을 제한된 회전 기록에 보존하고 첫 원문과 최신 원문을 별도 저장합니다. 최초 기준은 실행 시작 후의 첫 관측이므로 그 이전에 생긴 오류를 새 오류로 분류하지 않습니다. 이후 변화·추가 줄 수는 관측 간 차이이며 관측 사이에 회전해 사라진 모든 기록을 복원하는 값은 아닙니다. 기존 복구 경고나 새 일지 변화는 경고로 표시하고 연속 실행 판정과 구분합니다. 일지 수집 실패는 근거 단절로 실패하며, 연속 PASS를 오류 0 보장으로 확대하지 않습니다.

```powershell
& 'SDK의adb실행파일' -P 5043 -s emulator-5598 shell am force-stop kr.yunseok.touchmacro
```

사용자 실제 게임·플레이어·휴대폰은 이번 시험 대상이 아닙니다. [상세 시험 계약](../../20%EC%B0%A8/source/docs/2026-11-02_24%EC%8B%9C%EA%B0%84_%EC%8B%A4%EC%A0%9COCR_%EC%8B%9C%ED%97%98%EA%B3%84%ED%9A%8D.md)의 완료·정체·수면·시간 기준을 유지합니다.

이 폴더는 당시 고정한 시험 환경의 도구 보관본입니다. 기존 19차 제품·SDK·빌드 입력과 로컬 운영 상태를 별도로 준비해야 하며, 공개 파일만 내려받아 바로 장치 시험을 시작하는 구성은 아닙니다. 진행 중인 시험의 조작은 이 자료 정리에서 수행하지 않습니다.

#### LEVEL 4 · 이 차수 원래 안내의 세부 조건

#### LEVEL 4 · 관측 시점과 한계

사전 시험은 장치 392.176초·완료 사이클 4개·반복 60회·OCR 486회로 완료한 원래 기록을 보존했습니다. 본시험은 2026-11-02 16:14:52.516834+09:00에 시작했고, 16:20:00.327432+09:00 관측에서 실제 OCR 380회·15회 사이클 3개·장치 경과 300.8초를 확인한 시작 자료입니다. 본시험은 진행 중이며 최소 판정 시각은 2026-11-03 16:14:52.516834+09:00 이후입니다. 실제 86,400초와 완료 경계를 확인하기 전에는 24시간 통과로 표시하지 않습니다.

#### LEVEL 4 · 이후 상태 · 사용자 요청으로 중단

위 내용은 최초 기동 때의 기록입니다. [시험 중단 안내](../../20%EC%B0%A8/%EC%8B%9C%ED%97%98_%EC%A4%91%EB%8B%A8%EC%95%88%EB%82%B4.md)를 추가했으며 24시간 완료·통과가 아닙니다. 기존 19→20 전체 비교는 최초 17개 보관 자료 기준이며 중단 안내가 추가된 현재 폴더와 시점을 구분합니다.

#### LEVEL 4 · 관측과 중단

고정 `work/20차_24시간검증/status.json`은 최신 상태 요약입니다. 고유 run 폴더에 시작·예정 종료·PID/boot/세대·host 실제 경과·30초 heartbeat·실제 OCR/완료 횟수·자원 추세·원문 로그를 따로 남깁니다. 독립 조회 전에 장치 원문을 저장하고 조회 이력은 제한된 회전 기록으로 보존합니다. 실행 중에는 살아 있는 동일 PID를 요구합니다. 정상 종료 뒤에는 최종 장치 상태·기존 PID/boot 연속성·실제 정지 관측·정상 계측 종료를 함께 검증합니다. 운영 파일과 개인 로컬 경로는 공개 소스에 포함하지 않습니다. host는 자기 프로세스에서만 일시적인 SYSTEM_REQUIRED를 요청하고 finally에서 해제하며 전역 전원 설정을 변경하지 않습니다.

중단하려면 소유 PXE19 제어창의 정지 버튼을 누르거나, 확인한 SDK의 adb 실행파일로 다음 명령을 사용합니다. 시험은 연속 성공으로 처리하지 않으며 원문과 중단 상태를 보존합니다. 다른 serial이나 기본 ADB5037을 사용하지 않습니다.

각 관측에서 오류 일지 원문·해시·관측 시각을 제한된 회전 기록에 보존하고 첫 원문과 최신 원문을 별도 저장합니다. 최초 기준은 실행 시작 후의 첫 관측이므로 그 이전에 생긴 오류를 새 오류로 분류하지 않습니다. 이후 변화·추가 줄 수는 관측 간 차이이며 관측 사이에 회전해 사라진 모든 기록을 복원하는 값은 아닙니다. 기존 복구 경고나 새 일지 변화는 경고로 표시하고 연속 실행 판정과 구분합니다. 일지 수집 실패는 근거 단절로 실패하며, 연속 PASS를 오류 0 보장으로 확대하지 않습니다.

```powershell
& 'SDK의adb실행파일' -P 5043 -s emulator-5598 shell am force-stop kr.yunseok.touchmacro
```

사용자 실제 게임·플레이어·휴대폰은 이번 시험 대상이 아닙니다. [상세 시험 계약](../../20%EC%B0%A8/source/docs/2026-11-02_24%EC%8B%9C%EA%B0%84_%EC%8B%A4%EC%A0%9COCR_%EC%8B%9C%ED%97%98%EA%B3%84%ED%9A%8D.md)의 완료·정체·수면·시간 기준을 유지합니다.

이 폴더는 당시 고정한 시험 환경의 도구 보관본입니다. 기존 19차 제품·SDK·빌드 입력과 로컬 운영 상태를 별도로 준비해야 하며, 공개 파일만 내려받아 바로 장치 시험을 시작하는 구성은 아닙니다. 진행 중인 시험의 조작은 이 자료 정리에서 수행하지 않습니다.

<a name="-설치-환경과-실행사용법"></a>
## 설치 환경과 실행·사용법

source/docs의 24시간 실제 OCR 시험계획과 source/tools의 장치·빌드 준비 조건을 읽습니다. 19차 제품과 시험 APK/도구의 역할을 구분합니다.

20차는 기존 19차 제품을 대상으로 하는 장시간 시험 도구입니다. 새 제품 APK 빌드 명령과 구분하며 해당 폴더의 시험 안내·대상 장치 확인을 따릅니다.

<a name="-이-차수-원래-안내의-세부-조건"></a>
### 이 차수 원래 안내의 세부 조건

### 관측 시점과 한계

사전 시험은 장치 392.176초·완료 사이클 4개·반복 60회·OCR 486회로 완료한 원래 기록을 보존했습니다. 본시험은 2026-11-02 16:14:52.516834+09:00에 시작했고, 16:20:00.327432+09:00 관측에서 실제 OCR 380회·15회 사이클 3개·장치 경과 300.8초를 확인한 시작 자료입니다. 본시험은 진행 중이며 최소 판정 시각은 2026-11-03 16:14:52.516834+09:00 이후입니다. 실제 86,400초와 완료 경계를 확인하기 전에는 24시간 통과로 표시하지 않습니다.

### 이후 상태 · 사용자 요청으로 중단

위 내용은 최초 기동 때의 기록입니다. [시험 중단 안내](../../20%EC%B0%A8/%EC%8B%9C%ED%97%98_%EC%A4%91%EB%8B%A8%EC%95%88%EB%82%B4.md)를 추가했으며 24시간 완료·통과가 아닙니다. 기존 19→20 전체 비교는 최초 17개 보관 자료 기준이며 중단 안내가 추가된 현재 폴더와 시점을 구분합니다.

<a name="-관측과-중단"></a>
### 관측과 중단

고정 `work/20차_24시간검증/status.json`은 최신 상태 요약입니다. 고유 run 폴더에 시작·예정 종료·PID/boot/세대·host 실제 경과·30초 heartbeat·실제 OCR/완료 횟수·자원 추세·원문 로그를 따로 남깁니다. 독립 조회 전에 장치 원문을 저장하고 조회 이력은 제한된 회전 기록으로 보존합니다. 실행 중에는 살아 있는 동일 PID를 요구합니다. 정상 종료 뒤에는 최종 장치 상태·기존 PID/boot 연속성·실제 정지 관측·정상 계측 종료를 함께 검증합니다. 운영 파일과 개인 로컬 경로는 공개 소스에 포함하지 않습니다. host는 자기 프로세스에서만 일시적인 SYSTEM_REQUIRED를 요청하고 finally에서 해제하며 전역 전원 설정을 변경하지 않습니다.

중단하려면 소유 PXE19 제어창의 정지 버튼을 누르거나, 확인한 SDK의 adb 실행파일로 다음 명령을 사용합니다. 시험은 연속 성공으로 처리하지 않으며 원문과 중단 상태를 보존합니다. 다른 serial이나 기본 ADB5037을 사용하지 않습니다.

각 관측에서 오류 일지 원문·해시·관측 시각을 제한된 회전 기록에 보존하고 첫 원문과 최신 원문을 별도 저장합니다. 최초 기준은 실행 시작 후의 첫 관측이므로 그 이전에 생긴 오류를 새 오류로 분류하지 않습니다. 이후 변화·추가 줄 수는 관측 간 차이이며 관측 사이에 회전해 사라진 모든 기록을 복원하는 값은 아닙니다. 기존 복구 경고나 새 일지 변화는 경고로 표시하고 연속 실행 판정과 구분합니다. 일지 수집 실패는 근거 단절로 실패하며, 연속 PASS를 오류 0 보장으로 확대하지 않습니다.

```powershell
& 'SDK의adb실행파일' -P 5043 -s emulator-5598 shell am force-stop kr.yunseok.touchmacro
```

사용자 실제 게임·플레이어·휴대폰은 이번 시험 대상이 아닙니다. [상세 시험 계약](../../20%EC%B0%A8/source/docs/2026-11-02_24%EC%8B%9C%EA%B0%84_%EC%8B%A4%EC%A0%9COCR_%EC%8B%9C%ED%97%98%EA%B3%84%ED%9A%8D.md)의 완료·정체·수면·시간 기준을 유지합니다.

이 폴더는 당시 고정한 시험 환경의 도구 보관본입니다. 기존 19차 제품·SDK·빌드 입력과 로컬 운영 상태를 별도로 준비해야 하며, 공개 파일만 내려받아 바로 장치 시험을 시작하는 구성은 아닙니다. 진행 중인 시험의 조작은 이 자료 정리에서 수행하지 않습니다.
