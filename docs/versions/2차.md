### LEVEL 1 · 부분 자료를 보관한 이유


2차에는 **글자 동작과 OCR 미리보기 JSON 예제·사용법·당시 검증 기록**이 남아 있습니다.

JSON은 항목 이름과 값을 짝 지어 설정을 적는 파일이고, OCR은 화면 이미지의 글자를 읽는 기술입니다.

이 페이지의 입력은 보존된 파일, 하는 일은 조건과 검사 기록을 읽어 대조하는 것, 출력은 예제 설정과 당시 확인 범위에 대한 이해입니다.

### LEVEL 1 · 예제를 읽는 순서


텍스트와 JSON을 열 수 있는 편집기를 준비하고 예제 _OCR _미리 보기.json과 예제 _글자 _뒤로 가기.json을 읽습니다. schema는 저장 형식, 동작 type은 할 일의 종류, text는 찾을 문구, source는 글자를 읽는 방식, failure는 실패했을 때의 처리 항목입니다.

먼저 이 필드를 확인하고 사용법의 기능 설명과 실제 남은 파일을 나누어 보십시오.

참고 앱 _기능 반영 표도 설명 자료이며 완전한 구현 소스의 대체물이 아닙니다.

### LEVEL 1 · 검증 기록과 실제 화면의 차이


검증 결과.txt와 검증/에서 당시 장치와 검사 항목, 성공·미검증 범위를 확인합니다.

가상 기기는 컴퓨터에서 실행하는 Android 환경이며 실물 기기와 같은 검증으로 합치면 안 됩니다.

**과거 기록은 새 장치에서 다시 실행한 결과가 아닙니다.

** 예제와 현재 화면이 다르면 대상 문구·검색 영역·인식 방식을 따로 맞춰 보아야합니다.

제품 소스나 APK가 없다면 부분 본의 예제와 기록 범위에서 읽고 이 묶음으로 재빌드를 시도하지 않습니다.

### LEVEL 1 · 보존 자료와 전체 비교


전체 비교는 무엇이 추가·수정·삭제됐는지 보여 주는 기록입니다.

아래 ‘+’는 늘어난 행, ‘−’는 없어진 행이며 기능 개수나 성능 점수가 아닙니다.

주석·공백·줄바꿈도 차이에 포함됩니다.

실행 코드처럼 줄로 비교하기 어려운 파일은 크기와 해시로 같은 파일인지 확인합니다.

설명에 없는 과거 차수나 측정 결과를 채워 넣지 않습니다.


### LEVEL 1 · 이 자료에서 쓰는 용어


APK는 Android 기기에 설치하는 앱 패키지 파일입니다. 이 2차 자료에 담긴 설정 예제와 사용법 자체가 설치 파일이라는 뜻은 아닙니다.

### LEVEL 2 · 예제·문서·검증의 관계


2차의 보존 단위는 제품 전체 소스가 아니라 글자 동작/OCR 미리 보기 예제, 사용법, 검증 기록입니다.

예제는 설정 형태를, 사용법은 제품 동작에 대한 설명을, 검증 파일은 당시 관측 조건을 제공합니다.

파일을 입력으로 받아 글자 조건·검색 방식·실패 정책·검사 조건을 대조하는 것이 이 자료의 처리 흐름입니다.

**2차 전체 Java·Gradle 구현이 확인되지 않으므로 1 →3 기능 변화는 이 부분 자료로 확정할 수 없습니다.

### LEVEL 2 · 필드에서 사용 조건으로 연결하기


JSON과 텍스트를 읽을 편집기로 두 예제를 열고 schema →type →text/source →failure를 따라가십시오.

저장 형식과 동작 종류를 확인한 뒤 어떤 문구를 어떤 출처에서 읽고 실패 시 어떻게 처리하는지 연결합니다.

사용법과 참고 앱 기능 반영 표의 설명이 실제 보존된 파일과 어느 범위에서 대응하는지 구분합니다.

제품 전체 프로젝트가 없는 상태에서 예제 JSON을 APK로 바꾸는 실행 단계는 이 묶음에 없습니다.

### LEVEL 2 · 결과 해석의 조건


출력은 예제 설정과 당시 검사 범위의 설명입니다.

검증 기록의 장치·항목·성공/미검증을 함께 읽고 가상/실물 기기를 구분하십시오.

예제가 현재 화면과 다르면 문구·영역·인식 방식의 차이를 별도로 대조해야 하며 기록된 제품 동작을 새 환경의 재현 성공으로 확장하지 않습니다.

소스/APK 부재는 예제·기록이라는 자료 범위를 제한하는 조건이며 다른 차수로 빈 부분을 임의 보충할 근거가 아닙니다.

### LEVEL 3 · 사용할 수 있는 입력과 준비물


JSON·텍스트 편집기를 준비하고 보존된 두 예제·사용법·검증 파일을 입력으로 사용하십시오.

이 자료는 Android 매크로의 글자 조건과 OCR 미리 보기를 읽는 부분 본입니다.

전체 Java·Gradle 소스가 확인되지 않으므로 **재빌드 명령을 이 묶음에 적용하지 않습니다.

결과물은 설정 해석과 당시 검증 범위의 대조이며 새 기기 실행 결과가 아닙니다.

### LEVEL 3 · 예제와 문서를 대조하는 절차


예제 _OCR _미리 보기.json과 예제 _글자 _뒤로 가기.json의 schema·type·text·source·failure를 순서대로 확인하십시오.

형식/동작/문구/인식 출처/실패 정책을 기록하고 사용법 및 참고 앱 _기능 반영 표의 설명과 실제 보존 파일을 대조합니다.

실제 화면을 따로 확인할 때는 문구·검색 영역·인식 방식이 같은지 확인해야 합니다.

예제 항목이 있다는 이유로 해당 제품 전체 구현이 보존됐다고 기록하지 않습니다.

### LEVEL 3 · 검사 기록을 확인하는 절차


검증 결과.txt와 검증/에서 장치, 검사 항목, 성공과 미검증 범위를 읽으십시오. 가상 기기 결과와 실물 기기 결과를 분리하고 과거 관측을 현재 장치의 재검사로 보고하지 않습니다. APK_SHA256은 파일 식별 자료이고 NanumGothic-OFL은 사용 조건 자료이므로 성능 증거로 대체하지 않습니다.

### LEVEL 3 · 실제 자료 구성
