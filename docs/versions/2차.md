<a name="features"></a>

## ✨ 핵심 기능과 보존 범위

| 항목 | 이 차수에서 확인할 내용 |
|---|---|
| 1 | 글자 동작·OCR 예제와 공개 가능한 기존 검증 기록을 보존합니다. 2차 제품 소스의 완전한 묶음은 이 폴더에서 확인되지 않아 1→3차 사이 기능 변화를 이 자료만으로 확정하지 않습니다. 실행점검/2차의 화면 캡처 도구와는 별개입니다. |

| ⚙️ 처리 | 글자 조건·검색 방식·실패 정책·기존 검사 조건 읽기 |
| 📤 출력 | 예제 설정과 당시 검증 범위의 설명 |
