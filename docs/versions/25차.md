# 25차 · 차수별 안내 정리

앱 버전은 **24차 · 2.4.0** 그대로입니다. 이번 차수는 문서만 정리합니다.

<a id="reading-level-1"></a>

## LEVEL 1 - Beginner

[같은 수준 프로젝트](../읽기안내/레벨1.md) · [같은 수준 프로필](https://github.com/PUVKID/PUVKID/blob/main/docs/읽기안내/레벨1.md)

첫 화면에서 현재 앱과 사용법을 바로 찾을 수 있도록 바꿨습니다. 차수 문서를 열면 그 차수의 기능과 결과를 읽고, 예전 내용은 바뀐 점에서 연결된 원문으로 확인합니다. 설치 파일과 앱 기능은 바뀌지 않았습니다.

## LEVEL 2 - Explorer
