# 23차 · 기본 매크로와 선택형 오프라인 학습

현재 선택형 모델은 시범 OCR 글자 특징을 사용하는 **584→32→K 구조의 F64 오프라인 MLP**입니다. 기존 매크로가 주 기능이며 AI는 기본 꺼짐입니다.

사용자가 확인한 시범·교정으로 정책의 실제 가중치를 갱신하고 현재 OCR 글자 위치에서 행동합니다. OCR 엔진 자체의 재학습과 구분하며 자기 예측을 자동 정답으로 학습하지 않습니다. 기존 흑백·파란 포인트색과 네이티브 화면을 유지합니다.

과거 한국어 자연어 Transformer 실험은 개발 평가11/64, 17.18%(소수 둘째 자리까지 버림; 원값17.1875%)로 실패했고 언어모델 자산은 앱에 포함하지 않았습니다(assets0). 현재 행동 MLP의 통과를 LLM 전체 완성으로 표시하지 않습니다.

전용 Android 시험에서 실제 시범2회, 학습192단계, OCR 관측17회, 다른 UID 시험 앱의 자동 터치1회와 FINISH 뒤 추가 입력0을 확인했습니다. 같은 설치의 별도 저장소와 새 작업 식별자로 가져온 뒤 추가64단계를 학습했고, 원복30개 항목과 관리 대상 잔류0을 확인했습니다. 실제 단일 기기 검사와 원복은 통과했고 별도 독립 대조도 통과했습니다.

앞선 학습97은 첫64회 갱신 뒤 ZIP 검사에 실패하고 원복했습니다. 수정82의 제어·정지·방패 수명11개 통과와 Bundle98 저장 시각 수정 후 실제 학습 검증은 버전별 근거로 구분합니다. 과거 실패를 후속 성공으로 지우지 않습니다.

다른 설치·휴대전화 간 이식, Android 파일 선택창(SAF)의 실제 조작, 모든 게임·사용자 작업·24시간 연속 운용은 검증하지 않았습니다. 중단된 장기 시험은 재개하지 않았습니다. 전체 실행207.468초에는 설치·증거·복원이 포함되므로 매크로 사이클 속도가 아닙니다.

공용 APK `PXE_23차_v2.3_공용.apk`는 ARM64 휴대전화와 x86_64 기반64비트 Android 에뮬레이터에서 사용하는 한 파일입니다. Android API30 이상이며 ARM32는 포함하지 않습니다. 78,457,218바이트(십진 약78.46MB), SHA-256 `d95dfd884da3d44dd35f5df31e7a92c1710059b754b8c5c4c736c86b3d0111ad`입니다. 파일당64MiB 공개 상한을 넘으므로 APK는 Git 저장소에서 보류하고 로컬 납품·크기/해시·재현 소스를 제공합니다. 검사 APK와 ARM64 비교 APK는 사용자 납품 파일이 아닙니다.

## 최종 납품과 마지막 확인

공용 APK 한 개와 사용 안내를 로컬 최종 폴더에 저장했습니다. 기존 차수 원본과 검증 이력은 보존합니다. 마지막 중앙 검사는 단위255개·UTF-8·APK와 이전 차수 보존·언어모델/계획59개를 포함한4개 검사 모두 통과했습니다. Java는CPU4·최대 heap512MiB로 관측됐습니다. 이 중앙 검사에는 합성 학습이 포함되지만 새 기기·Gradle·지연 주입 진단·24시간 시험은 실행하지 않았습니다.

화면 응답 시간 초과의 추가 원인 후보는 실제 재현·제품 수리를 완료하지 않았습니다. 기존의 실제 시범 학습 성공이나 중앙 통과가 그 오류의 해결을 보장하지 않습니다. [최종 납품 안내](../../최종/README.md) · [사용 안내](../../23차/사용안내.md)
