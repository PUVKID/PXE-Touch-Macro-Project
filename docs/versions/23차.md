### LEVEL 1 · 글자를 보고 행동을 배우는 선택 기능


PXE의 기본은 사용자가 정한 동작을 순서대로 실행하는 매크로입니다. 23차는 여기에 **시범으로 행동을 가르치는 오프라인 기능**을 선택적으로 더 했습니다.

AI는 처음에는 꺼져 있습니다.

오프라인은 이 기능을 앱 안에서 처리한다는 뜻이며, 설치만 하면 모든 화면을 이미 배운 상태라는 뜻은 아닙니다.

기존 흑백·파란 포인트 색과 Android의 네이티브 화면을 유지합니다.

OCR은 화면 사진의 글자를 읽습니다.

사용자가 시범과 교정을 확인하면 작은 신경망의 내부 숫자인 가중치를 바꿔 다음 행동을 고르도록 학습합니다.

다시 실행할 때는 글자가 예전과 다른 곳에 있을 수 있으므로 **OCR로 찾은 현재 글자 위치**에서 행동합니다.

화면을 읽는 OCR 엔진 자체를 다시 학습시키는 것은 아니며, 모델이 스스로 고른 답을 자동으로 정답 삼아 배우지도 않습니다.

모델 표기 584 →32 →K는 입력 값 584개, 중간 노드 32개, 등록한 행동 수 K 개를 뜻합니다.

MLP는 이 층들을 연결한 작은 신경망이고 F64는 숫자를 64 비트로 저장하는 형식입니다.

이것은 자유로운 한국어 문장을 모두 이해하는 대형 언어 모델(LLM)이 아닙니다.

과거 자연 어 Transformer 실험은 개발 평가 64개 중 11개로 실패했습니다.

원 비율 17.1875%를 소수 첫째 자리로 반올림하면 **17.2%**입니다.

LEVEL5의 과거 17.18% 표시는 원문으로 보존하며 현재 요약 표시와 구분합니다.

언어 모델 자산은 앱에 0개입니다.

### LEVEL 1 · 실제로 확인한 순서와 실패


전용 Android 시험에서는 시범 2회로 학습 192 단계를 수행하고 화면 글자를 17회 관측했습니다.

다른 UID, 즉 Android가 별개 앱으로 구분하는 시험 앱에 자동 터치 1회가 전달됐고, FINISH라는 종료 상태 뒤 추가 입력은 0회였습니다.

같은 설치 안의 별도 저장소로 내보낸 내용을 새 작업 식별자로 가져온 뒤 64 단계를 더 학습했습니다.

이것이 이번 실제 단일 기기 검사와 별도 독립 대조가 확인한 범위입니다.

시험 뒤 원래 상태로 되돌리는 **원 복 30개 항목**도 확인했고 관리 대상 잔류는 0개였습니다.

원 복은 시험이 환경을 남기지 않았는지 확인하는 절차이므로 행동 학습 성공과 따로 읽습니다.

앞선 학습 97에서는 첫 64회 갱신 뒤 ZIP 묶음 검사에 실패하고 원 복했습니다.

수정 82의 제어·정지·방패 수명 11개 통과와, Bundle98의 저장 시 각 수정 후 학습 성공은 서로 다른 버전 근거입니다.

나중 성공해도 앞의 실패 기록은 남습니다.

### LEVEL 1 · 설치 파일과 준비 자료


사용자 납품 파일은 **공용 APK 한 개와 사용 안내**입니다.

APK는 Android 설치 파일입니다. `PXE_23차_v2.3_공용.apk`는 ARM64 휴대 전화와 x86_64 기반 64비트 에뮬레이터를 위한 한 파일이며 Android API30 이상이 필요하고 ARM32는 포함하지 않습니다.

크기는 78,457,218바이트, 십 진 단위 약 78.46MB입니다.

SHA-256은 파일이 같은지 확인하는 지문이며 값은 `d95dfd884da3d44dd35f5df31e7a92c1710059b754b8c5c4c736c86b3d0111ad`입니다.

파일당 64MiB 공개 상한을 넘으므로 Git 저장소에서 APK는 보류하고 로컬 납품·파일 정보·재현 소스를 제공합니다.

검사 APK나 ARM64 비교 APK는 사용자가 설치할 최종 납품 파일과 다릅니다.

먼저 [사용 안내](../../23차/사용안내.md)로 준비와 조작을 확인하고 [자료](../../23차/)에서 관련 파일을 찾습니다. [변경 기록](../../23차/공개용_변경기록.md)과 [22→23 전체 차이](../revision-audit/23차.md)는 무엇이 달라졌는지 확인하는 근거입니다.

### LEVEL 1 · 최종 확인이 의미하는 범위


마지막 중앙 검사 4개는 단위 255개, UTF-8 글자 인코딩, APK·이전 차수 보존, 언어 모델/계획 59개를 포함해 통과했습니다.

Java 실행에서는 CPU4·최대 메모리 512MiB가 관측됐습니다.

합성 학습 자료가 포함된 검사이며 새 기기·Gradle·지연 주입 진단·24시간 시험을 새로 실행한 결과는 아닙니다.

기존 차수 원본과 검증 이력을 보존한 채 공용 파일과 안내를 로컬 최종 폴더에 두었습니다.

다른 설치나 휴대 전화로 옮기는 일, Android 파일 선택 창(SAF)의 실제 조작, 모든 게임과 사용자 작업,24시간 연속 운용은 확인하지 않았습니다.

중단된 장기 시험도 재개하지 않았습니다.

전체 207.468초에는 설치·증거 수집·원 복이 들어 있어 매크로 한 바퀴 속도로 볼 수 없습니다.

화면 응답 시간 초과의 추가 원인 후보도 실제 재현·수리를 완료하지 않았으므로 학습 성공을 그 오류 해결로 읽지 않습니다. [검증 범위](../../23차/검증_결과.md)와 [최종 납품 안내](../../23차/사용안내.md)를 함께 확인하십시오.

### LEVEL 2 · 관측·학습·실행이 맡는 일


23차의 선택형 AI는 화면의 글자를 읽는 OCR, 다음 행동을 고르는 **584→32→K F64 MLP**, 실제 입력을 전달하는 기존 매크로 경로를 연결합니다.

OCR은 글자와 현재 위치를 제공합니다.

MLP는 사용자가 확인한 시범·교정으로 가중치를 갱신합니다.

실행은 녹화 당시 위치가 아니라 지금 OCR로 찾은 위치를 사용합니다.

따라서 OCR 엔진 학습과 행동 정책 학습을 같은 과정으로 볼 수 없습니다.

AI가 기본 꺼짐인 이유를 이해하려면 기존 매크로와 선택형 학습의 관계를 봐야합니다.

기존 매크로는 여전히 주 기능이고 시범 학습은 필요한 경우 켜는 추가 경로입니다.

화면은 기존 네이티브 구성과 흑백·파란 포인트 색을 유지합니다.

자기 예측을 자동 정답으로 되 먹이지 않으므로 터치가 전달됐다는 신호만으로 모델이 그 행동을 옳게 학습하는 구조로 설명해서는 안 됩니다.

### LEVEL 2 · 행동 학습과 자연어 실험의 평가를 나누기


MLP의 584개 입력은 32개 중간 노드를 거쳐 K 개 행동으로 이어집니다.

F64는 가중치 숫자 형식이며 모델이 자유로운 한국어를 이해한다는 지표가 아닙니다.

과거 자연 어 Transformer의 개발 평가11/64는 별도 과제에서의 실패입니다.

원값 17.1875%, 현재 반올림 표시 17.2%이고 언어 모델 자산은 0개입니다.

원문에 남은 17.18% 버림 표시는 당시 표시 방식이며 관측값 변경이 아닙니다.

**행동을 배워 한 번 누른 결과를 자연어 명령 전체의 성공으로 연결할 수 없습니다.**

### LEVEL 2 · 실제 학습에서 저장·가져오기까지


전용 Android 시험의 시범 2회 →학습 192 단계 →OCR17회 →다른 UID 앱 자동 터치 1회 →FINISH 후 입력 0이라는 흐름은 가중치 갱신과 행동·종료를 연결한 근거입니다.

같은 설치의 별도 저장소와 새 작업 식별자로 가져온 뒤 추가 64 단계 학습은 저장된 상태를 이어 쓰는 경로의 근거입니다.

서로 다른 설치 사이의 이식이나 SAF 선택 창 조작은 여기에 포함되지 않습니다.

원 복 30개 항목과 관리 대상 잔류 0은 환경 복원의 결과입니다.

단일 기기 검사와 별도 독립 대조가 통과했지만 전체 207.468초는 설치·증거·복원을 포함합니다.

처리 속도 평가에는 구간 정의가 필요하므로 이 값을 매크로 사이클 시간으로 쓰지 않습니다.

앞선 학습 97은 첫 64회 후 ZIP 검사에서 실패했고 원 복했습니다.

수정 82의 제어·정지·방패 수명 11개와 Bundle98 저장 시 각 수정 후 실제 학습은 버전이 달라 각각의 원인·결과 연결을 유지합니다.

### LEVEL 2 · 배포 구조와 검증 경계


공용 APK 하나가 ARM64 휴대 전화와 x86_64 64비트 에뮬레이터를 지원합니다.

Android API30 이상, ARM32 제외라는 조건이 있으므로 ‘공용’이 모든 Android 기기를 뜻하지 않습니다. `PXE_23차_v2.3_공용.apk`는 78,457,218바이트(십 진 약 78.46MB), SHA-256 `d95dfd884da3d44dd35f5df31e7a92c1710059b754b8c5c4c736c86b3d0111ad`로 식별합니다. 64MiB 공개 상한 때문에 Git에는 APK를 보류하고 로컬 납품과 재현 소스를 제공합니다.

검사 APK·ARM64 비교 APK는 사용자 납품이 아닙니다.

최종 폴더의 공용 APK와 사용 안내는 차수 원본·검증 이력과 분리해 관리합니다.

마지막 중앙 4 검사의 단위 255·UTF-8·APK/이전 차수 보존·언어 모델/계획 59는 짧은 확인 범위입니다.

Java CPU4·heap512MiB 관측을 기록했으며 합성 학습은 포함하지만 새 기기·Gradle·지연 주입·24 시간 검사는 실행하지 않았습니다.

화면 응답 시간 초과 후보가 재현·수리되지 않았다는 한계도 남습니다.

[최종 납품](../../23차/사용안내.md)을 확인할 때도 다른 설치·SAF·모든 게임·사용자 작업·24시간 운용 미검증, 중단된 장기 시험 미재개를 함께 읽어야합니다.

### LEVEL 3 · 설치와 선택형 기능의 준비


먼저 [사용 안내](../../23차/사용안내.md)의 조건과 사용할 APK를 맞춥니다.

사용자 납품은 `PXE_23차_v2.3_공용.apk`와 안내이며 검사 APK·ARM64 비교 APK는 제외합니다.

공용 파일은 Android API30 이상, ARM64 휴대 전화 및 x86_64 기반 64 비트 에뮬레이터용이고 ARM32는 없습니다.

크기 78,457,218바이트(십 진 약 78.46MB), SHA-256 `d95dfd884da3d44dd35f5df31e7a92c1710059b754b8c5c4c736c86b3d0111ad`를 해당 파일의 식별 값으로 사용합니다. 64MiB 공개 상한을 넘겨 Git에는 APK를 보류했으며 로컬 파일 정보와 재현 소스를 제공합니다.

AI 기본값은 꺼짐입니다. 일반 매크로가 주 기능이고 기존 흑백·파란색 네이티브 화면을 유지합니다. 시범 학습을 확인할 경우 현재 기능이 **OCR 글자 특징의 584 →32 →K F64 MLP**임을 먼저 구분하십시오. 자연어 문장을 자유롭게 해석하는 LLM 기능이 완성됐다고 전제하지 않습니다.

### LEVEL 3 · 시범과 학습 결과를 확인하는 항목


사용자가 확인한 시범·교정이 입력이며 정책 가중치의 실제 갱신이 학습 결과입니다. OCR 엔진 자체의 재학습이나 자기 예측의 자동 정답화를 의미하지 않습니다. 행동 확인에서는 OCR로 찾은 **현재 위치**에 입력이 전달됐는지와 종료 뒤 추가 입력이 없는지를 함께 봅니다.

이번 전용 Android 실 측은 다음과 같습니다.

시범 2회, 학습 192 단계, OCR 관측 17회, 다른 UID 시험 앱의 자동 터치 1회, FINISH 이후 추가 입력 0회입니다.

같은 설치 안에서 별도 저장소와 새 작업 식별자로 가져온 뒤 추가 64 단계도 학습했습니다.

원 복 30개 항목은 모두 확인했고 관리 대상 잔류는 0개였습니다.

단일 기기 검사와 별도 독립 대조는 통과했습니다.

이 목록은 사용자가 현재 기기에서 그대로 재현했다고 기록할 수 있는 기본 값이 아니라 당시 실제 결과입니다.

### LEVEL 3 · 실패 기록과 시간의 범위


학습 97의 첫 64회 갱신 뒤 ZIP 검사 실패·원 복은 보존됩니다.

수정 82의 제어·정지·방패 수명 11개 통과와 Bundle98 저장 시 각 수정 후 실제 학습 성공은 버전을 구분해 [검증 범위](../../23차/검증_결과.md)에서 대조합니다.

뒤의 PASS만 보고 앞의 실패를 지우거나 서로 다른 APK 결과를 합하지 않습니다.

전체 207.468초에는 설치, 증거 수집과 복원이 포함됩니다.

속도 비교에 이 값을 사용하려면 측정 구간이 맞지 않으므로 매크로 사이클 시간으로 보고하지 않습니다.

가져오기 시험도 같은 설치 안의 별도 저장소였으므로 다른 휴대 전화 또는 다른 설치에서 실제 파일 선택을 마쳤다고 쓰지 않습니다.

SAF 파일 선택 창의 실제 조작, 모든 게임·사용자 작업,24시간 연속 운용은 미검증이고 중단된 장기 시험은 재개하지 않았습니다.

### LEVEL 3 · 최종 납품 뒤 중앙 확인 읽기


[최종 납품 안내](../../23차/사용안내.md)는 공용 APK 하나와 사용 안내를 가리킵니다.

차수별 원본과 검증 이력은 남습니다.

마지막 중앙 검사 4개는 단위 255개·UTF-8·APK/이전 차수 보존·언어 모델/계획 59개를 포함해 통과했습니다.

실행 조건은 Java CPU4·최대 heap512MiB로 관측됐습니다.

합성 학습 검사를 포함하지만 그 실행에서 새 기기·Gradle·지연 주입·24 시간 검사를 하지 않았습니다.

화면 응답 시간 초과의 추가 원인 후보는 실제 재현과 제품 수리가 완료되지 않았습니다.

중앙 통과 또는 기존 학습 성공을 해당 오류의 해결 표시로 사용하지 마십시오.

과거 자연 어 Transformer 평가도11/64 실패, 원값 17.1875%, 현재 반올림 표시 17.2%, 언어 모델 assets0입니다.

원문의 17.18%는 당시 버림 표시로 보존합니다.

이 설명에 없는 실행 명령이나 성공 수치를 만들어 재현 결과로 사용하지 않습니다.

### LEVEL 4 · 정책 학습의 경계와 기본 경로 보존


23차의 현재 모델은 **584→32→K F64 오프라인 MLP**입니다.

관측 입력은 OCR 글자 특징이며, 사용자가 확정한 시범·교정으로 정책 가중치를 갱신합니다.

실행 위치는 현재 OCR 관측에서 얻습니다.

저장된 시범 좌표를 그대로 재생하는 설명이나 OCR 엔진 자체를 학습하는 설명은 이 구조와 다릅니다.

자기 예측을 자동 정답으로 학습하지 않는 조건은 전달 성공과 과제 성공을 혼동하는 되먹임을 막는 경계입니다.

기본 꺼짐인 AI와 기존 매크로 주 경로를 분리하고 흑백·파란 포인트 색의 네이티브 UI를 유지합니다.

과거 자연 어 Transformer와 현재 행동 MLP는 입력·출력·평가 과제가 다릅니다.

자 연어 개발 평가11/64는 실패로 남으며 원값 17.1875%, 현재 반올림 표시 17.2%, 당시 원문의 버림 표시 17.18%를 구분합니다.

언어 모델 assets0인 상태에서 MLP 통과를 LLM 배포 완료로 확장할 근거는 없습니다.

### LEVEL 4 · 실제 학습·저장·종료 프로토콜의 증거


전용 Android의 시범 2·학습 192·OCR17·다른 UID 앱 자동 터치 1·FINISH 이후 입력 0은 정책 갱신부터 실제 입력·종료까지 연결한 단일 기기 근거입니다.

같은 설치의 별도 저장소와 새 작업 식별자에서 추가 64 단계 학습한 것은 저장된 학습 상태를 이어 사용하는 경로를 지지합니다.

단일 검사와 별도 독립 대조가 통과했으며 환경 원 복 30개 항목과 관리 대상 잔류 0을 별도로 확인했습니다.

이 프로토콜에는 다른 설치·휴대 전화 간 이식과 SAF 선택 창의 실제 UI가 포함되지 않습니다.

전체 207.468초는 설치·증거·복원을 포함한 외부 구간이므로 정책 추론 시간 또는 매크로 사이클 속도의 대리 지표로 쓸 수 없습니다.

모든 게임·사용자 작업·24시간 운용의 일반화도 미검증이며 중단된 장기 시험은 유지합니다.

학습 97은 첫 64회 갱신 후 ZIP 검사에서 실패하고 원 복했습니다. 수정 82의 제어·정지·방패 수명 11개와 Bundle98 저장 시 각 수정 후 학습 검증은 각 버전에 결합해야 합니다. 후속 성공을 초기 저장 실패의 부재로 재해석하거나 11개 제어 검사를 새로운 저장 버전 전체의 근거로 소급하지 않습니다.

### LEVEL 4 · 납품 식별과 검증 계층


사용자 산출물은 공용 APK와 사용 안내 두 종류입니다. `PXE_23차_v2.3_공용.apk`는 Android API30 이상에서 ARM64와 x86_64를 지원하며 ARM32는 제외합니다.

크기 78,457,218바이트(십 진 약 78.46MB), SHA-256 `d95dfd884da3d44dd35f5df31e7a92c1710059b754b8c5c4c736c86b3d0111ad`로 파일을 결합합니다.

파일당 64MiB 공개 상한에 따라 APK는 Git에서 보류하고 로컬 납품·크기/해시·재현 소스를 제공합니다.

검사 APK와 ARM64 비교 파일을 사용자 최종 파일로 혼합하지 않습니다.

최종 중앙 4 검사는 단위 255·UTF-8·APK/이전 차수 보존·언어 모델/계획 59 를 포함합니다.

Java CPU4·heap512MiB 조건이 관측됐으며 합성 학습도 포함합니다.

그러나 새 기기·Gradle·지연 주입·24시간 실행은 그 검사에 없습니다.

따라서 **중앙 통과와 실제 기기 학습 관측을 별도 증거로 결합**해야하며 한 쪽으로 다른 쪽을 대신할 수 없습니다.

화면 응답 시간 초과의 추가 후보는 재현·제품 수리가 미완료여서 기존 행동 학습 PASS로 해결했다고 결론 내릴 수 없습니다.

차수 원본과 검증 이력은 유지하고 [23차 사용 안내](../../23차/사용안내.md)의 파일을 구분합니다. 과거 원문·실패·측정값을 바꾸는 방식으로 수준별 설명을 간결하게 만들지 않습니다.

## LEVEL 5 - Expert
[바뀐 점·차이점](#reading-level-5-differences)


기존의 전체 설명·표·코드·함수 참조·파일별 비교는 아래에 그대로 이어집니다. [자료 폴더](../../23%EC%B0%A8) · [직전 비교·자료 범위](../revision-audit/23%EC%B0%A8.md) · [이 차수의 원래 전체 상세](#reading-level-5)

현재 선택형 모델은 시범 OCR 글자 특징을 사용하는 **584→32→K 구조의 F64 오프라인 MLP**입니다. 기존 매크로가 주 기능이며 AI 는 기본 꺼짐입니다.

사용자가 확인한 시범·교정으로 정책의 실제 가중치를 갱신하고 현재 OCR 글자 위치에서 행동합니다. OCR 엔진 자체의 재학습과 구분하며 자기 예측을 자동 정답으로 학습하지 않습니다. 기존 흑백·파란 포인트색과 네이티브 화면을 유지합니다.

과거 한국어 자연 어 Transformer 실험은 개발 평가11/64, 17.18%(소수 둘째 자리까지 버림; 원값 17.1875%)로 실패했고 언어 모델 자산은 앱에 포함하지 않았습니다(assets0). 현재 행동 MLP의 통과를 LLM 전체 완성으로 표시하지 않습니다.

전용 Android 시험에서 실제 시범 2회, 학습 192 단계, OCR 관측 17회, 다른 UID 시험 앱의 자동 터치 1회와 FINISH 뒤 추가 입력 0을 확인했습니다.

같은 설치의 별도 저장소와 새 작업 식별자로 가져온 뒤 추가 64 단계를 학습했고, 원 복 30개 항목과 관리 대상 잔류 0을 확인했습니다.

실제 단일 기기 검사와 원 복은 통과했고 별도 독립 대조도 통과했습니다.

앞선 학습 97은 첫 64회 갱신 뒤 ZIP 검사에 실패하고 원 복했습니다. 수정 82의 제어·정지·방패 수명 11개 통과와 Bundle98 저장 시 각 수정 후 실제 학습 검증은 버전별 근거로 구분합니다. 과거 실패를 후속 성공으로 지우지 않습니다.

다른 설치·휴대 전화 간 이식, Android 파일 선택 창(SAF)의 실제 조작, 모든 게임·사용자 작업·24시간 연속 운용은 검증하지 않았습니다. 중단된 장기 시험은 재개하지 않았습니다. 전체 실행 207.468초에는 설치·증거·복원이 포함되므로 매크로 사이클 속도가 아닙니다.

공용 APK `PXE_23차_v2.3_공용.apk`는 ARM64 휴대 전화와 x86_64 기반 64비트 Android 에뮬레이터에서 사용하는 한 파일입니다.

Android API30 이상이며 ARM32는 포함하지 않습니다. 78,457,218바이트(십 진 약 78.46MB), SHA-256 `d95dfd884da3d44dd35f5df31e7a92c1710059b754b8c5c4c736c86b3d0111ad`입니다.

파일당 64MiB 공개 상한을 넘으므로 APK는 Git 저장소에서 보류하고 로컬 납품·크기/해시·재현 소스를 제공합니다.
