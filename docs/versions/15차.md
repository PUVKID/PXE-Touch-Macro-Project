# 15차 · 인식 방식과 캡처 간격

[소스](../../15차/source/) · [사용 안내](../../15차/사용안내.md) · [14차 대비 공백·주석 포함 전체 차이](../revision-audit/15차.md)

목록 탐지 설정과 개별 글자 동작의 인식 방식 적용 범위를 구분하고 설정 화면의 검색 방식 표시를 보완합니다. 화면 정보는 접근성 텍스트를 읽으며 이미지 글자는 OCR·자동 방식을 사용합니다. 캡처 제한이 있는 화면은 읽지 못하며 제한 우회나 추측 터치를 하지 않습니다.

계속 기다리기, 인식 후 추가 대기 생략과 목록의 인식 즉시 들어가기 옵션은 각각 적용 범위가 다릅니다. 목록 즉시 들어가기는 기본 꺼짐이며 켜면 터치 전 재확인을 생략합니다. 실제 화면 읽기·캡처 보호 간격까지 0초가 되지는 않습니다. 기존 동작 사이 대기값은 자동 축소하지 않습니다.

`MacroService`, `MainActivity`, `CapturePacer`, `SetupWizard`, 관련 단위·장치 검사와 리소스·Gradle 입력을 보존합니다. 16차의 다음 글자 적응 대기·실측 표시와 혼합하지 않습니다. 실제 블루스택 5개 동시 속도·노트10+·장시간 무중단은 이번 문서 대조로 검증하지 않았습니다.
