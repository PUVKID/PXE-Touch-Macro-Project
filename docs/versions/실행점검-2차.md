### LEVEL 1 · 자료의 목적·입력과 확인 순서

이 자료는 **BlueStacks 화면 캡처의 별도 점검 도구**입니다.

제품 앱의 2차 소스나 새 UI가 아닙니다.

ADB는 Android 장치에 명령을 전달하는 도구이며 입력은 원래 고정한 로컬 BlueStacks 대상의 화면입니다. capture_readonly.py에서 setup은 연결 준비, capture는 화면을 PNG 그림 파일로 받아 검사하는 분기입니다.

결과는 PNG와 명령 JSONL입니다.

JSONL은 명령 기록을 한 줄씩 저장한 파일입니다.

먼저 코드의 고정 장치·도구 경로와 두 분기를 읽고 소유 장치·출력 경로가 맞는지 확인합니다.

Python과 원래 ADB·기존 장치가 필요하지만 앱을 시작하거나 매크로를 실행하는 도구는 아닙니다.

다른 장치를 이름이 비슷하다는 이유로 대신 선택하지 않습니다. 새 캡처에 개인 화면이 담길 수 있어 공유 전에 분리합니다.

PNG 서명은 파일 종류를, CRC는 그림 조각의 손상 여부를, 폭/높이는 크기를, SHA-256은 파일 동일성을 확인하는 값입니다. validate_png는 서명·끝 부분·크기·청크 경계·CRC를 확인합니다. setup 또는 capture1~5의 허용 요청과 원문 거부 조건은 아래 표에서 확인합니다.

장치가 없으면 소유 장치/고정 대상을, PNG 검사가 실패하면 원 바이트·CRC·크기·명령 오류를 대조합니다.

이 결과는 매크로 완료나 제품 기능의 통과가 아닙니다.

### LEVEL 1 · 보존 범위와 전체 비교

전체 비교는 무엇이 추가·수정·삭제됐는지 보여 주는 기록입니다.

아래 ‘+’는 늘어난 행, ‘−’는 없어진 행이며 기능 개수나 성능 점수가 아닙니다.

주석·공백·줄바꿈도 차이에 포함됩니다.

실행 코드처럼 줄로 비교하기 어려운 파일은 크기와 해시로 같은 파일인지 확인합니다.

설명에 없는 과거 차수나 측정 결과를 채워 넣지 않습니다.

[전체 비교·자료 범위](../revision-audit/실행점검-2차.md)

이 묶음의 직전 제품 차수는 임의로 만들지 않습니다.


### LEVEL 1 · 이 자료에서 쓰는 용어

OCR은 화면 이미지 속 글자를 텍스트로 읽는 처리입니다. 접근성 서비스는 사용자가 기기 설정에서 별도로 허용한 뒤 화면 정보와 조작 기능을 이용하는 Android 기능입니다. 여기의 실행 점검 도구는 화면 캡처를 확인하는 별도 자료이며, 제품 앱의 2차나 접근성 제스처를 실행하는 도구라는 뜻은 아닙니다.

### LEVEL 2 · 자료의 목적·입력과 확인 순서

자료의 연결은 고정 BlueStacks ADB 대상→setup 연결/capture 읽기→PNG 구조 검사→PNG·명령 JSONL 보존입니다. **화면 수집과 제품 실행은 별도 역할**입니다. 제품 2차와 비교하는 버전 진행으로 합치지 않으며 새 UI 구현도 아닙니다.

Python·코드가 참조하는 ADB/장치/출력 경로를 먼저 확인합니다. setup/capture 분기가 원래 고정된 로컬 환경을 전제하므로 현재 소유 대상과 일치하는지가 실행의 선행 조건입니다. 앱 시작·매크로 실행 성공을 이 도구의 출력에서 추론할 수 없습니다.

서명·청크 경계·CRC·끝 부분·폭/높이 검사는 PNG의 구조적 완전성을, SHA-256은 동일 파일 여부를 설명합니다.

JSONL은 명령 근거를 연결합니다.

허용 요청 setup/capture1~5와 각 거부 조건을 아래 코드 선언 표에서 대조하십시오.

대상 부재는 장치 설정 문제, PNG 실패는 캡처 바이트/CRC/크기/명령 오류로 나누어 봅니다.

**구조 검사 성공과 화면 내용의 공개 허용도 별도**여서 개인 화면을 분리해야 합니다.

## 핵심 기능과 보존 범위

**항목:** 1

**이 차수에서 확인할 내용:** BlueStacks 화면 캡처의 별도 점검 도구를 정리했습니다.

**항목:** 2

**이 차수에서 확인할 내용:** capture_readonly.py는 고정된 로컬 BlueStacks ADB 대상에서 연결·PNG 캡처를 수행하고 CRC·크기·해시·명령 JSONL을 기록합니다. 제품 앱의 2차 소스나 새 UI 구현이 아닙니다.

**항목:** 3

**이 차수에서 확인할 내용:** 제품 차수와 비교하지 않는 독립 점검 자료입니다. 앱 소스와 스크린샷 수집 도구를 하나의 버전 진행으로 합치지 않습니다.

**항목:** 4

**이 차수에서 확인할 내용:** capture_readonly.py의 setup/capture 분기는 원래 고정된 로컬 장치·도구 경로를 전제로 합니다. 실행 점검을 위한 화면 캡처 도구입니다. 새 캡처에는 화면의 개인 데이터가 담길 수 있습니다.
