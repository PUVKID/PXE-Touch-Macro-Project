| 항목 | 이 차수에서 확인할 내용 |

| 1 | BlueStacks 화면 캡처의 별도 점검 도구를 정리했습니다. |
| 2 | capture_readonly.py는 고정된 로컬 BlueStacks ADB 대상에서 연결·PNG 캡처를 수행하고 CRC·크기·해시·명령 JSONL을 기록합니다. 제품 앱의 2차 소스나 새 UI 구현이 아닙니다. |

<a name="setup"></a>

## 🚀 설치 환경과 실행·사용법

Python과 capture_readonly.py가 참조하는 ADB·기존 장치가 필요한 화면 캡처 보조 자료입니다. 원래 고정 경로를 확인한 뒤 읽습니다.

이 도구는 원래 고정된 로컬 장치·경로를 전제로 합니다. 제품 앱을 시작하거나 매크로를 실행하는 명령이 아닙니다. 현재 소유 장치와 코드의 대상이 일치하는지 먼저 확인합니다.

### 📖 이 차수 원래 안내의 세부 조건

### 🔄 입력·처리·출력

| 단계 | 내용 |
| :--- | :--- |
| 입력 | 기존 로컬 BlueStacks ADB 대상 |
| 처리 | setup 연결 또는 capture 화면 읽기와 PNG 검사 |
| 출력 | PNG 화면·CRC/크기/해시·명령 JSONL |

### 🚀 실행 경로와 제약

capture_readonly.py의 setup/capture 분기는 원래 고정된 로컬 장치·도구 경로를 전제로 합니다. 실행점검을 위한 화면 캡처 도구입니다. 새 캡처에는 화면의 개인 데이터가 담길 수 있습니다.

코드/의 차수 밖 NEX 자료와 실행점검/2차는 별도로 안내합니다. 실행점검/2차는 제품 앱의 2차가 아닙니다.
