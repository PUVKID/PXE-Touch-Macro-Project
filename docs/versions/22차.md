### LEVEL 1 · 작은 진행창과 글자 찾기


22차는 화면 위에 뜨는 작은 진행창을 옮기고 상태를 접어 볼 수 있도록 보강한 자료입니다. 진행창은 현재 실행 상태를 보여 주는 창입니다. 글자를 못 찾은 뒤 재시도하거나 기다리는 흐름도 유지했습니다. 예를 들어 보고 싶은 화면을 진행창이 가렸다면 이동하여 상태를 확인할 수 있습니다. 이 예는 기능 설명이며 새 기기에서 지금 시험한 결과는 아닙니다. **실제 파일별 변경은 21→22 전체 비교**에 기록했습니다.

### LEVEL 1 · 무엇을 열고 어떻게 읽는가


[22차 자료](../../22차/)에서 [공개 변경기록](../../22차/공개용_변경기록.md)을 읽고 [검증 범위](../../22차/검증_결과.md)를 대조한 뒤 [21→22 비교](../revision-audit/22차.md)를 확인하십시오. 공개 사본에는 일반 빌드 코드·원본 소스·합성 검사가 있습니다. 합성 검사는 시험을 위해 만든 조건을 사용하는 검사입니다. 빌드 위치와 도구는 고정된 개인 컴퓨터 경로 대신 상대경로와 사용자 환경 설정으로 연결했습니다.

서명키, 비공개 운영 원문, 장치 복원 스크립트, 개인 보존 JSON과 원래 APK는 제외 또는 보류했습니다. 서명키는 앱 배포 신원을 확인하는 비밀 자료이고 JSON은 이름/값을 담는 저장 형식입니다. 따라서 공개 자료에 없는 파일까지 모두 내려받을 수 있다고 생각하면 안 됩니다. 공개 파일이 어느 원본에서 왔는지는 비공개 파일 목록으로 추적합니다.

### LEVEL 1 · 통과하지 않은 결과도 함께 읽기


기기 검사 기록은 **71개 통과·1개 실패·123개 미실행**입니다. 24시간 시험은 중단했습니다. 일부 통과를 전체 완료 성능으로 표현하지 않으며, 아직 확인하지 않은 123개가 통과했다는 뜻도 아닙니다. 별도로 후속 선택 묶음을 준비했지만 실행하지 않았습니다. 이 묶음의 수와 원래 195개 중 남은 123개는 같은 검사 집합에서 센 값이 아니므로 서로 빼거나 더해 완료율을 계산하지 않습니다.

버전이 다른 기능과 검사 결과를 합치지 않고 당시 실패·미실행·중단을 그대로 보존합니다.

### LEVEL 2 · 화면 제어와 실행 상태의 관계


22차의 설명은 이동·접기 가능한 작은 진행창과 글자 미발견 뒤 재시도/대기 흐름을 연결합니다. 진행창은 실행 상태를 보여 주는 제어 표면이며, 창을 옮기는 개선과 글자 조건 처리의 결과는 별도로 확인해야 합니다. 파일별로 무엇이 달라졌는지는 [21→22 전체 비교](../revision-audit/22차.md)가 근거입니다.

### LEVEL 2 · 공개 자료와 재현 입력의 경계


[자료 폴더](../../22차/)의 일반 빌드 코드·원본 소스·합성 검사는 구현과 시험 조건을 보여 줍니다. 빌드 위치·도구는 상대경로와 사용자 환경 설정을 통해 연결되므로 자신의 환경에서 조건을 맞추어야 합니다. [공개 변경기록](../../22차/공개용_변경기록.md)은 변경의 의미를, [검증 기록](../../22차/검증_결과.md)은 실제 실행 범위를 보여 줍니다.

서명키·비공개 운영 원문·장치 복원 스크립트·개인 보존 JSON·원APK는 공개 사본에서 제외 또는 보류한 별도 자료입니다. 공개 가능한 소스가 있다는 사실과 기존 배포 환경의 모든 입력이 제공된다는 것은 다릅니다. 파일별 원본 대응은 비공개 manifest로 추적합니다. 이 목록은 공개 파일의 출처 관리용이며 빠진 기기 검사의 통과 근거가 아닙니다.

### LEVEL 2 · 검사 집합을 섞지 않는 이유


원래 기기 검사 집합 195개는 71개 통과, 1개 실패, 123개 미실행으로 기록되어 있습니다. **실패와 미실행을 유지한 부분 결과**이며 24시간 시험 중단도 남습니다. 이후 선택한 별도 묶음은 준비만 하고 실행하지 않았고 원195개 잔여123개와 동일한 모집합이 아닙니다. 서로 다른 집합의 숫자를 합쳐 검사 완료율로 해석하면 실제 범위를 왜곡합니다.

후속 기능이 존재한다는 사실로 22차의 실패나 중단을 성공으로 소급하지 않습니다.

| 원195개 검사 | 71통과·1실패·123미실행입니다. | 별도 후속 선택 묶음과 같은 모집합으로 합산하지 않습니다. |

### LEVEL 3 · 결과를 보고할 때의 기준


기기 검사는 **71통과/1실패/123미실행**으로 적고 원195개 범위를 유지하십시오. 24시간 시험은 중단 상태입니다. 통과 수만 뽑아 전체 제품 성능으로 제시하거나 미실행을 성공으로 넣지 않습니다. 별도 후속 선택 묶음은 준비했으나 실제로 실행하지 않았습니다. 이 묶음은 잔여123개와 동일 집합이 아니므로 대체 검사 수나 추가 통과 수로 합산하지 마십시오.

22차 UI·재시도 자료와 뒤 버전의 모델 검증을 혼합하지 않으며, 실패·중단·미실행을 그대로 남깁니다.

### LEVEL 4 · 변경 범위와 증거 단위


22차의 변경 축은 작은 진행창의 이동·접기와 글자 미발견 뒤 재시도·대기 흐름입니다. 상태를 표현하는 UI와 탐지 실패 후 실행 제어를 구별하여 [21→22 전체 비교](../revision-audit/22차.md)의 실제 파일 변화로 검토합니다.

### LEVEL 4 · 공개 사본의 재현 경계


[공개 자료](../../22차/)는 일반 빌드 코드·원본 소스·합성 검사를 포함하며 도구와 빌드 위치를 상대경로/환경 설정으로 매개합니다. 기존 비공개 운영 환경을 공개 코드에 고정하지 않는 구조입니다. 서명키·운영 원문·장치 복원 스크립트·개인 보존 JSON·원APK의 제외/보류를 유지하고 파일별 원본 대응은 비공개 manifest로 관리합니다. 공개 소스의 추적 가능성과 배포·기기 환경의 완전 재현성을 동일시하지 않습니다.

### LEVEL 4 · 분모와 버전 경계


원195개 검사에서 71통과·1실패·123미실행을 보존하며 24시간 시험은 중단 상태입니다. **부분 실행과 완성 성능은 다른 주장**입니다. 별도 후속 선택 묶음은 실행되지 않았고 원195개의 잔여123개와 동일한 집합도 아닙니다. 집합 대응 없이 수를 합치거나 차감해 커버리지를 계산할 수 없습니다.

이 자료를 그 정책의 성능 근거로 쓰지 않으며, 후속 성공이 22차의 실패·미실행·장기 시험 중단을 해소한 것으로 기록하지 않습니다.

### LEVEL 4 · 바뀐 점·차이점

## LEVEL 5 - Expert
[바뀐 점·차이점](#reading-level-5-differences)


기존의 전체 설명·표·코드·함수 참조·파일별 비교는 아래에 그대로 이어집니다. [자료 폴더](../../22%EC%B0%A8) · [직전 비교·자료 범위](../revision-audit/22%EC%B0%A8.md) · [이 차수의 원래 전체 상세](#reading-level-5)

작은 진행창을 이동하고 상태를 접어 볼 수 있게 보강하며, 글자 미발견 뒤 재시도·대기 흐름을 유지했습니다. 실제 파일별 차이는 전체 비교에 기록했습니다.


현재 공개 사본은 일반 빌드 코드·원본 소스·합성 검사를 포함합니다. 빌드 위치와 도구는 상대경로·사용자 환경 설정으로 연결했습니다. 서명키·비공개 운영 원문·장치 복원 스크립트·개인 보존 JSON·원APK는 제외 또는 보류합니다. 공개 파일별 원본 대응은 별도 비공개 manifest로 추적합니다.

기기71통과·1실패·123미실행과24시간 시험 중단을 보존하며 완료 성능으로 해석하지 않습니다.

별도 후속 선택 묶음은 준비했지만 실제 실행하지 않았습니다. 이 묶음은 원195개 검사의 잔여123개와 같은 전체에서 센 수가 아닙니다.
