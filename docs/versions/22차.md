## LEVEL 1 - Beginner

### LEVEL 1 · 처음 읽는 분을 위한 동작과 결과

작은 진행창을 옮기고 상태를 접어 볼 수 있게 만든 차수입니다. 글자를 찾지 못했을 때 재시도·대기하는 흐름을 유지했습니다. 공개 사본은 일반 빌드 코드·원본 소스·합성 검사를 제공하며 서명키나 개인 저장 자료·원래 APK를 모두 제공하는 묶음은 아닙니다. 기기 검사 71통과·1실패·123미실행과 24시간 시험 중단을 그대로 남깁니다. 다음 23차의 시범 신경 정책이 여기서 이미 성공했다는 뜻은 아닙니다.

### LEVEL 1 · 이 자료의 세부 조건을 함께 읽기

작은 진행창을 이동하고 상태를 접어 볼 수 있게 보강하며, 글자 미발견 뒤 재시도·대기 흐름을 유지했습니다. 실제 파일별 차이는 전체 비교에 기록했습니다.

현재 공개 사본은 일반 빌드 코드·원본 소스·합성 검사를 포함합니다. 빌드 위치와 도구는 상대경로·사용자 환경 설정으로 연결했습니다. 서명키·비공개 운영 원문·장치 복원 스크립트·개인 보존 JSON·원APK는 제외 또는 보류합니다. 공개 파일별 원본 대응은 별도 비공개 manifest로 추적합니다.

기기71통과·1실패·123미실행과24시간 시험 중단을 보존하며 완료 성능으로 해석하지 않습니다. 이 차수는23차 시범 신경 정책의 성능 자료가 아닙니다.

별도 후속 선택 묶음은 준비했지만 실제 실행하지 않았습니다. 이 묶음은 원195개 검사의 잔여123개와 같은 전체에서 센 수가 아닙니다.

## LEVEL 2 - Explorer

### LEVEL 2 · 구성과 조건의 관계
