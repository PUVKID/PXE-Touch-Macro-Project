# 21차 · 진입 글자 확인과 새 글자로 시작

목록 글자를 눌러 들어간 화면에서 확인 글자를 읽고 매크로 실행 여부를 결정하도록 했습니다. 확인 글자가 없거나 설정한 다른 글자가 보이면 뒤로 가서 1순위부터 다시 찾습니다. 일시정지·계속 실행을 명확하게 표시하고, 실행 중 글자를 바꾸어 시작하면 새 설정으로 처음부터 실행합니다.

이전 실행의 늦은 OCR·창 조회·정리 처리가 새 실행의 상태를 덮지 않도록 실행 세대 경계를 보강했습니다. 기존 녹화·반복·새로고침·중복 방지·대상 보호를 유지합니다. 기존 네이티브 화면 배치를 유지하며 블랙·화이트와 파란 포인트색으로 공통 팔레트·선·조작 영역을 정리했습니다.
