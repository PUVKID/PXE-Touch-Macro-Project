### LEVEL 1 · 그림을 가르친다는 뜻

PXE의 기본 기능은 미리 정한 순서대로 글자를 찾고 화면을 누르는 **매크로**입니다. 24차는 선택형 AI에 글자 없는 아이콘도 가르치려는 변경입니다. AI는 처음에는 꺼져 있으며, 기존 매크로를 쓰는 데 켤 필요가 없습니다. 예를 들어 그림 버튼을 가르칠 때는 그때 보이는 글자와 화면의 색 배치, 사용자가 누른 그림 조각을 함께 기록합니다. 다시 실행할 때는 예전 좌표를 그대로 누르는 대신 **현재 화면에서 그림을 다시 찾은 위치**를 사용합니다. 같은 그림이 두 개 있어 구별하기 어렵거나 처음 보는 화면이면 누르지 않고 기다립니다.

OCR은 화면 사진의 글자를 읽는 기능입니다. RGB는 화면 색을 빨강·초록·파랑 값으로 나타내는 방법입니다. 정책 모델은 이 관측을 보고 가르친 행동 중 하나를 고르는 작은 신경망입니다. 사용자가 확인한 시범으로 가중치, 즉 행동 선택에 쓰는 내부 숫자를 바꿉니다. 화면을 저장했다는 사실만으로 학습이 끝난 것은 아닙니다. 이미지 선택, 글자 대기, 일반 동작 선택은 각각 다른 입력이므로 앞에서 선택한 이미지 모드가 다음 동작에 남지 않아야 합니다.

### LEVEL 1 · 예전 모델과 새 저장 파일

23차의 글자 모델은 584개의 입력값을 32개의 중간 노드를 거쳐 등록한 행동 수 K개의 선택값으로 바꿉니다. 이를 584→32→K라고 적습니다. 24차의 시각 정책은 글자와 이전 행동 등의 584개 값에 색 배치 576개를 더한 **1160개 입력**을 사용합니다. F64는 내부 숫자를 64비트로 저장한다는 뜻이며 정확도가 64%라는 뜻이 아닙니다. 구형 584차원 모델을 읽는 기능도 남깁니다.

새 모델은 v2 packed라는 묶음에 가중치뿐 아니라 시범, 행동 이름표, 난수 생성 상태와 학습 상태를 넣습니다. 난수 생성 상태는 학습의 다음 계산을 이어 가는 데 필요한 기록입니다. 파일 형식을 검사했더라도 다른 휴대전화에 가져와 파일 선택창으로 여는 과정까지 확인한 것은 아닙니다. 개인 시범·화면·모델은 비공개로 보관합니다.

### LEVEL 1 · 응답이 늦을 때 누르기를 반복하지 않기

화면 작업의 답이 늦으면 한 번 더 누르고 싶을 수 있지만, 첫 입력이 뒤늦게 실행되면 두 번 눌릴 수 있습니다. 그래서 일반 화면 작업의 5초와 제스처의 65초는 지연을 알리는 기준으로 쓰고 **처음 요청한 작업의 결과를 계속 기다립니다**. future는 이 결과를 받기 위한 대기표에 해당합니다. 새 대기표를 만들어 같은 터치를 다시 보내지 않습니다.

아직 실제 입력을 하지 않은 화면 캡처 준비는 다르게 처리합니다. 오래된 준비 작업을 취소하고 대기열에서 제거한 뒤 새 준비를 시도합니다. 이때도 정지, 권한 해제, 서비스 종료, 회전과 사용자가 정한 전체 실행 시간 제한을 확인합니다. 영원히 응답이 없는 기기를 반드시 복구한다는 약속은 아닙니다.

### LEVEL 1 · 검사 결과를 읽는 순서

먼저 빌드와 실제 기기 동작을 구분합니다. 빌드는 소스로 설치 파일을 만드는 과정입니다. 초기 기록에는 제품·Android 검사 앱·별도 시험 앱의 빌드, 단위 279개, Android 개발 도구로 확인한 컴파일, 린트 오류 0·경고 4가 있습니다. 린트는 코드의 문제 가능성을 찾는 검사입니다. 제어한 시간의 화면 작업 12개와 창 복원 5개도 확인했습니다. 뒤의 합성 회귀 추가로 단위 수가 280개가 된 결과와 초기 279개를 같은 실행으로 합치지 않습니다.

첫 Android 진단은 OCR 복구가 관측됐지만 시작 직후 정지 버튼을 찾는 단계에서 실패했습니다. 세 패키지의 원본 복원은 확인했습니다. 정지 버튼이 실제 나타날 때까지 정해진 시간 안에서 기다리도록 검사 준비를 고친 뒤 두 번째 첫 진단은 통과했습니다. 이것만으로 그림 학습이나 15회 반복 전체가 성공한 것은 아닙니다. 최신 결과는 아래의 별도 관측 절을 읽어야 합니다.

검사 코드의 JSON 예외 선언과 검사 함수의 예외 전달 부분도 고쳤습니다. 이는 기존 279개 검사의 입력·기대값·단언을 유지하면서 컴파일되도록 한 변경입니다. 실패 기록은 남습니다. 23차에서 첫 64회 학습 뒤 ZIP 저장 검사에 실패한 학습97과 후속 학습104 성공·원복은 **23차의 기록**입니다. 22차도 원래 195개 중 71통과·1실패·123미실행과 별도의 131개 미실행 묶음을 구분합니다.

### LEVEL 1 · 설치 파일과 남은 한계

공용 APK는 Android 설치 파일이며 버전은 24/2.4.0입니다. 크기는 **78,473,602바이트**, SHA-256 파일 지문은 `fa7250c7a5d7e3d1f2275782536ce32ebf95d2e240a3ce2d58bf0c6b0a154198`입니다. 기존 서명, ARM64와 x86_64 두 CPU 종류, 압축 파일 손상 검사인 CRC, 네트워크 권한 없음을 확인했습니다. Git 공개 파일 상한 64MiB보다 커서 설치 파일은 로컬 차수에 두고 공개 저장소에서는 재현 소스와 정보를 제공합니다.

이 행동 모델은 자유로운 한국어 명령을 모두 이해하는 LLM이 아닙니다. 과거 자연어 Transformer 실험은 64개 중 11개로 실패했습니다. 비율은 원값 17.1875%, 소수 첫째 자리 반올림 표시는 **17.2%**이며 언어모델 자산은 앱에 0개입니다. 모든 게임, 다른 설치, Android 파일 선택창(SAF), 24시간·1년 연속 운용을 확인한 결과가 아닙니다. 경량화도 검토만 했습니다.

[사용 안내](../../24차/사용안내.md)에서 준비와 조작을, [검증 기록](../../24차/검증_결과.md)에서 실행별 결과를 확인하실 수 있습니다. [전체 소스 비교](../revision-audit/24차.md)는 주석·공백까지 포함한 변경 확인용이며, [경량화 검토](../../24차/경량화_검토.md)는 실제 경량화 완료 보고가 아닙니다.

### LEVEL 2 · 화면 관측과 행동 선택의 연결

24차의 변경은 **무엇을 할지 고르는 정책**과 **지금 어디를 눌러도 되는지 확인하는 실행 경계**를 함께 읽어야 이해할 수 있습니다. 기존 매크로는 사용자가 정한 순서를 실행하며, 기본 꺼짐인 선택형 AI가 이를 대체하지 않습니다. 새 정책은 시범의 OCR 글자와 RGB 색 배치를 입력으로 받고 가르친 행동을 선택합니다. 선택이 이미지 터치라면 저장한 아이콘 외형 조각을 현재 화면에서 찾아 위치를 정합니다. 따라서 정책이 행동을 골랐다는 사실만으로 예전 좌표를 전달할 수는 없습니다.

글자만 다른 두 화면과 글자는 같지만 그림이 다른 두 화면은 구별해야 할 조건이 다릅니다. 1160차원 입력은 글자·이전 행동·상태를 담은 584차원과 RGB 배치 576차원을 결합합니다. 같은 그림이 중복되거나 새 화면이라 판단 근거가 부족하면 입력 없이 대기합니다. 이미지 선택 뒤 글자 대기나 일반 동작을 고를 때도 모드를 분리해야 이전 이미지 선택이 새 시범의 의미를 바꾸지 않습니다. 학습에 쓰는 것은 사용자가 확정한 시범이며, 시범 저장과 실제 가중치 갱신은 서로 다른 과정입니다.

### LEVEL 2 · 호환성과 이식은 다른 연결 단계

구형 글자 정책의 **584→32→K F64 MLP**는 584개 입력, 32개 중간 노드, K개 행동 출력을 가진 작은 신경망입니다. 새 시각 정책과 구형 모델을 같은 입력 형식으로 억지 해석하지 않고 구형 584차원 읽기를 유지합니다. 새 v2 packed 묶음은 F64 가중치와 시범·행동 사전·RNG·학습 상태를 함께 저장합니다. RNG는 난수 생성기의 상태로, 단순히 지금의 예측만 복제하는 것과 이어서 학습할 상태를 보존하는 것의 차이를 보여 줍니다.

여기에는 세 경계가 있습니다. 첫째는 바이트 형식이 맞는지, 둘째는 읽은 모델과 학습 상태가 맞는지, 셋째는 다른 설치의 파일 선택·가져오기와 실행이 되는지입니다. 저장 형식 검사 통과를 세 번째 단계까지의 실측으로 확대할 수 없습니다. 개인 시범·화면·모델은 이 연결을 설명하는 공개 예제로 복제하지 않습니다.

### LEVEL 2 · 늦은 응답에서 재시도를 나누는 이유

화면 작업은 요청 시점과 완료 시점이 다릅니다. 터치가 이미 전달됐는데 결과만 늦는 경우, 같은 요청을 다시 보내면 중복 동작이 됩니다. 그래서 UI 5초·제스처 65초는 **지연 관측 기준**으로 두고 원래 future에서 결과를 받습니다. future를 새로 만들어 다시 입력하는 방식이 아닙니다.

반대로 캡처 준비는 아직 입력이 없는 단계입니다. 오래된 준비 작업을 취소하고 큐에서 제거한 뒤 새 준비로 진행할 수 있습니다. 이 차이를 무시하고 모든 시간 초과를 동일하게 재시도하면 중복 입력과 작업 누적이 생길 수 있습니다. 정지·권한 해제·서비스 종료·회전·전체 실행 기한은 두 경로 모두에서 별도로 살아 있습니다. 기다림을 늘렸다는 사실이 이 중단 조건을 해제하지 않습니다.

### LEVEL 2 · 어떤 검사가 어느 연결을 확인했는가

초기 공개 원문은 공용 제품, Android 검사 APK와 별도 시험 앱의 빌드 통과를 기록합니다. 실제 Gradle 단위 279개와 SDK checked 컴파일은 코드·예외 경계의 근거이고, 린트 오류 0·경고 4는 정적 검사 결과입니다. 제어 시간의 UI 12개·창 복원 5개는 지연과 복원 분기의 근거입니다. 뒤의 단위 280개는 추가 회귀가 포함된 별도 시점이며 초기 279개를 수정한 수치가 아닙니다.

첫 Android 진단에서는 OCR 복구 관측 뒤 정지 버튼 조회가 실패했습니다. 세 패키지를 원복한 결과는 정리 성공을 뜻합니다. 검사에서 버튼의 실제 표시를 유한하게 기다리도록 바꾼 뒤 두 번째 첫 응답 진단이 통과했지만, 그때 나머지 검사는 진행 중이었습니다. 최신 결과는 별도 관측 절에서 갱신됩니다. **코드 검사→기기 일부 검사→전체 시각 학습 확인**은 같은 결론을 갖는 단계가 아닙니다.

JSON checked 예외 선언 오류와 검사 람다의 예외 전달은 컴파일 가능성의 문제였으며, 수정 때 기존 입력·기대·단언과 279개를 유지했습니다. 23차 학습97의 첫 64회 뒤 ZIP 실패와 후속104 성공·원복은 모델 저장과 학습 연결의 이전 버전 근거입니다. 22차의 195개 계획 중 71통과·1실패·123미실행, 별도 131개 미실행도 같은 분모로 더하지 않습니다.

### LEVEL 2 · 파일 배포와 주장 가능한 범위

24/2.4.0 공용 APK의 크기는 78,473,602바이트이고 파일 지문은 `fa7250c7a5d7e3d1f2275782536ce32ebf95d2e240a3ce2d58bf0c6b0a154198`입니다. 기존 서명·ARM64+x86_64·CRC·네트워크 권한 없음을 확인했습니다. Git의 이번 공개 파일 상한 64MiB를 넘으므로 로컬 차수 납품과 재현 소스 제공을 나눕니다. [사용 안내](../../24차/사용안내.md), [검증 기록](../../24차/검증_결과.md), [전체 비교](../revision-audit/24차.md), [경량화 검토](../../24차/경량화_검토.md)는 각각 사용 조건·관측·파일 변화·검토 범위의 연결점입니다.

행동을 고르는 MLP의 결과로 자유로운 한국어 이해를 평가할 수는 없습니다. 과거 Transformer 자연어 개발 평가는 **11/64 실패**, 원값 17.1875%, 반올림 표시 17.2%였고 언어모델 자산은 0개입니다. 다른 설치·SAF 파일 선택·모든 게임·24시간·1년 운용은 확인하지 않았습니다. 경량화는 검토 단계이므로 파일 크기 감소나 속도 향상을 주장하지 않습니다.

### LEVEL 3 · 사용할 버전과 자료부터 구분하기

24차를 확인할 때는 [사용 안내](../../24차/사용안내.md)와 [검증 기록](../../24차/검증_결과.md)을 먼저 함께 읽습니다. 일반 매크로가 주 기능이며 AI 기본값은 꺼짐입니다. 그림 학습을 시험하려면 선택형 AI의 시범 경로를 사용해야 합니다. 기존 글자 모델은 584→32→K F64 MLP이고, 시각 정책의 입력은 **1160차원 OCR+RGB**입니다. 구형 584차원 모델을 읽을 수 있다는 조건과 새 이미지 시범을 학습시키는 조건을 구분하십시오.

공용 파일 식별값은 버전 24/2.4.0, 78,473,602바이트, SHA-256 `fa7250c7a5d7e3d1f2275782536ce32ebf95d2e240a3ce2d58bf0c6b0a154198`입니다. 기존 서명·ARM64+x86_64·CRC·네트워크 권한 없음을 검사한 파일입니다. 이 크기는 64MiB 공개 상한보다 커 Git에 APK 자체를 넣지 않으며 로컬 차수 파일과 재현 소스를 제공합니다. [전체 소스 비교](../revision-audit/24차.md)로 변경 범위를 확인하고, [경량화 검토](../../24차/경량화_검토.md)를 이미 적용된 경량화로 읽지 마십시오.

### LEVEL 3 · 시범을 넣고 결과를 확인하는 순서

1. 가르칠 화면과 행동을 구분합니다. 그림 행동에서는 시범의 OCR·RGB 배치와 아이콘 외형 조각이 함께 근거가 됩니다. 글자 대기 또는 일반 동작을 선택한 경우 이전 이미지 모드가 남아 있지 않은지도 확인할 항목입니다.
2. 사용자가 확인한 시범으로 학습합니다. 파일 저장 여부만 보지 말고 정책 가중치 갱신을 별도 근거로 봅니다. 정책이 하는 일은 등록한 행동의 선택이며 OCR 엔진 자체의 재학습이나 범용 LLM 학습이 아닙니다.
3. 실행 때에는 **현재 화면에서 다시 찾은 위치**를 확인합니다. 시범 당시 좌표와 같다는 이유로 성공을 판단하지 않습니다. 같은 그림이 겹치거나 새 화면인 경우 입력 없이 기다리는 조건을 확인합니다.
4. 내보내기 자료는 v2 packed의 가중치·시범·행동 사전·RNG·학습 상태를 함께 봅니다. 저장 형식 검사 결과가 있어도 다른 설치에서 SAF 파일 선택과 가져오기를 실제로 했다는 기록이 없으면 이식 완료로 기록하지 않습니다.

개인 화면·시범·모델은 공개 결과 자료에 넣지 않습니다. 위 순서는 검토할 항목이며 이 문서를 읽는 사용자 환경에서 실제 시험을 마쳤다는 뜻은 아닙니다.

### LEVEL 3 · 지연과 정지를 판독하기

일반 UI의 5초와 제스처의 65초를 넘긴 경우, 지연 관측과 종료를 구분하십시오. 현재 설계는 원래 게시한 작업의 **동일 future**를 기다리며 터치·뒤로가기 등을 재전송하지 않습니다. 실제 입력이 이미 전달됐을 수 있으므로 응답을 받지 못했다는 사실만으로 새 입력을 보내면 안 됩니다.

입력 없는 캡처 준비는 오래된 작업 취소·큐 제거 뒤 새 준비로 확인합니다. 관측에서는 정지·권한 해제·서비스 종료·회전·전체 시간 제한이 여전히 적용되는지도 함께 확인합니다. 영구 무응답 환경의 자동 복구를 수락 기준 충족으로 추정하지 않습니다.

### LEVEL 3 · 검사 수를 버전과 시점에 붙여 읽기

초기 기록의 빌드는 공용 제품·Android 검사 앱·별도 시험 앱을 포함합니다. Gradle 단위 279개, SDK checked 컴파일, 린트 오류 0·경고 4, 제어된 UI 지연 12개와 창 복원 5개가 기록돼 있습니다. 합성 회귀 추가 뒤의 280개와 초기 279개는 다른 시점입니다. JSON 예외 선언과 람다 예외 경계 수정에서는 279개의 입력·기대값·단언을 유지했습니다.

기기 기록에서는 다음 세 사실을 따로 대조합니다. 첫 진단의 OCR 복구 긍정 관측, 실행 직후 정지 버튼 조회 실패, 원본 3패키지 복원입니다. 버튼 표시를 유한하게 기다리도록 검사 동기화를 고친 뒤 두 번째 첫 진단은 통과했습니다. 초기 원문의 진행 중 상태는 역사로 남기고 최신 관측 절과 함께 읽습니다. 이 일부 검사로 전체 그림 학습·15회 반복·기기 회귀 완료를 체크하지 않습니다.

이전 버전 비교도 분리합니다. 23차 학습97은 첫 64회 후 ZIP에서 실패했고 후속104는 성공·원복했습니다. 22차의 원195 기준 결과는 71통과·1실패·123미실행입니다. 별도 후속131묶음은 미실행으로 남습니다. 이를 현재24차의 통과 수에 합산하지 않습니다.

### LEVEL 3 · 보고할 수 있는 결과와 미확인 항목

관측한 행동 성공과 자연어 품질을 같은 성능으로 보고하지 마십시오. 과거 자연어 Transformer 개발 평가는 11/64, 원값17.1875%, 소수 첫째 자리 반올림 **17.2%**로 실패했고 언어모델 자산은 0개입니다. 구형 글자 MLP와 새 시각 정책은 범용 LLM이 아닙니다.

다른 설치·휴대전화 간 이동, SAF 실제 조작, 모든 게임, 24시간·1년 무오류 운용은 미검증입니다. 경량화도 실적이 없습니다. 파일이 생성되었다는 확인, 형식 검사, 실제 기기 행동, 환경 복원은 각각의 결과로 적고 최종 상태는 최신 관측과 독립 검토를 통해 판단해야 합니다.

### LEVEL 3 · 초기 APK 기록과 최종 확인 구분

### LEVEL 4 · 정책 입력과 실행 권한의 경계

24차는 OCR 글자만 쓰던 선택형 정책에 화면 외형을 추가합니다. 기존 584→32→K F64 MLP 읽기를 유지하면서 시각 정책은 OCR·이전 행동·상태 584차원과 RGB 배치 576차원을 결합한 **1160차원 입력**을 사용합니다. 기존 매크로가 주 경로이고 AI는 기본 꺼짐입니다. 새 정책의 존재가 일반 매크로 실행에 AI 사용을 요구하지 않습니다.

설계에서 구분할 출력은 행동 선택과 위치 결정입니다. 확정 시범으로 갱신한 정책이 이미지 행동을 선택해도 저장 좌표를 바로 실행하지 않습니다. 시범의 외형 조각을 현재 관측에서 다시 찾아 위치를 결정하며 중복 후보·낯선 화면은 무입력 대기로 처리합니다. OCR·RGB 배치·외형 조각의 역할을 합치면 ‘시범을 기억했다’는 상태가 ‘현재 입력을 승인했다’는 의미로 잘못 확장됩니다. 이미지·글자 대기·일반 동작 선택 사이의 모드 수명도 별도 경계입니다.

### LEVEL 4 · 모델 직렬화의 책임

v2 packed는 F64 가중치뿐 아니라 행동 사전, 시범, RNG와 학습 상태를 결합합니다. 예측 재현과 추가 학습 재개는 필요한 상태가 다르므로 가중치만의 왕복으로 전체 계약을 판단할 수 없습니다. 구형584 호환과 신규1160 정책을 각각 검사해야 하며, 파일 형식 검증은 다른 설치의 SAF 선택·가져오기·실행 프로토콜을 대신하지 않습니다. 개인 시범·화면·모델은 공개 소스와 분리합니다.

현재 행동 정책의 통과는 별도 자연어 Transformer의 실패를 변경하지 않습니다. 개발 평가11/64의 원비율은17.1875%, 반올림 표시는17.2%이며 언어모델 assets는0입니다. 두 과제의 입력·출력과 평가 분모가 달라 MLP 결과를 LLM 완성으로 승계할 수 없습니다.

### LEVEL 4 · 지연 정책의 상태 전이와 절충

UI5초·제스처65초를 종료 기준에서 지연 관측 기준으로 바꾸는 핵심은 **원요청의 정체성을 유지**하는 것입니다. 동일 future를 기다리면 뒤늦은 완료를 기존 요청의 결과로 받습니다. 전달 여부가 불확실한 입력을 재전송하는 정책은 중복 동작 가능성을 만들므로 사용하지 않습니다.

캡처 준비는 입력 없는 작업으로 분리돼 오래된 작업 취소·큐 제거 후 다시 시도합니다. 이 차이는 단순히 제한시간을 늘리는 것보다 중요한 재시도 경계입니다. 사용자 정지·권한 해제·서비스 종료·회전·전체 실행 기한은 계속 검사합니다. 영구 무응답에서 진행 보장은 없으며, 지연 지속과 사용자 중단 가능성을 함께 유지해야 합니다.

### LEVEL 4 · 평가 계층과 실패 이력

초기 공개 원문의 Gradle279개·SDK checked 컴파일·린트 오류0/경고4, 공용/검사/시험 앱 빌드는 빌드·정적 계층입니다. 제어된 UI12개와 창 복원5개는 가상 시간 및 경계 검사입니다. 후속 합성 회귀 추가로280개가 된 결과는 다른 소스 시점과 결합합니다. checked JSON 선언과 검사 람다 예외 경계 수정은 컴파일 책임의 보강이며 원입력·기대값·단언·279개를 유지했습니다.

실제 Android의 첫 진단은 OCR 복구를 관측한 뒤 정지 버튼 조회에서 실패했습니다. 버튼 표시를 유한하게 기다리는 검사 동기화 수정 후 두 번째 첫 진단은 통과했습니다. 초기 기록의 나머지 검사 진행 중 상태와 원본3패키지 복원은 각각 보존합니다. **복원 성공은 기능 성공의 증거가 아니며**, 일부 응답 검사 통과는 시각 학습·15회 반복·전체 회귀를 대체하지 않습니다. 최신 관측은 별도 절에 결합합니다.

23차 학습97의 첫64회 후 ZIP 실패와 후속104 성공·원복은 저장·학습 경로의 이전 버전 증거입니다. 22차 원195의71통과/1실패/123미실행과 후속131미실행도 다른 계획입니다. 과거 분모를 현재24차에 더하거나 성공한 후속 결과로 앞선 실패를 덮는 해석을 피합니다.

### LEVEL 4 · 산출물 식별과 확장 판단

공용 APK의 식별은 버전24/2.4.0,78,473,602바이트, SHA-256 `fa7250c7a5d7e3d1f2275782536ce32ebf95d2e240a3ce2d58bf0c6b0a154198`입니다. 기존 서명·ARM64+x86_64·CRC·네트워크 권한 없음을 확인했습니다. 파일당64MiB 공개 계약 때문에 APK는 로컬 차수에 보존하고 재현 소스를 공개합니다. 이 제한에 맞추기 위한 기능 삭제나 런타임 경량화를 실제 적용한 것은 아닙니다.

[전체 소스 비교](../revision-audit/24차.md)에서 기능·설정·주석·공백의 변경을 검토하고, [사용 안내](../../24차/사용안내.md)와 [검증 기록](../../24차/검증_결과.md)을 연결해야 배포 파일과 평가 버전을 혼동하지 않습니다. [경량화 검토](../../24차/경량화_검토.md)는 선택 검토 근거입니다. 다른 설치·SAF·모든 게임·24시간·1년 무오류는 미검증이며, 이식 형식이나 무네트워크 권한만으로 해당 운용 조건의 성공을 추론할 수 없습니다.

# 24차 · 화면 이미지 학습과 응답 복구

글자만으로 설명하기 어려운 그림·아이콘 동작을 직접 보여 주고, 현재 화면에서 다시 찾은 위치를 사용하도록 확장했습니다. 시범의 OCR·화면 RGB 배치와 아이콘 외형 조각을 보존하고 확정된 시범으로 가중치를 갱신합니다. 같은 그림이 겹치거나 새로운 화면이면 입력 없이 기다립니다. 이미지 선택·글자 대기·일반 동작 선택은 서로의 모드를 남기지 않도록 구분합니다.

기존584차원 글자 모델은 그대로 읽습니다. 새 시각 입력1160차원 정책의 F64 가중치와 시범·행동 사전·RNG·학습 상태를 v2 packed 형식으로 저장하고 이식할 수 있도록 구성했습니다. 저장 형식 검사는 실제 다른 설치의 파일 선택과 구분합니다.

일반 UI의5초와 제스처65초는 응답 지연을 표시하는 관측 기준으로 바꿨습니다. 원래 게시한 작업의 같은 future를 기다리고 이미 보낸 입력을 재전송하지 않습니다. 입력 없는 캡처 준비는 오래된 작업을 취소·큐에서 제거한 뒤 새 준비로 확인합니다. 사용자 정지·권한 해제·서비스 종료·회전과 전체 실행 시간 제한을 계속 확인합니다.

## 현재 관측과 남은 검사

로컬 공용 빌드와 Android 검사 APK·별도 시험 앱 빌드가 통과했습니다. 실제 Gradle 단위279개, SDK checked 컴파일, 린트 오류0·경고4와 제어된 시간의 UI12개·창 복원5개를 확인했습니다. 첫 실제 Android 진단은 OCR 복구의 긍정 관측이 있었지만 실행 직후 정지 버튼을 조회하는 단계에서 실패했고 원본3패키지 복원을 확인했습니다. 제어창의 실제 표시를 유한하게 기다리도록 검사만 고친 뒤 두 번째 실행의 첫 화면 응답 진단은 통과했습니다. 나머지 검사와 최종 원본 복원은 진행 중입니다. 이를 전체 시각 학습·15회 반복·실기 회귀 성공으로 확대하지 않으며 제어된 JVM 지연17개와 구분합니다.

공용 APK는78,473,602바이트, SHA-256 `fa7250c7a5d7e3d1f2275782536ce32ebf95d2e240a3ce2d58bf0c6b0a154198`입니다. 버전24/2.4.0·기존 서명·ARM64+x86_64·CRC·네트워크 권한 없음을 확인했습니다. 64MiB를 넘으므로 Git에 APK를 넣지 않고 로컬 차수 납품과 재현 소스를 제공합니다.

이전 빌드의 checked JSON 예외 선언 오류와 검사 람다 예외 경계를 고쳤습니다. 검사 입력·기대·단언과279개를 유지했습니다. 과거23차 학습97의 첫64회 후 ZIP 실패·후속 학습104 성공과 원복은 이전 버전 근거이며 새24차 Android 성공을 대신하지 않습니다. 22차 원195기준71통과/1실패/123미실행과 별도 후속131묶음 미실행도 보존합니다.

기존 매크로가 주 기능이고 AI는 기본 꺼짐입니다. 구형584→32→K F64 MLP와 새1160차원 OCR+RGB 시각 정책은 범용 LLM이 아닙니다. 과거 자연어 Transformer 개발 평가는11/64, 17.2%(소수 첫째 자리 반올림; 원값17.1875%)로 실패했고 언어모델 자산은 assets0입니다. 개인 시범·화면·모델은 공개하지 않습니다. 모든 게임·다른 설치·SAF 선택창·24시간·1년 무오류를 검증한 결과가 아닙니다. 경량화는 검토만 했습니다.
