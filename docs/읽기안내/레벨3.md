## 설정과 저장을 맞춰 적용하기

공용 APK는 ARM64 휴대전화와 x86_64 에뮬레이터용 코드를 함께 포함합니다. Android 11 이상에서 기존 앱을 삭제하지 않고 업데이트로 설치합니다. 기존 ID·서명을 유지하며 16차의 매크로 JSON, 목록 탐지 설정과 테마를 읽습니다. 별도 AI 시범·행동 모델을 가져오는 기능은 없습니다.

| 설정 | 적용 범위 | 선택 기준 |
| --- | --- | --- |
| 검색 방식 | 각 글자 동작·목록 탐지에서 각각 설정 | 이미지로 그린 게임 문구는 한글 OCR |
| 공백·대소문자·비교 방식 | 현재 글자 조건 | 정확한 문구면 일치, 일부면 포함 |
| 계속 기다리기 | 글자 터치·글자 대기 | 다음 화면이 나올 때까지 기다릴 때 켬 |
| 인식 후 추가 대기 생략 | 완료 후 지연·터치 전 재확인 | 빨라질 수 있지만 화면 변화를 고려 |
| 다음 글자에 맞춰 진행 | 인접한 호환 글자 조건 | 다음 글자의 사전 부재가 확인된 경우 대기 단축 |
| 개별 반복 / 탐지 반복 | 한 동작 / 저장 매크로 전체 | 3회 동작과 전체 15회를 곱하지 않도록 확인 |
| 재시도·뒤로·스크롤 | 글자가 없는 유한 검색 | 횟수와 초를 정하고 종료 정책 확인 |
| 우선 영역·중복·복귀·새로고침 | 목록 탐지 | 동일 문구를 다시 실행할 조건을 정함 |

### 설정을 적용하는 순서

| 구분 | 적용 내용 |
| --- | --- |
| **영역·미리보기** | 처음에는 한 영역에서 인식 미리보기로 확인하고 녹화합니다. |
| **저장·낮은 반복 확인** | 이름으로 저장한 매크로를 선택해 낮은 반복으로 순서를 확인한 뒤 목표 횟수로 적용하세요. |
| **편집본과 저장본** | 수정한 현재 편집본이 탐지용 별도 저장본에 자동 반영되는 것은 아니므로 같은 이름으로 다시 저장해야 합니다. |
| **실행 상태 제어** | 정지·일시정지와 재개, 진행 표시와 오류 기록을 함께 사용합니다. |

### 재현 환경과 자료 경계

| 구분 | 적용 내용 |
| --- | --- |
| **빌드 도구** | 빌드는 JDK 17·Gradle 8.13·SDK 35를 사용하고 기존 개인 서명이 필요합니다. |
| **일반 폴더 사용** | 실제 일반 폴더의 빌드 사본을 사용하며 폴더 연결을 만들지 않습니다. |
| **경로 확인** | 소스의 빌드 안내와 Python 경로 인자를 확인합니다. |
| **비공개 제외** | 개인 키와 실행 원문은 공개·패키지에 넣지 않습니다. |
| **전용 기기 제한** | 기기 검사는 전용 장치 이름·설치 버전·서버를 확인한 도구로 제한합니다. |

현재 제품은 **26차 · 2.6.0**입니다. 단위 106개와 최종 축소 APK 기기 검사 89개를 확인했습니다. 오류·취소·보존·미확인 범위는 [검증 결과](../../26차/검증_결과.md)에 구분합니다.

## 바뀐 점·차이점

16차 기반으로 UI·기본 매크로를 유지하며 Unicode 공백 비교·느린 창 조회·미사용 코드 축소를 보강했습니다. 별도 AI 학습 기능은 포함하지 않습니다. [24차 같은 수준 설명](../../24차/읽기안내/레벨3.md)과 [26차 전체 비교](../revision-audit/26차.md)에서 차이를 확인합니다.
