현재 제품은 **24차·2.4.0**입니다. [설치·사용 안내](../../최종/사용안내.md)와 [최종 파일](../../최종/README.md#reading-level-3)을 확인하실 수 있습니다.

## LEVEL 3 · 사용할 버전과 자료부터 구분하기

24차를 확인할 때는 [사용 안내](../../24차/사용안내.md)와 [검증 기록](../../24차/검증_결과.md)을 먼저 함께 읽습니다.

일반 매크로가 주 기능이며 AI 기본 값은 꺼짐입니다.

그림 학습을 시험하려면 선택형 AI의 시범 경로를 사용해야 합니다.

기존 글자 모델은 584 →32 →K F64 MLP이고, 시각 정책의 입력은 **1160차원 OCR +RGB**입니다.

구형 584차원 모델을 읽을 수 있다는 조건과 새 이미지 시범을 학습시키는 조건을 구분하십시오.

현재 공용 파일은 **버전 24 / 2.4.0**입니다. 최종 크기와 SHA-256은 [24차 검증 결과](../../24차/검증_결과.md)의 최종 파일 표를 따릅니다. ARM64와 x86_64를 지원하며 인터넷 권한 없이 동작합니다.

## LEVEL 3 · 시범을 넣고 결과를 확인하는 순서

1. 가르칠 화면과 행동을 구분합니다. 그림 행동에서는 시범의 OCR·RGB 배치와 아이콘 외형 조각이 함께 근거가 됩니다. 글자 대기 또는 일반 동작을 선택한 경우 이전 이미지 모드가 남아 있지 않은지도 확인할 항목입니다.
2. 사용자가 확인한 시범으로 학습합니다. 파일 저장 여부만 보지 말고 정책 가중치 갱신을 별도 근거로 봅니다. 정책이 하는 일은 등록한 행동의 선택이며 OCR 엔진 자체의 재학습이나 범용 LLM 학습이 아닙니다.
3. 실행 때에는 **현재 화면에서 다시 찾은 위치**를 확인합니다. 시범 당시 좌표와 같다는 이유로 성공을 판단하지 않습니다. 같은 그림이 겹치거나 새 화면인 경우 입력 없이 기다리는 조건을 확인합니다.
4. 내보내기 자료는 v2 packed의 가중치·시범·행동 사전·RNG·학습 상태를 함께 봅니다. 저장 형식 검사 결과가 있어도 다른 설치에서 SAF 파일 선택과 가져오기를 실제로 했다는 기록이 없으면 이식 완료로 기록하지 않습니다.

개인 화면·시범·모델은 공개 결과 자료에 넣지 않습니다. 위 순서는 검토할 항목이며 이 문서를 읽는 사용자 환경에서 실제 시험을 마쳤다는 뜻은 아닙니다.


## LEVEL 3 · 지연과 정지를 판독하기

일반 UI의 5초와 제스처의 65초를 넘긴 경우, 지연 관측과 종료를 구분하십시오. 현재 설계는 원래 게시한 작업의 **동일 future**를 기다리며 터치·뒤로가기 등을 재전송하지 않습니다. 실제 입력이 이미 전달됐을 수 있으므로 응답을 받지 못했다는 사실만으로 새 입력을 보내면 안 됩니다.

입력 없는 캡처 준비는 오래된 작업 취소·큐 제거 뒤 새 준비로 확인합니다. 관측에서는 정지·권한 해제·서비스 종료·회전·전체 시간 제한이 여전히 적용되는지도 함께 확인합니다. 영구 무응답 환경의 자동 복구를 수락 기준 충족으로 추정하지 않습니다.

## 확인한 결과

단위 검사 280개와 전용 기능 1개·시 각 2개를 확인했습니다. 기능 검사의 동작 15회는 한 Watch 사이클이며 전체 매크로 15 사이클을 뜻하지 않습니다. 최종 APK 지문과 실제 시험의 적용 범위는 [24차 검증 결과](../../24차/검증_결과.md)에 한 번만 정리했습니다.
