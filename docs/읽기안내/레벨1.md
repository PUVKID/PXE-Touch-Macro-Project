## 직접 정한 순서대로 글자를 찾고 누르기

PXE는 화면의 글자를 읽고 사용자가 만든 순서대로 터치·스크롤·뒤로가기를 실행하는 앱입니다. 이번 26차는 **16차의 화면과 일반 매크로**를 기준으로 합니다. 사용자가 시범을 보여 주며 행동을 학습시키는 별도 AI는 포함하지 않습니다. OCR은 화면 사진에서 글자를 읽는 기능이며 계속 필요하므로 앱 안에 유지했습니다. 인터넷 연결이 없어도 사용할 수 있습니다.

| 설정할 것 | 실제 동작 | 주의할 점 |
| --- | --- | --- |
| 글자와 네모 영역 | 지정한 영역에서 문구를 찾아 누릅니다. | 비슷한 문구와 다른 버튼을 영역에서 줄입니다. |
| 녹화 또는 동작 목록 | 저장한 순서대로 터치·대기·뒤로가기를 실행합니다. | 이름으로 저장한 매크로와 편집 중인 매크로는 구분합니다. |
| 반복 횟수 | 탐지한 항목에 들어가 저장 매크로를 지정 횟수 실행합니다. | 동작 하나의 반복과 전체 매크로 반복은 다릅니다. |
| 글자가 없을 때 | 기다리거나, 뒤로가기·스크롤 뒤 다시 찾습니다. | 계속 기다리기와 횟수가 있는 재시도는 다른 설정입니다. |
| 우선 영역과 새로고침 | 최대 6개 영역을 순서대로 확인하고 완료 후 다시 탐지합니다. | 같은 문구 중복 방지는 별도 설정입니다. |

### 설치에서 저장까지

| 구분 | 적용 내용 |
| --- | --- |
| **업데이트·권한** | 공용 APK를 기존 앱 위에 업데이트로 설치하고 권한 안내를 따릅니다. |
| **안내 순서** | 찾을 글자 → 탐지 영역 → 매크로 녹화 → 시간·반복 설정 → 실행 준비 순으로 안내 화면을 따라가세요. |
| **게임 인식** | 게임처럼 글자가 이미지로 그려지는 화면은 한글 OCR을 선택합니다. |
| **저장본 반영** | 이름으로 저장한 매크로를 수정했다면 같은 이름으로 다시 저장하고 탐지에서 그 이름을 선택해야 합니다. |

### 다음 글자와 속도 설정

| 구분 | 적용 내용 |
| --- | --- |
| **계속 기다리기** | 다음 버튼을 기다리고 싶다면 해당 글자 동작에서 ‘글자가 나타날 때까지 계속 기다리기’를 켭니다. |
| **부재 처리** | 글자가 없다는 이유로 멈추거나 바로 뒤로가지는 않습니다. |
| **빠른 옵션의 조건** | 인식 후 추가 대기 생략은 빠른 옵션이지만 터치 전 재확인도 생략하므로 정확도를 우선하면 꺼 두세요. |
| **적응 대기** | 서로 이어지는 글자 조건에는 ‘다음 글자에 맞춰 진행’ 옵션을 사용할 수 있습니다. |

### 다른 화면일 때 돌아오기

| 구분 | 적용 내용 |
| --- | --- |
| **조건 분기** | 다른 화면에 들어갔을 때는 확인할 글자를 조건 분기에 넣고, 없으면 뒤로가기 동작으로 이동한 뒤 처음 찾기로 이어지게 구성합니다. |
| **재시도 종료** | 유한 재시도 횟수를 모두 써도 없으면 중단하는 정책은 유지합니다. |
| **오류와 글자 부재** | 화면을 읽을 수 없다는 오류와 실제로 글자가 없는 상황은 다릅니다. |

## 바뀐 점·차이점

16차 기반으로 UI·기본 매크로를 유지하며 Unicode 공백 비교·느린 창 조회·미사용 코드 축소를 보강했습니다. 별도 AI 학습 기능은 포함하지 않습니다. [24차 같은 수준 설명](../../24차/읽기안내/레벨1.md)과 [26차 전체 비교](../revision-audit/26차.md)에서 차이를 확인합니다.
