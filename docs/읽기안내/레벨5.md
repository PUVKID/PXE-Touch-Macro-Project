## LEVEL 5 · 실행 계약과 인과 해석

Macro·Step의 JSON 입력·좌표·영역·반복·재검색·실패 정책 검증은 실행의 전제입니다. 단일 조회·캡처 요청 수명·OCR Task·비트맵 수명과 세대·대상·창·내용·설정·모델 확인은 늦은 응답 재사용을 막기 위한 경계입니다. 사용자 정지·권한 해제·서비스 종료·전체 시간 제한은 지연 대기와 병존합니다. 관측 상태를 읽는 순서와 실제 guard 평가 사이 동시 변경 가능성을 고려하며, 고정 카운터나 스택만으로 정확한 원인을 단정하지 않습니다.
