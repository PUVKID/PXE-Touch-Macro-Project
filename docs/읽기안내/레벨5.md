## 최종 소스·파일·실행 근거 대조

26차는 16차를 구현 기준으로 선택했고 직전 제품과의 전체 비교도 별도로 남깁니다. 이전 차수의 성능·검사 수를 26차의 결과로 합치지 않습니다. 16차 선택 소스의 보존 해시, 실제 빌드 사본과 기준 소스의 동일성, 버전·ABI·인증서·ZIP CRC와 내장 OCR 자산을 확인했습니다.

| 근거 | 확인 대상 | 해석의 범위 |
| --- | --- | --- |
| 단위·린트 | 비교 규칙·모델·영역·중복·시간·실행 상태·제품 코드 | 기기 동작 전체의 대체가 아님 |
| 실제 축소 APK 기기 검사 | 오프라인 OCR·영역·대기·지연 복구·반복·UI·제어 | 전용 Android 12 가상 장치 |
| 실제 업데이트 | 16차 설정 저장 → 26차 설치 → 설정 대조 | 앱 ID·개인 서명·저장 구조 유지 |
| 전체 비교·소스 | 추가·수정·삭제, 주석·공백·개발 도구 | 공개 가능한 코드 원문 전체 |
| 바이너리 정보 | 공용 APK 크기·SHA-256·두 ABI·기존 서명 | 크기 감소가 속도·인식률 수치는 아님 |

### 발견한 문제와 최종 수리

| 구분 | 적용 내용 |
| --- | --- |
| SDK 공개 API | 초기 축소에서 검사 연결용 SDK 클래스·공개 메서드가 없어지는 문제를 실제 실행으로 발견하고 공개 API 보존 규칙으로 해결했습니다. |
| 유한 대기 회귀 | 유한 글자 동작 전체에 절대 시한을 적용했던 중간 회귀도 제거했습니다. |
| 최종 제한 범위 | 최종 구현은 실제 창 조회 대기만 제한하고 정상 OCR 결과는 기존 정책대로 처리합니다. |
| 실패 원문 보존 | 실패 원문·호스트 Java 내부 오류·독립 검토의 앞선 FAIL은 비공개 작업 이력에 유지했습니다. |

### 결과를 대조하는 방법

| 구분 | 적용 내용 |
| --- | --- |
| 검사 범위 구분 | [검증 결과](../../26차/검증_결과.md)는 검사 묶음별 개수·시간과 기능별 직접 실행·코드 보존·미확인 외부 환경을 구분합니다. |
| 파일 지문 대조 | [파일 정보](../../26차/파일정보.json)의 지문과 로컬 납품 APK를 대조할 수 있습니다. |
| 미측정 성과 제외 | 새로 측정하지 않은 실제 게임 15회 속도, 일반적인 99% 정확도, 6개 동시 운용과 장기 연속 운용을 성과로 주장하지 않습니다. |
