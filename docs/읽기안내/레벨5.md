<a id="reading-level-5"></a>## LEVEL 5 · 구현·재현·증거 한계

28차 2.8.3은 기존 기능을 유지하면서 내부 화면과 화면 위 창의 색상·간격·로고를 통일한 수정본입니다. 밝은 화면은 연회색 바탕과 흰 카드, 어두운 화면은 짙은 회색 바탕과 카드로 구분하고 파란색은 주요 동작·선택 상태에 사용합니다.

| 디자인 요소 | 현재 기준 | 적용 범위 |
|---|---|---|
| 색상 | 라이트 #F6F7F9 / 흰 카드, 다크 #101216 / #1A1D24 카드 | 앱·입력·팝업·화면 위 창 |
| 포인트 | 라이트 #245CE2 / 다크 #90B4FF | 실행·선택·포커스·체크박스 |
| 글자 | 나눔고딕700, 제목24sp·주요 입력22~23sp·본문14sp | 큰 제목 축소·설명 대비·줄 간격 |
| 선·모서리 | 1dp 구분선, 입력/버튼12dp·카드14~16dp | 행·폼·팝업·탐지 영역 선택 |
| 로고 | 파란 사각형과 흰 P | 런처·헤더·접힌 단축창·알림(단색) |
| 작은 진행 창 | 1/15와 화살표, 드래그·글자 변경·단축키 유지 | 하단 일시정지/정지 없음 |

현재 제품은 입력한 글자와 인식 결과의 원문 완전 일치만 사용합니다. `Adobe`와 `어도비`, `ADOBE`, `Adobe Pro`, 앞뒤 공백이 붙은 문구는 서로 다릅니다. 저장된 포함·정규식·공백/대소문자 무시 옵션도 실행 시 적용하지 않습니다. OCR은 낱말 일부 대신 한 줄 전체를 비교하고, 화면 정보는 접근성 설명(contentDescription) 대신 text만 비교합니다. text를 제공하지 않는 화면은 OCR을 사용하세요. OCR이 잘못 읽은 글자 자체를 완벽히 구별한다고 보장하는 기능은 아닙니다.

| 기능 | 현재 동작 | 설정·경계 |
|---|---|---|
| 일반 매크로 | 녹화·터치·스와이프·곡선·멀티터치·대기·뒤로가기·분기·반복 | 저장한 순서·동작별 반복과 전체 반복 구분 |
| 글자 인식 | 내장 한글 OCR·화면 정보·자동 선택 | Adobe와 어도비를 번역해 같은 글자로 바꾸지 않음 |
| 목록 탐지 | 최대 6개 우선 영역에서 찾고 진입 → 등록 매크로 15회 → 복귀 | 반복·우선 영역·복귀·완료 후 대기·새로고침 시간 사용자 설정 |
| 중복 방지 | 설정한 재등장 조건과 저장된 잠금 유지 | 글자를 못 읽은 오류와 실제 부재를 구분 |
| 실행 제어 | 앱과 상단 단축창에서 일시정지·계속 실행·정지 | 하단 진행 위젯에는 해당 버튼 없음 |
| 글자 단축키 | 등록·중복 억제·삭제·가로 목록 | 최대 30개, 글자·탐지 탭과 펼친 하단 위젯 공유 |
| 저장·화면 | 매크로 가져오기/내보내기·테마·위젯 위치와 불투명도 | 앱을 삭제하지 않고 업데이트, 중요한 원본은 먼저 내보내기 |

| 수정 | 2.8.3 구현 | 유지한 부분 |
|---|---|---|
| 자동 이동 | 목록 하강·미인식 재시도 0.9초·화면 높이 22.5% 이동 | 아래로 당겨 새로고침은 거리 45%·시간 0.9초, 녹화 제스처는 저장값 그대로 |
| 내부 디자인 | 26차의 단순한 행·구분선 기반, 동작 설명 전체 폭·입력/선택/팝업 간격 | 흑백·블루·나눔고딕700·라이트/다크 저장 |
| 하단 편집 | 1/15 옆 화살표 → 글자 변경 → 적용 | 숫자 드래그·위치 저장·바깥 화면 터치 |
| 빠른 글자 전환 | 가로 단축키를 누르면 첫 탐지 글자와 단독 글자 설정을 함께 저장 | 실행 중 탐지/단독 글자는 처음부터 새 실행, 일반 매크로 목록 자체는 변경하지 않음 |
| 화면 조회 경합 | 글자 교체 직후 이전 조회가 끝날 때까지 취소 가능한 대기 | 조회를 누적하지 않음·실제 미응답 경계·늦은 결과 폐기 유지 |
| 작은 진행 창 | 접힘 104×44dp, 펼침 너비 280dp·진행/시간/글자/단축키 | 하단 일시정지·정지 제거, 상단과 앱 제어 유지 |

Macro·CapturePacer의 기존 정의는 보존합니다. Step은 완전 일치 표시와 구형 정규식 검증 경계를 수정했습니다. WatchConfig는 자동 SCROLL_DOWN 끝점이 바뀌었으므로 네 파일 모두가 16/26차와 동일하다는 이전 설명은 현재 적용하지 않습니다. 캡처 간격(API30 1100ms/API31+ 500ms), 캡처/OCR 동시 작업 제한, 백오프와 늦은 응답 폐기 경로는 변경하지 않습니다.

자동 이동은 ScrollMotion.DURATION_MS=900과 START_Y=75, END_Y=52.5를 실제 목록 하강·미인식 재시도 제스처에 연결했습니다. PULL_DOWN은 30→75로 유지합니다. 녹화 SWIPE/GESTURE는 기존 Step의 duration/경로를 사용하는 실행 분기를 유지합니다. 실제 터치 DOWN/UP과 이동 거리를 별도 기기 검사로 확인합니다. 상수 단위 검사만으로 사용감을 검증했다고 확대하지 않습니다.

검사 환경은 전용 Android12/API31 x86_64 AVD, ADB5047이며 사용자 블루스택·게임과 기본 ADB 서버는 조작하지 않습니다. 단위·린트·기기 결과, 실제 화면과 최종 바이너리의 크기/SHA-256은 검증 결과와 파일정보에 연결합니다. 초기 실패·수정·검사 준비 오류와 중간 실행 종료는 보존하며 다른 실행의 시간을 합산하지 않습니다.

Rust는 Windows 색상 생성기를 빌드 시 실제 호출하는 범위이며 Android OCR 엔진의 Rust 전환이 아닙니다. Graphify는 로컬 Java AST 관계 조사에 사용하며 그래프 수를 속도·정확도로 환산하지 않습니다. 모든 기능의 미래 무오류·수년 무중단·99% 인식률·사용자 게임의 완료 시간을 보장하지 않습니다.

현재 검사 결과와 APK/ZIP 지문은 [검증 결과](../../28차/검증_결과.md)와 [파일정보](../../28차/파일정보.json)를 따릅니다. 장기 무중단·모든 기기 무오류·게임의 15회 완료 시간은 측정하지 않았습니다.

### LEVEL 5 · 변경 조건과 구현 근거

| 확인 축 | 27차 내용 | 검토 기준 |
| --- | --- | --- |
| 기능 기반 | 16차 기반 일반 매크로·직전 차수 기능 유지 | OCR·영역·반복·중복·대기·취소·저장·제어 보존 |
| 캡처 시간 | 숨김 안정화와 pacer 대기를 겹치는 순서 | 숨김 150ms 및 API별 1100/500ms 간격 모두 유지 |
| 입력 품질 | 전체 화면 OCR·기존 모델 | ROI 자르기·다운샘플링·새 의존성 없음 |
| UI 범위 | Ui·RunHud·컨트롤·메인 화면 등 UI 8개 파일의 팔레트·중복 문구·간격·선택 표시 | 기능 삭제·실행 흐름 변경 없음 |
| 배포 묶음 | 최종 APK·소스·안내·전체 비교 | 최종 지문·버전·ABI·서명은 확정 결과와 대조 |

라이트 강조색은 `#365F9D`, 다크 강조색은 `#A9C7F5`입니다. 카드 안쪽 세로 여백은 14dp에서 16dp, 모서리는 8dp에서 10dp, 바깥 위·아래 여백은 4/6dp에서 6/8dp로 조정했습니다. RunHud 보조 정보 위에 5dp 간격을 두었습니다. 기존 화면 구성·나눔고딕 Bold와 밝고 어두운 테마 선택을 유지합니다.

`Ui.textIfChanged`는 현재 표시된 문구와 새 문구를 비교해 다를 때만 설정합니다. RunHud의 두 문구와 FloatingController의 상태·재생 문구에 적용하며, MainActivity의 기존 변경 비교도 공통 함수로 모았습니다. 재생 버튼의 접근성 설명과 RunHud의 표시 상태도 같은 값의 재설정을 피합니다. 이런 UI 변경에 별도 성능 개선 수치를 부여하지 않습니다.

### LEVEL 5 · 직전 26차와 직접 비교

| 항목 | 직전 26차 | 27차 |

| 별도 비교용 OCR 실행 | 같은 장치·새 데이터·15회×5구간 75회 성공, 구간 합 50.965초 | 같은 조건 75회 성공, 구간 합 45.260초 |
| 연속 운용 | 이번 27차의 장기 검사 근거로 전용하지 않음 | 남은 호스트 표본의 누적 54.5분·247바퀴, 호스트 재부팅으로 최종 판정 미완료 |

초기 예비 기록의 60.172초는 직전 제품의 반복 검사 전체 시간이며 당시 호스트 제품 빌드와 겹쳤습니다. 이 예비값은 위 별도 비교에 섞지 않았습니다. 구간 합은 반복 동작 경과이며 순수 OCR 엔진 시간이나 JUnit 전체 시간이 아닙니다. 이전 차수 자체의 설명과 근거는 [26차 상세](../versions/26차.md#user-content-reading-level-5)에 보존합니다.

### LEVEL 5 · 평가와 재현 시 구분할 항목

| 검사 묶음 | 필요한 기록 | 현재 상태 |
| --- | --- | --- |
| 빌드·단위·린트 | 최종 소스·도구·실제 명령·종료 코드·검사 수 | APK 빌드·단위 106개 통과·린트 오류 0·경고 0 |
| 속도 비교 | 같은 가상 장치 API31·새 앱 데이터·Adobe·15회×5구간 | 5구간 전체 평균 11.2% 감소. 순차 실행·호스트 타 작업 영향은 남음 |
| 실제 UI | 검사 메서드 1개·화면 6개·문구 갱신 콜백 | 통과: 같은 값 40회 갱신 시 콜백 1회, 변경 뒤 2회 |
| 캡처 복구 | 실제 캡처 복구 검사 메서드 3개 | 3개 통과 |
| 그 밖의 기기 기능 | OCR·대기·반복·복귀·취소·업데이트 설정 보존 | 위 검사 결과로 전체 통과를 대신하지 않으며 결과 문서에서 구분 |
| 60분 연속 운용 | 장치 바퀴별 원문 복구 0·호스트 54행·부재한 종료 근거 구분 | 장치 3,271,842ms·247바퀴·3,705회. 최종 판정 미완료, 오류 기록 상태는 검증 결과 참조 |
| 납품 일치 | APK 크기·SHA-256·앱 ID·버전·ABI·서명·소스와 빌드 사본 | 최종 APK 32,718,470바이트·아래 SHA-256 확인, 나머지 세부 근거는 결과 문서와 대조 |

최종 APK의 SHA-256은 `a6ce7b3aa3889117a790e0cab33dd6c659253fe010bfa2d625d7222a4dcc85a8`입니다. 실제 UI 검사에서 같은 값 40회 갱신의 문구 콜백은 최초 1회였고, 문구를 바꾸자 누적 2회가 되었습니다. 이는 동일 문구 재설정 방지의 동작 근거이며 전체 속도 향상률은 아닙니다.

호스트 빌드와 겹친 초기 예비 속도값은 최종 비교 수치로 사용하지 않습니다. 같은 장치에서 제품 빌드 없이 별도 속도 비교를 끝냈습니다. 중단된 연속 검사와 새 실행 시간을 합산하지 않았으며 원래 60분 성공 기준도 변경하지 않았습니다. 남은 호스트 원값·메모리 표본·원문 복구 실패·최종 미확인 항목은 검증 결과에서 구분합니다.

단위·정적 검사는 실제 기기 동작의 대체가 아닙니다. 60분 검사는 같은 실행의 연속성을 확인하는 유한 관측이며 재시작을 숨긴 채 같은 실행으로 합치지 않습니다. 사용자의 블루스택 대신 전용 검사 장치를 사용합니다. 성능 향상률·장기 무중단·모든 게임의 인식률은 결과 없이 주장하지 않습니다.

최종 결과와 남은 한계는 [검증 결과](../../27차/검증_결과.md)에, 납품 파일의 지문은 [파일 정보](../../27차/파일정보.json)에 연결합니다. 공개 가능한 코드의 주석·공백을 포함한 실제 차이는 [전체 비교](../revision-audit/27차.md)에서 확인합니다. 문서 저장 자체를 실제 검사나 원격 게시의 증거로 사용하지 않습니다.

## 최종 소스·파일·실행 근거 대조

26차는 16차를 구현 기준으로 선택했고 직전 제품과의 전체 비교도 별도로 남깁니다. 이전 차수의 성능·검사 수를 26차의 결과로 합치지 않습니다. 16차 선택 소스의 보존 해시, 실제 빌드 사본과 기준 소스의 동일성, 버전·ABI·인증서·ZIP CRC와 내장 OCR 자산을 확인했습니다.

| 근거 | 확인 대상 | 해석의 범위 |
| --- | --- | --- |
| 단위·린트 | 비교 규칙·모델·영역·중복·시간·실행 상태·제품 코드 | 기기 동작 전체의 대체가 아님 |
| 실제 축소 APK 기기 검사 | 오프라인 OCR·영역·대기·지연 복구·반복·UI·제어 | 전용 Android 12 가상 장치 |
| 실제 업데이트 | 16차 설정 저장 → 26차 설치 → 설정 대조 | 앱 ID·개인 서명·저장 구조 유지 |
| 전체 비교·소스 | 추가·수정·삭제, 주석·공백·개발 도구 | 공개 가능한 코드 원문 전체 |
| 바이너리 정보 | 공용 APK 크기·SHA-256·두 ABI·기존 서명 | 크기 감소가 속도·인식률 수치는 아님 |
