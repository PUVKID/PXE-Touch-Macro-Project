NEX 6차 v6.0.0 검증 결과

최종 적용 방식
- 직접 그린 네모 영역 1~6순위. 매번 1순위부터 확인하여 처음 글자가 있는 영역을 실행.
- 1순위가 없고 2순위에 있으면 2순위 실행. 완료 후 대기 중에는 재실행 금지.
- 기본 10분 대기 후 첫 새로고침. 이후 글자가 없으면 기본 10초마다 새로고침.
- 새로고침 후 같은 2순위에 같은 글자가 있어도 다시 실행.
- 기본 흐름에서는 글자가 사라져야만 재실행하는 모드를 사용하지 않음.

빌드 / 정적 검사
- versionCode 6, versionName 6.0.0, Android 11 이상.
- 휴대전화 APK: arm64-v8a.
- PC APK: arm64-v8a + x86_64. Android 12 x86_64 가상 기기에 실제 릴리스 APK 설치/첫 안내 실행 확인.
- 두 APK 모두 기존 앱과 같은 개인 서명 인증서 확인.
- 단위 검사 58개 통과. Android Lint: No issues found.

Android 12 가상 기기 통합 검사 6개 통과
1. 안내: 실제 글자 입력 → 화면 영역 그리기 → 안내 복귀 → 터치 녹화/재생 → 이름을 붙여 저장 → 단계별 초 입력 → 실행 준비.
   원래 편집하던 매크로 보존 확인.
2. 우선순위: 직접 정한 아래쪽 1순위 / 위쪽 2순위. 1순위 없을 때 2순위 실행, 대기 전 재실행 차단,
   새로고침 후 같은 2순위 재실행, 이후 1순위가 나타나면 1순위를 우선 실행.
3. 개별 반복: 동작 A=3회, B=1회, 전체=2회. 실제 터치 순서 AAABAAAB, A 6회 / B 2회 확인.
4. 전체 반복: 저장본 전체 반복도 15인 상황에서 탐지 설정의 정확한 15회만 실행 (225회로 곱하지 않음).
5. 한글 OCR / 검색 영역 / 자동 뒤로가기 / 새로고침 / 일시정지 / 정지 / 오류 중단 검사.
6. 추가 옵션인 사라짐 확인 모드의 차단과 재실행 상태 저장 검사. 기본 흐름은 이 옵션을 끈 상태임.

마지막 화면 정리 후 안내 흐름을 별도로 다시 검사하여 통과.
분/추가 초 입력으로 10분이 실제 600000 내부 시간으로 저장되는 것 확인.
10분을 실제로 모두 기다리는 장시간 검사는 하지 않았으며, 동일한 대기 로직의 짧은 설정으로 시간 순서/차단을 확인.

하단 표시
- 현재 순위, 반복과 동작, 직전 완료한 일, 다음 일, 남은 대기 시간 표시.
- 직전 한 바퀴 처리 시간 / 전체 경과 시간 / 완료 바퀴 수 표시.
- 한 바퀴 처리 시간은 진입부터 복귀 후 목록 대기까지. 전체 경과에는 쉬는 시간과 일시정지 포함.
- 하단 표시가 터치를 가로채지 않으며, OCR 캡처 시 잠깐 숨김.

한계
- 실제 노트 10+ 및 녹스는 연결되지 않아 실기기/녹스 검사는 하지 않음.
- 녹스 5개 동시 실행, 장시간 10분 대기 반복은 아직 실검사하지 않음.
- 노트 10+ 기존 설치 위 업데이트는 동일 서명 확인으로 준비했으며, 실기기 설치 자체는 미검사.
