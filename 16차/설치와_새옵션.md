# PXE 16차 설치와 새 옵션

블루스택에는 `PXE_16차_v1.6_PC용.apk`, 갤럭시 노트10+에는 `PXE_16차_v1.6_노트10플러스.apk`를 설치합니다. 기존 앱과 같은 서명이며 앱 ID를 유지합니다. 기존 앱을 삭제하면 설정이 지워질 수 있으므로 업데이트로 설치합니다.

## 기존 매크로에 다음 글자 진행 적용

1. 사용할 저장본을 불러옵니다.
2. **반복 · 시간 설정**에서 **다음 글자에 맞춰 진행**을 켜고 **적용**합니다.
3. 목록 탐지에서 이름으로 저장한 매크로를 실행한다면 같은 이름으로 다시 저장합니다. 현재 편집본의 설정을 바꾸는 것만으로 별도 저장본까지 바뀌지는 않습니다.
4. 탐지 화면에서 사용할 매크로와 반복 횟수를 확인한 뒤 시작합니다.

이 옵션은 다음 글자의 사전 부재를 확인한 연속 글자 조건의 대기를 줄입니다. 이미 보이는 글자·수동 대기·반복 간격·무작위 대기는 유지합니다. 같은 위치의 바로 다음 글자 터치는 사라졌다 다시 나타나야 진행합니다. 목록의 기존 중복 방지는 별도 설정입니다.

하단에는 현재 동작, 한 바퀴 시간, 전체 경과 시간과 단계·OCR·캡처·설정 대기의 실측이 나옵니다. 단계 시간은 하위 작업을 포함하므로 항목을 모두 더하면 전체 시간과 다릅니다.

15회 실행 시간과 실제 시험 조건은 함께 제공한 검증 보고서를 확인합니다. 해상도를 낮춘 시험의 결과를 현재 블루스택 속도와 같다고 볼 수는 없습니다.
