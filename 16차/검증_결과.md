# PXE 16차 · 1.6.0 검증 결과

기존 차수와 매크로 저장 형식을 유지한 업데이트입니다. 블루스택에는 PC용 APK, 노트10+에는 노트10플러스용 APK를 설치합니다.

## 반영한 변경

- **다음 글자에 맞춰 진행**: 사전 부재가 확인된 연속 글자 조건의 완료 후 대기를 다음 조건 대기로 이전합니다. 새 글자가 나타나면 진행하며, 기존 수동 대기·반복 간격·무작위 대기·저장값은 유지합니다. 새 옵션은 기본 꺼짐입니다.
- 바로 다음 글자 터치가 같은 위치를 가리키면 사라짐과 재등장을 확인합니다. 목록의 기존 중복 방지와 개별 반복의 의미는 유지합니다.
- 준비 전에 즉시 일시정지·정지한 실행을 대기열 초기화가 덮어쓰던 경합을 수리했습니다. 개별 글자 터치의 준비 뒤 대상 확인과 전달 직전 관측된 창·일시정지 세대 확인도 보완했습니다.
- 하단에 현재 단계, 한 바퀴와 전체 시간, OCR·캡처·대기의 실제 시간을 표시합니다. 단계 시간은 하위 작업을 포함합니다.
- 실제 OBJ224정점·168면을 투영하고 조명으로 그리는 입체 PXE 모델을 넣었습니다. 상시 모델 애니메이션 루프 없이 라이트/다크와 나눔고딕 Bold·원래 라이선스를 유지합니다.

기기 검사는 소유 Android31 시험 기기에서 수행했습니다. PC용은 ARM64/x86_64, 휴대전화용은 ARM64입니다. 노트10+ 실기기와 사용자 블루스택을 직접 조작한 검사는 아닙니다.

기기89개와 Gradle98개는 당시 누적14/20, 독립 CPU4 성능은13/19 문맥으로 보존했습니다. 이후 변경은 공개 문서 형식과 운영 이력·누적뿐이며 앱·테스트·APK·수락 기준은 동일합니다. 별도 검증자가 엔진13파일·UI7파일·공개소스134개와 APK 해시를 다시 대조하고 현재16/22 문맥의 중앙 검사를 통과해 최종 영수증을 발급했습니다. 과거 실행을 새 문맥에서 수행한 것처럼 기록하지 않았습니다.

## 속도 결과와 조건

**CPU4·RAM2GB·540×1140·210dpi**의 같은 시험 화면에서 글자 터치2단계×15회를 실행했습니다. 15차는94.336초,16차는67.087초였으며 독립 검증자는67.518초를 확인했습니다. 각각 실제 OCR60회·30터치·오터치0입니다.

CPU2에서는 저해상도와 재부팅 뒤 추가 측정 모두 기한에 미달했습니다. 기본 해상도의 과거 실패도 보존했습니다. 앱 설치만으로 블루스택 설정이 자동 변경되지는 않습니다. 자세한 조건별 숫자는 **성능_실측결과.md**에 있습니다.

실제 게임 전체 정확도99%, 블루스택5개 동시, 노트10+ 실기기, 24시간 무중단은 이번 결과로 확인하지 않았습니다. OCR 확인을 생략하거나 실패 기한을 늘려 성능 통과로 만들지 않았습니다. OS의 앱 전환과 제스처 전달을 완전히 원자적으로 묶는 보장도 아닙니다.
