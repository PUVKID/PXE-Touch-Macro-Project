# PXE 16차 성능 실측

CPU4의 세 실행은 모두 실제 OCR60회·실제 입력540×1140·글자 배율1.0·최소 글자 ink26×28픽셀을 확인했습니다. Android Emulator의 WHPX·swiftshader를 사용했습니다. CPU4 첫 비교 한 쌍에서16차가15차보다27.249초 짧았습니다. 서로 다른 반복 횟수까지 수행한 CPU2 실패의 총 시간을 속도 개선률 계산에 쓰지 않았습니다.

기본1080×2280·420dpi의 과거 비교도 제한 안에 완주하지 못했습니다. 당시16차는 통합 중인 구현이었으며, 저해상도와 CPU4의 성공으로 그 실패를 지우거나 최종본의 기본 해상도 성능이 보장된다고 표현하지 않습니다.

## 결과를 적용할 때

이번120초 목표는 위 시험 화면과CPU4 조건에서 통과했습니다. 앱 설치만으로 블루스택의 CPU·해상도가 자동 변경되는 것은 아닙니다. 실제 게임의 동작 수·화면 전환·에뮬레이터와 호스트 부하가 달라지면 시간도 달라집니다.

오터치0은 위 관측 범위의 결과입니다. 실제 게임 전체 정확도99%·블루스택5개 동시·노트10+ 실기기·24시간 무중단은 이 시험으로 확인하지 않았습니다. 글자 인식 결과 확인이나 터치 전 재확인을 생략해 시간을 줄이지 않았습니다.

단계 시간은 하위 작업을 포함하고, 다음 조건의 선행 대기는 OCR과 겹칠 수 있습니다. 하단의 단계·OCR·캡처·설정 대기 숫자를 모두 더한 값을 전체 실행 시간으로 사용하지 않습니다.

추가 CPU2 측정은 전체 기능 검사 뒤 별도 단계로 실행했습니다. 재부팅만으로 목표가 달성되는지를 살핀 한 번의 추가 진단이며, CPU4가 모든 환경에서 필수라는 인과적 보장은 아닙니다.
