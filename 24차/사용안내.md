# PXE 사용 안내

휴대전화와 Android 에뮬레이터에서 같은 공용 APK를 사용합니다. Android 11 이상, ARM64 또는 x86_64 환경을 지원합니다. 기존 매크로가 기본이며 **AI 기능은 처음에는 꺼져 있습니다.** 업데이트 전에 매크로와 개인 작업 파일을 따로 보관해 주세요.

## 글자가 보이면 바로 누르기

1. 매크로 동작 목록에서 **글자 찾아 터치** 동작을 편집합니다.
2. **찾을 글자**와 탐지 영역을 정합니다. 검색 방식은 먼저 **자동 · 화면 정보 → OCR**을 사용합니다. 에뮬레이터가 화면 정보를 제공하지 않으면 **한글 OCR**을 직접 선택할 수 있습니다.
3. 화면이 바뀔 때까지 터치 없이 기다리려면 **글자가 나타날 때까지 계속 기다리기**를 켭니다.
4. **인식 후 추가 대기 없이 다음 동작**을 켜면 고정된 완료 후 대기를 생략합니다. 화면을 읽고 인식하는 처리 시간은 필요합니다. 글자 터치 직전 재확인도 생략하므로, 재확인을 원하면 이 옵션을 끕니다.
5. 다음 동작에도 필요한 글자를 각각 지정합니다. 전체 매크로 15회와 **이 동작 한 세트만 반복 · 회**는 서로 다른 설정입니다.

목록을 탐지하는 방식과 매크로 안의 개별 동작 검색 방식은 따로 저장됩니다. 목록을 OCR로 바꾸더라도 이미 만든 동작의 검색 방식은 함께 바뀌지 않습니다.

## 글자가 없으면 뒤로가서 다시 찾기

같은 화면에서 기다리기와 복구 동작을 반복하기 중 하나를 선택합니다.

1. 동작 편집에서 **글자가 나타날 때까지 계속 기다리기**를 끕니다.
2. **최대 기다릴 시간 · 초**를 정합니다. 그 시간 안에 글자가 없으면 다음 복구 동작을 합니다. 0은 한 번만 확인합니다.
3. **글자가 없으면 → 뒤로가기 후 다시 찾기**를 선택합니다. 같은 화면 확인, 위로 스크롤, 아래로 당겨 새로고침, 지정 동작 실행도 선택할 수 있습니다.
4. **찾을 때까지 계속 재시도**를 켜면 정지할 때까지 반복합니다. 끄면 최대 재시도 횟수를 적용하며, 그 뒤에도 없으면 중단합니다.
5. **복구 후 다시 찾기 전 대기 · 초**는 최소 0.3초부터 지정합니다.

화면을 읽지 못한 오류를 글자 없음으로 처리해 뒤로가기를 누르지는 않습니다. 읽기가 복구된 새 화면으로 다시 판단합니다. 원하는 화면에 들어갔는지 확인하는 글자 동작을 따로 넣으면, 확인 글자가 없을 때 뒤로 돌아가도록 구성할 수 있습니다.

## 일시정지·중단과 진행창

**Ⅱ / ▶**는 일시정지와 계속 실행, **■ 중단**은 실행 종료입니다. 진행창은 손잡이로 옮기거나 접을 수 있고, 설정의 화면 위 컨트롤에서 불투명도를 조절합니다. 진행창 본문은 아래 앱으로 터치를 통과시키며, 본문을 0%로 해도 작은 손잡이는 남습니다. 실행 중에는 현재 동작, 반복 진행, 한 바퀴 시간과 전체 경과를 확인합니다.

화면·OCR·동작 응답이 늦으면 현재 대기 이유를 표시합니다. 오래된 인식 좌표를 사용하거나 이미 보낸 입력을 무조건 재전송하지 않습니다. 사용자 최대 실행 시간, 권한 해제, 서비스 종료는 별도로 적용됩니다.

## 글자와 그림을 함께 가르치기

1. **설정 → AI 기능**에서 AI를 켭니다.
2. 홈의 **AI 시범 학습 → 새 작업 가르치기**에서 작업 이름과 대상 앱을 정합니다.
3. **AI 가르치기**를 누르고 원하는 동작을 보여 줍니다. 글자가 없는 아이콘은 제어창의 **이미지 터치**를 선택한 뒤 가운데를 누릅니다.
4. 뒤로가기·스크롤·글자 기다리기는 제어창의 해당 버튼으로 가르칩니다.
5. **시범 완료 · 확인하고 학습**을 눌러 확정합니다.
6. 처음 화면에서 같은 작업을 한 번 더 보여 줍니다. 최소 두 번의 확정 시범을 만든 뒤 **시작해 · 자동 수행**을 누릅니다.
7. 잘못 배운 동작은 **고치기**에서 다시 가르칩니다. 자동 수행 결과를 스스로 정답으로 저장하지 않습니다.

그림의 외형, 화면 배치, 글자를 함께 사용합니다. 같은 그림이 여러 곳에 있거나 배운 단서가 부족하면 입력 없이 기다립니다. 낯선 화면의 모든 의미를 이해하는 범용 언어모델은 아닙니다.

## 저장과 추가 학습

작업 화면의 **개인 작업 내보내기**로 `.pxeb` 파일을 저장합니다. 다른 설치에서는 **개인 작업 가져오기**에서 같은 대상 앱을 정하고 파일을 선택합니다. 가져온 작업에도 시범을 추가할 수 있습니다. 기존 글자 모델을 읽을 수 있으며 새 이미지 모델에는 화면·이미지 조각·학습 자료가 포함됩니다. 개인 작업 파일은 비공개로 보관해 주세요. 설정의 실행 기록과 오류 기록에도 작업 정보가 포함될 수 있으므로 비공개로 다룹니다.

## 화면을 읽지 못할 때

일시적인 화면 조회·OCR 지연은 별도 복구 대기 설정 없이 새로 확인합니다. **권한이 회수되거나 보안 화면이 캡처를 막으면 강제로 읽을 수는 없습니다.** 접근성 연결이나 권한 안내를 확인해 주세요. 계속 기다리기와 미발견 재시도를 켜도 사용자가 정한 전체 실행 시간 제한은 유지됩니다.

합성 시험의 처리 시간을 실제 게임이나 여러 에뮬레이터의 속도로 해석하지 않습니다. 모든 앱의 인식 정확도나 1년 무오류 운용은 측정하지 않았습니다.
