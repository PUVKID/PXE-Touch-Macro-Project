## LEVEL 5 · 모델과 실행 구조

시각 정책은 글자·직전 행동·상태 584차원과 RGB 배치 576차원을 결합한 **1160차원 입력**을 사용합니다.

구형 584 →32 →K F64 MLP 읽기 호환도 제공합니다. v2 packed에는 F64 가중치·행동 사전·확정 시 범·RNG·학습 상태를 저장합니다.

OCR 엔진 자체를 재학습하거나 범용 언어 모델을 탑재하는 구조는 아닙니다.

| 구현 | 책임 |
| --- | --- |
| BehaviorVisual / BehaviorVisualPolicy | 화면 특징과 시각 행동 정책 |
| BehaviorAndroidBridge / BehaviorAndroidSession | 관측·시범·학습·실행 연결 |
| VisualMatcher | 저장한 외형 조각을 현재 화면에서 다시 탐색 |
| MacroService | 실행 세대·일시정지·취소·대상 앱·입력 경계 |
| FloatingController | 이동·접기·중단과 시범 모드 제어 |

## LEVEL 5 · 비동기 응답과 중복 입력

일반 UI 5초·제스처 65초는 지연을 관측하는 기준입니다.

이미 보낸 입력은 동일 future를 기다리며 재전송하지 않습니다.

입력 없는 캡처 준비만 오래된 작업 취소·큐 제거 뒤 새 준비를 시도합니다.

사용자 중단·권한 회수·서비스 종료·회전·전체 실행 기한은 계속 검사합니다.

화면을 읽지 못한 상태를 글자 없음으로 바꿔 뒤로 가기를 실행하지 않습니다.

## LEVEL 5 · 결과와 재현 자료

정상 빌드 13의 단위 44 클래스·280개와 린트 오류 0개·경고 4개를 확인했습니다. 실제 기기 시험은 기능 1개·시 각 2개이며 최종 빌드와의 결합 방식은 [24차 검증 결과](../../24차/검증_결과.md)에 기록했습니다. 단위 검사 수·기기 검사 수·시범 수·학습 단계 수를 같은 분모로 합치지 않습니다.

## 확인한 결과

단위 검사 280개와 전용 기능 1개·시 각 2개를 확인했습니다. 기능 검사의 동작 15회는 한 Watch 사이클이며 전체 매크로 15 사이클을 뜻하지 않습니다. 최종 APK 지문과 실제 시험의 적용 범위는 [24차 검증 결과](../../24차/검증_결과.md)에 한 번만 정리했습니다.
