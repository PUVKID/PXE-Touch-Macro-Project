## LEVEL 1 · 그림을 가르친다는 뜻

PXE의 기본 기능은 미리 정한 순서대로 글자를 찾고 화면을 누르는 **매크로**입니다. 24차는 선택형 AI에 글자 없는 아이콘도 가르치려는 변경입니다.

AI는 처음에는 꺼져 있으며, 기존 매크로를 쓰는 데 켤 필요가 없습니다.

예를 들어 그림 버튼을 가르칠 때는 그 때 보이는 글자와 화면의 색 배치, 사용자가 누른 그림 조각을 함께 기록합니다.

다시 실행할 때는 예전 좌표를 그대로 누르는 대신 **현재 화면에서 그림을 다시 찾은 위치**를 사용합니다.

같은 그림이 두 개 있어 구별하기 어렵거나 처음 보는 화면이면 누르지 않고 기다립니다.

OCR은 화면 사진의 글자를 읽는 기능입니다.

RGB는 화면 색을 빨강·초록·파랑 값으로 나타내는 방법입니다.

정책 모델은 이 관측을 보고 가르친 행동 중 하나를 고르는 작은 신경망입니다.

사용자가 확인한 시범으로 가중치, 즉 행동 선택에 쓰는 내부 숫자를 바꿉니다.

화면을 저장했다는 사실만으로 학습이 끝난 것은 아닙니다.

이미지 선택, 글자 대기, 일반 동작 선택은 각각 다른 입력이므로 앞에서 선택한 이미지 모드가 다음 동작에 남지 않아야합니다.


## LEVEL 1 · 예전 모델과 새 저장 파일

24차의 시각 정책은 글자와 이전 행동 등의 584개 값에 색 배치 576개를 더 한 **1160개 입력**을 사용합니다. F64는 내부 숫자를 64 비트로 저장한다는 뜻이며 정확도가 64%라는 뜻이 아닙니다. 구형 584차원 모델을 읽는 기능도 남깁니다.

새 모델은 v2 packed라는 묶음에 가중치뿐 아니라 시범, 행동 이름표, 난수 생성 상태와 학습 상태를 넣습니다.

난수 생성 상태는 학습의 다음 계산을 이어 가는 데 필요한 기록입니다.

파일 형식을 검사했더라도 다른 휴대 전화에 가져와 파일 선택 창으로 여는 과정까지 확인한 것은 아닙니다.

개인 시범·화면·모델은 비공개로 보관합니다.


## LEVEL 1 · 응답이 늦을 때 누르기를 반복하지 않기

화면 작업의 답이 늦으면 한 번 더 누르고 싶을 수 있지만, 첫 입력이 뒤늦게 실행되면 두 번 눌릴 수 있습니다.

그래서 일반 화면 작업의 5초와 제스처의 65초는 지연을 알리는 기준으로 쓰고 **처음 요청한 작업의 결과를 계속 기다립니다**. future는 이 결과를 받기 위한 대기 표에 해당합니다.

새 대기 표를 만들어 같은 터치를 다시 보내지 않습니다.

아직 실제 입력을 하지 않은 화면 캡처 준비는 다르게 처리합니다. 오래된 준비 작업을 취소하고 대기열에서 제거한 뒤 새 준비를 시도합니다. 이때도 정지, 권한 해제, 서비스 종료, 회전과 사용자가 정한 전체 실행 시간 제한을 확인합니다. 영원히 응답이 없는 기기를 반드시 복구한다는 약속은 아닙니다.
