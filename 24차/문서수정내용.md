# 24차 문서 수정 내용

| 요청 사항 | 반영 내용 |
| --- | --- |
| 24차는 24차 내용만 표시 | 현재 안내·상세·최종 안내를 24차 기준으로 통일 |
| 각 차수는 해당 차수만 설명 | 기능·설정·관측 결과를 해당 차수 본문에 유지 |
| 이전 차수 설명 제한 | 바뀐 점·차이점에서만 비교하고 원래 차수로 연결 |
| 반복과 혼동 제거 | 과거 납품 결과·초기 확정 대기·중복 확정표를 현재 본문에서 분리 |
| 읽기 편한 화면 | 현재 사용법·기능·결과를 먼저 표시하고 전체 차수는 펼침 표로 제공 |
| 문서만 수정할 때 | 새 차수 생성·APK 재빌드 없이 현재 차수 문서 수정 |
| 최종 파일 한 곳에 보관 | 24차 APK·ZIP·사용 안내 유지 |

문서 정리로 만들었던 별도 차수는 제거하고 24차로 합칩니다. 앱과 설치 파일을 재빌드하지 않았으며 기존 24차 원본을 유지합니다.
