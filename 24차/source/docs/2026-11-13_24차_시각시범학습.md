# 24차 시 각 시범 학습

기존 584차원 글자 MLP는 보존하고 시각 입력이 있는 시범에는 화면의 RGB·배치 특징을 쓰는 별도 학습 분류기를 사용합니다. 글자 없는 아이콘은 사용자가 시범에서 누른 주변 외형을 저장하고 현재 화면에서 다시 찾습니다. 위치만 재생하지 않습니다.

AI 기본 꺼짐과 기존 매크로를 유지합니다. 같은 문구라도 화면 외형이 다르면 시범 문맥을 구별하며, 확정 시범 두 개 미만·중복 아이콘·낯선 화면·불확실한 정책은 입력하지 않고 기다립니다. 새로운 두 프레임의 일치와 기존 대상 앱·세대·정지·일시정지 보호를 유지합니다.

구형 v1 글자 모델은 그대로 읽습니다. 시각 데이터가 포함된 새 모델은 v2로 내보내며 RGB·템플릿·가중치·시범은 개인 자료입니다. 실행 코드를 받지 않고 기존 16MiB 묶음/8MiB 항목 상한과 4096 표본 상한을 함께 지킵니다. 먼저 도달한 상한에서 기존 저장을 보존하고 새 저장을 거절합니다.

이 기능은 시범에 맞춘 작은 오프라인 화면 정책입니다. 범용 LLM이나 장면의 모든 의미를 이해하는 모델이라고 표시하지 않습니다. 실제 1년 연속 실행과 정확도는 측정하지 않았으며 무오류를 보장하지 않습니다. 경량화는 이번 범위에서 실제 적용하지 않습니다.

## 모델별 출력 사전과 기존 학습 보존

구형 v1은 기존 584 →32 →K 추론과 묶음 계약을 그대로 사용합니다. v2의 시각 분류기는 별도 화면 특징과 가중치로 학습합니다. v2에서 글자 정책은 확정된 글자 시범의 행동 ID 집합을 자신의 출력 사전으로 사용하고, 새 시각 전용 행동의 무작위 행을 기존 글자 softmax 분모에 넣지 않습니다.

이는 확신 기준을 낮추는 방식이 아니며 기존 0.80 확률·0.20 격차와 반복 시범 지원 조건을 유지합니다.

이번 시범에 새 글자 표본이 없으면 옛 글자 정책을 재학습 하지 않습니다.

전체 문맥은 최대 64×112 RGB로 저장하고, 현재 관측의 아이콘 찾기는 최대 256×448 상세 RGB와 16×16 대상 외형을 이용합니다.

상세 전체 화면은 표본·모델에 저장하지 않습니다.

매우 작거나 비슷한 아이콘·애니메이션·큰 배치 변경을 모두 구별하는 범용 비전 모델은 아닙니다.

익숙하지 않거나 둘 이상 가능한 대상은 누르지 않습니다.

모델 최대 출력 500개에서 시각 가중치 원 배열은 4,644,000바이트입니다.

학습 후보·경사·기존 모델 배열은 별도로 필요합니다. 4096개는 표본 수 상한이며 이미지가 있는 작업은 8MiB 항목·16MiB 전체 묶음 상한에 먼저 닿을 수 있습니다.

완료 전 시범도 원본과 새 초안을 합산해 표본 수와 provenance별 8MiB 실제 UTF-8 예산을 확인합니다.

저장 실패가 기존 작업의 교체를 승인하지 않습니다.

시각 정책 입력은 1160차원으로 고정합니다.

기존 글자·이전 동작·상태 584차원과 화면 RGB 배치 576차원을 함께 사용하여 그림 때문에 글자 구별을 잃지 않게합니다.

시각 분류기의 별도 가중치는 F64 big endian 바이트와 Base64로 기록하고 실제 길이·유한 값을 검증합니다.

최대 500개 출력의 Base64 본문은 6,192,000 문자이며 기존 8MiB 항목 상한을 바꾸지 않습니다.

같은 배경의 다른 글자와 같은 글자의 다른 이미지를 각각 검사합니다.

## 탐색 표본의 좌표 일치

동일한 20 픽셀 이미지 조각의 전체 16×16 오차는 0인데 4×4 사전 검사 표본이 1 픽셀 어긋나 거절되는 결함을 실제 제품 코드로 재현했습니다.

사전 검사가 저장된 16×16 표본의 해당 인덱스와 정확히 같은 픽셀을 읽도록 두 좌표 식만 바꿨습니다.

사전 기준 0.06·전체 기준 0.025, 후보 모호함·취소와 최종 전체 비교는 유지했습니다.

비주기 이미지의 자기 일치와 이동을 확인하는 영구 회귀 1개를 추가했고 기존 279개와 합친 280개를 구현 자·별도 검증자가 각각 통과했습니다. 두 차례의 실제 시각 검사 실패와 이 합성 재현의 직접 인과는 구분하며, 새 APK의 실제 기기 결과는 차수별 검증 문서에 기록합니다.


## 2026-11-13 후속 검사 a7~a12와 수리 44

준비 지연, 연속 OCR, OCR 복구를 포함한 전용 합성 환경의 검사이며 사용자 블루스택이나 1년 무오류를 검증한 결과는 아닙니다.
