# PXE 24차 Android 소스

기존 매크로와 기본 꺼짐 AI를 유지하며 화면 이미지·아이콘 시범 학습과 화면 응답 지연 대기를 추가합니다.

기존 정책의 총 584차원(글자 512 +직전 행동 64 +상태 8)과 새 1160차원 시각 정책을 구분하고 구형 모델 읽기를 유지합니다.

원문의 글자 조건·반복·영역·정지와 신선한 화면 확인 경계는 소스와 합성 검사에서 확인할 수 있습니다.

공개 사본은 환경·상대경로 인터페이스를 사용합니다. 키·개인 화면·시범·가중치·운영 원문은 포함하지 않습니다. 기존 글꼴·제삼자 라이선스를 보존하며 새 라이선스를 부여하지 않습니다.
