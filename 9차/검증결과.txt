단축창 실제 터치 확인
- 현재 편집 매크로와 탐지에 등록한 매크로를 다르게 저장.
- ▶를 누르면 일반 매크로 대신 글자 탐지가 시작됨.
- 글자를 눌러 들어가 등록 매크로를 정확히 15회 실행.
- 뒤로간 후 완료 대기로 진입, 편집 중인 원래 매크로는 유지.
- 같은 단축창에서 일시정지/계속 실행/정지 동작 확인.
- 탐지 설정이 없으면 현재 일반 매크로를 대신 실행하지 않음.

캡처 오류 주입 시험
- 오류(3) 두 번 후 실제 화면 캡처와 한글 OCR로 복구.
- 새 캡처로 글자를 재확인한 후 한 번만 진입, 완료 후 대기 중 재진입 안 함.
- 요청 사이 4초/8초의 늘어난 간격과 성공 후 유지된 간격 확인.
- 재시도 대기 중 정지 시 추가 캡처/항목 진입 없음.
- 계속 오류(3)를 반환하면 최초 요청+3회 재시도 후 중단, 터치 없음.

초기 단축창 검사 실패의 원인
시험용 MainActivity 안내 화면에서 컨트롤을 숨기는 상태를 실제 외부 사용 상태로 전환하지 않았고,
조건 확인 도구가 클릭을 두 번 실행했습니다. 시험 환경과 클릭 도구를 보정했습니다.
제품 코드의 새 ▶ 흐름은 보정한 실제 터치 시험에서 통과했습니다.

한계
사용자 블루스택 다섯 창에서 새 APK 설치 및 동시 실행을 검증한 결과는 아닙니다.
기존 자동 설치 연결 오류로 사용자 창은 직접 APK 업데이트가 필요합니다.
이후 사용자 요청으로 LD플레이어로 전환했습니다. 설치된 제품은 LDPlayer 14.0.29.2입니다.
LD플레이어 설치 명령을 전송했지만 Android 설치 조회 연결이 실패해 완료 여부를 확인하지 못했습니다.
LD플레이어의 실제 OCR·접근성 및 5개 동시 실행은 아직 검증하지 못했습니다.
대상 앱의 보안 화면/접근성 미지원/블루스택 캡처 구현 오류까지 해결된다는 보장은 없습니다.
오류가 반복되면 무한 재시도하거나 다른 위치를 대신 누르지 않고 중단합니다.
