PXE 11차 · 1.1.0

현재 9버전에서 자동 인식을 사용할 때 발생한 화면 정보 응답 지연을 수정한 버전입니다.

설치
1. LD플레이어: PXE_11차_v1.1_PC용.apk를 각 LD플레이어 창으로 끌어 넣어 업데이트하세요.
2. 노트10+: PXE_11차_v1.1_노트10플러스.apk를 열어 업데이트하세요.
3. 기존 앱을 삭제하지 마세요. 같은 앱 ID와 서명으로 업데이트하여 저장된 설정을 유지합니다.
4. 안드로이드 설정의 PXE 앱 정보에서 버전 1.1.0인지 확인하세요. 접근성 연결이 끊겨 있다면 PXE 접근성 서비스를 다시 연결하세요.
5. 탐지할 대상 앱을 다시 열고 자동 인식으로 실행하세요.

주요 변경
- 자동 인식에서 화면 정보 응답이 지연되면 해당 실행 중 이미지 글자 인식으로 전환합니다.
- 하단 기록에 전환 이유를 표시합니다.
- 이미지 글자 인식의 대상 앱 확인을 지연된 화면 노드 읽기와 분리했습니다.
- 다른 앱으로 이동하거나 대상 앱을 확인하지 못하면 터치하지 않습니다.
- 우선순위, 매크로 반복, 뒤로가기, 완료 후 휴식과 새로고침 설정을 유지합니다.

확인 범위
검증결과.txt에서 실제 실행한 검사와 한계를 확인하세요.
사용자 LD플레이어의 대상 앱은 직접 연결되지 않아 실제 5개 동시 실행 결과는 확인하지 못했습니다.
기존 9차와 10차 폴더는 보존했습니다.
