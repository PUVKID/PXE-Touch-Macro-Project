Click Assistant 참고 기능 → NEX 구현

참고: 사용자가 첨부한 Click Assistant 1.22.7 XAPK
확인: manifest.json, AndroidManifest.xml, 한국어 리소스, 개발사 공개 기능 설명
공식 설명: https://ycstudio.app
Google Play: https://play.google.com/store/apps/details?id=com.rise.automatic.autoclicker.clicker

접근성 제스처 실행 → AccessibilityService.dispatchGesture
화면 밖에서도 떠 있는 조작 UI → 접근성 오버레이 + 별도 foreground 컨트롤 서비스
클릭·스와이프 → 좌표 터치, 두 번, 길게, 스와이프
곡선 스와이프 → 제어점 곡선 및 직접 경로 녹화
두 손가락 확대/축소 → PINCH_IN / PINCH_OUT
멀티터치 → 동시 다중 터치 + 손가락별 경로/시작/지속 시간
녹화 → 화면 위 터치를 먼저 캡처하고 손을 뗀 후 원래 앱에 제스처 재생
개별 시간·반복 설정 → 지속 시간, 완료 후 대기, 동작 반복
무작위 시간 → 지속 시간/완료 후 대기의 ±ms 범위
화면 위 점 위치 편집 → 번호 점 드래그, 녹화 제스처 전체 이동
동작 순서·복제·삭제 → 앱 및 화면 위 동작 목록
지정된 번호부터 실행 → startAt 및 화면 위 목록의 '여기서부터'
카운트다운·시작 지연 → 시작 전 대기, 경과/남은 시간, 최대 실행 시간
크기·불투명도 → 컨트롤 크기 75~140%, 불투명도 40~100%
표시·접기 → 번호 점 표시, 작은 NEX 버튼으로 접기
저장·불러오기 → 이름별 보관 + JSON 파일

NEX의 추가 핵심
원하는 문구 찾고 터치, 한글 OCR 내장, 접근성 글자 + OCR 자동 모드,
검색 영역/터치 보정, 인식 위치 미리보기, 글자 없으면 뒤로/대기/스크롤 재검색,
라이트/다크/기기 테마, 화면 켜짐 유지, 조건 분기와 문자 입력.

구현의 범위
일반 사용 기능을 독립 코드로 구현했습니다.
첨부 앱의 바이너리나 내부 구현 전체를 동일하게 복제했다고 주장하지 않습니다.
첨부 앱의 리소스/원본 코드/서명을 NEX에 포함하지 않았습니다.
원본 앱의 자체 저장 파일 형식과의 직접 호환은 확인하지 않았습니다.
NEX 1차 JSON 파일은 2차에서 불러올 수 있습니다.
