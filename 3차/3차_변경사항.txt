3차 디자인 변경
- 첫 화면: 글자 입력, 뒤로가기 재검색, 주요 실행 버튼 중심으로 단순화
- 인식 방식과 비교 방식: 인식 설정 창으로 이동
- 내비게이션: 글자 / 매크로 / 설정 3개로 정리
- 저장과 파일 관리: 매크로 더보기에서 접근
- 동작 목록: 제목을 눌러 편집, ⋮ 메뉴로 순서·복제·삭제 관리
- 세부 검색 영역·터치 보정 등: 편집창의 세부 설정으로 접어서 표시
- 화면 위 컨트롤: 상태 문구 + 시작/정지/글자/더보기 한 줄
- 설정: 주요 항목만 표시하고 컨트롤 옵션은 별도 창으로 이동
- 라이트·다크 모드, 나눔고딕 Bold 유지
- 22개 동작 유형과 글자 인식·뒤로가기 재검색 기능 유지
- 기존 1차·2차 보존
