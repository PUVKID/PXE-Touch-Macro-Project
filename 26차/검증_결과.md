# PXE 26차 검증 결과

**16차 기반 2.6.0의 변경 부분과 아래 기능을 전용 Android 12 가상 장치에서 확인했습니다.** 실제 사용자 블루스택·게임·노트10+는 조작하지 않았습니다. 모든 환경의 무오류나 인식률 99%, 장기 무중단 운용을 입증한 결과는 아닙니다.

## 바뀐 점·차이점

16차의 디자인·저장 구조·매크로를 유지합니다. 정규화 후 빈 검색어가 모든 글자와 일치하던 결함을 고치고, 공백 무시 시 전각·유니코드·보이지 않는 공백을 처리합니다. 정규식과 검색어는 탐지 한 번에 한 번 준비해 반복 계산을 줄였습니다.

창 조회 지연 시 목록 탐지와 무한 글자 대기는 조회를 중복 전송하지 않고 기다립니다. 유한 동작은 창 조회의 실제 대기만 제한하며 정상 OCR 계산 전체에 절대 제한을 씌우지 않습니다. 늦게 도착한 이전 실행·일시정지 전 응답으로 터치하지 않습니다. 실제 캡처 거부와 서비스 연결 종료 같은 오류는 숨기지 않습니다.

후속 차수의 선택형 AI를 가져오지 않았습니다. 미사용 의존성과 리소스를 축소하되 자체 앱·공유 프레임워크·OCR 공개 API는 저장·반사·검사 호환을 위해 보존합니다. 인식 엔진의 해상도·모델·화면 품질을 낮추는 축소는 하지 않았습니다.

초기 축소 검사에서 발견한 SDK 연결 문제와 유한 대기 회귀는 수정 후 위 검사로 확인했습니다. 중간 실패 원문과 호스트 Java 실행기 오류는 비공개 작업 기록에 보존합니다. 과거 검사 실패를 성공으로 바꾸지 않았습니다.

속도 개선률·배터리 절감률은 측정하지 않았습니다. 보호 화면 우회, 모든 글꼴·화면 배율, 실제 6개 블루스택 동시 운용과 24시간·1년 운용은 이 검사 범위에 포함하지 않습니다. 위 표에서 확인하지 않은 외부 환경까지 전체 기능 무결함으로 확대하지 않습니다.

복구·제어 묶음의 원래 34개 중 33개가 통과했고, 예전 자동 중단 기대 1개는 현재 계속 대기 요구에 맞는 별도 검사로 대체해 통과했습니다. 기본 반복·제어 묶음의 10개 중 9개가 통과했고, 뒤로가기 재시도 검사는 같은 앱의 두 화면이 실제로 준비된 뒤 검사하도록 고쳐 1개가 통과했습니다. 원래 실패한 묶음을 전부 성공으로 바꿔 기록하지 않았으며 각 묶음 시간에는 당시 실패한 검사 시간이 포함되어 있습니다.
