# 26차 · 16차 기반 경량 인식

## 요구와 구현 범위
16차의 디자인·라이트/다크·저장 형식·일반 매크로·6순위 탐지·반복·중복 방지·일시정지/중단·적응 대기를 유지합니다. 이후 차수의 시범 학습·AI 메뉴·ONNX·행동 모델을 가져오지 않습니다. 한글 OCR은 글자 인식의 필수 기능으로 오프라인 내장 모델을 유지합니다.

## 선택한 방법
16차에서 시작해 확인된 글자 비교 결함과 대상 창 응답 지연만 좁게 개선합니다. 전체 최신 엔진을 되가져오거나 영역 OCR로 화면의 문맥을 줄이는 변경은 하지 않습니다. 검색 조건은 한 번 준비해 재사용하고, 공백 무시 때 Unicode 공백·보이지 않는 공백을 처리하며 정규화 후 빈 검색어를 거절합니다. 창 조회가 늦어지면 조회를 중복 전송하지 않고 정지 가능한 대기를 유지합니다.

## 경량화
ONNX와 시범 학습은 포함하지 않습니다. R8과 리소스 축소를 적용하되 앱 내부 클래스는 검사와 저장·연동 호환을 위해 보존합니다. 실제 APK 크기로만 경량화 결과를 비교하며 속도와 정확도 향상을 미측정 수치로 쓰지 않습니다.

## 성공 조건
기존 기능별 근거를 재사용하고 바뀐 글자 비교·느린 창 조회·취소·업데이트 보존·축소 APK의 실제 동작을 확인합니다. APK의 버전26/2.6.0·기존 서명·공용 ARM64/x86_64·오프라인 OCR·AI 미포함과 기존 차수 보존을 확인합니다. 미확인 기능을 전체 정상으로 표시하지 않습니다.

## 유한 대기 보존
유한 글자 동작에서는 창 조회마다 실제 대기만 max(1500ms, 설정 timeout)으로 제한합니다. 정상 OCR 한 번의 소요 시간 전체에 절대 시한을 적용하지 않습니다. 무한 대기와 목록 탐지에서는 조회가 늦어도 중복 요청 없이 기다립니다. 잠금·방향 변경·서비스 종료·최대 실행 시간·사용자 정지는 기존대로 확인합니다.
