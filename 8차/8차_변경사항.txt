NEX 8차 v8.0 — 화면 정보 읽기 지연 대응

1. 탐지 중 화면 정보와 대상 앱을 읽는 작업을 화면 조작 스레드에서 분리했습니다.
   읽기가 막혀도 상태 표시와 정지 버튼이 계속 반응하도록 변경했습니다.
2. 화면 읽기 중 경과 초를 하단에 표시합니다.
   약 3.5초 동안 응답하지 않으면 지연 메시지를 표시하고 실행을 중단합니다.
   느린 읽기를 글자 없음으로 취급하거나 다음 순위를 대신 실행하지 않습니다.
3. 한 탐지 회차에서 최대 여섯 영역이 화면 정보 한 번을 함께 사용합니다.
   실제 누르기 전에는 새 화면 정보로 선택한 글자를 다시 확인합니다.
4. 화면 정보 탐색에 시간·깊이·항목 수 제한을 추가했습니다.
   이전 읽기가 아직 끝나지 않았으면 새 읽기를 계속 쌓지 않습니다.
   정지 후 늦게 도착한 결과는 터치에 사용하지 않습니다.
5. OCR 캡처 실패를 모두 보안 화면이라고 안내하던 문구를 수정했습니다.
   실패 번호를 유지하고 권한·캡처 간격·화면 오류 등을 나눠 안내합니다.

기본 처리 방식과 설정은 유지합니다.
1순위부터 확인 → 발견한 영역 하나 터치 → 전체 매크로 설정 횟수 반복
→ 뒤로가기 → 설정한 완료 후 대기 → 새로고침 → 다시 1순위부터 탐지.

NEX는 인스턴스 간 입력이나 실행 상태를 동기화하지 않습니다.
블루스택 작업 동기화가 켜져 있으면 그 기능이 입력을 다른 창으로 전달할 수 있습니다.
이번 수정은 코드에서 확인한 멈춤 가능성을 줄이는 수정입니다.
사용자 블루스택 다섯 창의 실제 멈춤 원인이나 정상 동시 실행은 아직 확인하지 못했습니다.
