# PXE 사용 안내

휴대전화와 Android 에뮬레이터에서 같은 공용 APK를 설치합니다. Android 11 이상, ARM64 또는 x86_64 환경을 지원합니다. 기존 매크로가 기본이며 AI 기능은 처음에는 꺼져 있습니다.

## 기존 매크로 사용

공용 APK로 업데이트한 뒤 기존 매크로를 불러와 사용합니다. 글자·탐지 영역·우선순위·반복 횟수는 기존 설정을 사용합니다. 앱이 안내하는 접근성 연결과 화면 읽기 권한을 허용합니다.

실행 중 `Ⅱ / ▶`는 일시정지와 계속 실행, `■ 중단`은 실행 종료입니다. 진행창은 손잡이로 옮기거나 접을 수 있고, 설정의 화면 위 컨트롤에서 본문 불투명도를 조절합니다.

## 시범으로 가르치기

1. 설정 → **AI 기능** → **AI 켜기**를 선택합니다.
2. 홈의 **AI 시범 학습** → **새 작업 가르치기**를 누릅니다.
3. 작업 이름과 시범을 보일 앱을 정해 **작업 만들기**를 누릅니다.
4. **AI 가르치기**를 누른 뒤 대상 앱에서 원하는 순서대로 글자를 누릅니다. 뒤로가기·스크롤·글자 기다리기는 작은 제어창의 해당 버튼을 사용합니다.
5. 원하는 완료 지점에서 **시범 완료 · 확인하고 학습**을 눌러 직접 확인합니다.
6. 같은 작업을 처음 화면에서 한 번 더 가르칩니다. 최소 두 번의 시범을 확정한 뒤 **시작해 · 자동 수행**을 누릅니다.
7. 잘못 배운 동작은 **고치기**에서 시범을 선택해 다시 보여 줍니다. 자동 수행한 행동은 스스로 정답으로 저장하지 않습니다.

## 저장하고 다른 곳에서 이어 쓰기

작업 화면의 **개인 작업 내보내기**로 `.pxeb` 파일을 저장합니다. 다른 설치에서는 AI 시범 학습 → **개인 작업 가져오기**에서 같은 대상 앱을 정하고 파일을 선택합니다. 가져온 작업에 **AI 가르치기**로 시범을 더 추가할 수 있습니다. 개인 작업 파일에는 화면 글자와 학습 자료가 들어가므로 보관 위치를 직접 정해 주세요.

## 확인한 범위

공용 APK에서 실제 시범 두 번, 학습 192단계, 자동 터치와 완료, 내보내기·가져오기·추가 학습, 원래 상태 복원을 확인했습니다. 가져오기는 같은 설치의 별도 저장소와 새 작업 식별자로 시험했습니다. 휴대전화 간 이동과 Android 파일 선택 화면의 실제 조작은 별도 시험하지 않았습니다. 모든 게임의 정확도나 24시간 연속 운용을 보장하는 결과는 아닙니다.

이 기능은 화면 글자를 이용하는 작은 오프라인 학습 모델입니다. 자유로운 문장을 이해하는 언어모델 기능은 완성된 기능으로 제공하지 않습니다.


## 이번 납품의 확인 범위

시범 학습·자동 실행·모델 저장과 불러오기·추가 학습은 전용 검사 환경에서 확인했습니다. 사용자 요청에 따라 추가 지연 주입 검사는 보류했습니다. 화면 응답 시간 초과의 추가 원인 후보는 실제 재현과 수정이 끝나지 않았습니다. 이 APK가 해당 오류를 완전히 해결하거나 장시간 무중단을 보장하는 버전이라는 뜻은 아닙니다.
