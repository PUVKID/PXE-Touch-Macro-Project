## LEVEL 1 - Beginner

### LEVEL 1 · 처음 읽는 분을 위한 동작과 결과

최종 납품은 공용 APK와 사용 안내 두 파일입니다. ARM64 휴대전화와 x86_64 기반64비트 에뮬레이터에서 같은 파일을 쓰며 Android API30 이상, ARM32 제외입니다. 파일은 78,457,218바이트라 64MiB Git 상한을 넘어 저장소에 올리지 않았습니다. 로컬 파일과 크기·SHA, 재현 소스를 안내합니다. 기본 매크로와 꺼진 선택형 AI를 구분하고 23차의 제한된 실제 시범·학습·자동 행동 확인을 모든 작업의 보장으로 보지 않습니다.

### LEVEL 1 · 이 자료의 세부 조건을 함께 읽기

로컬 최종 폴더의 납품 파일은 `PXE_23차_v2.3_공용.apk`와 `사용안내.md` 두 개입니다. ARM64 휴대전화와 x86_64 기반64비트 Android 에뮬레이터에서 같은 앱 기능을 사용합니다. Android API30 이상이며 ARM32는 포함하지 않습니다.

APK: **78,457,218바이트**, SHA-256 `d95dfd884da3d44dd35f5df31e7a92c1710059b754b8c5c4c736c86b3d0111ad`. 64MiB 공개 상한을 넘으므로 Git에 APK를 올리지 않고 로컬 납품과 크기·해시를 제공합니다. 별도 Release 업로드는 하지 않았습니다.

[사용 안내](사용안내.md) · [공용 재현 소스와 빌드 안내](../23차/source/빌드방법.txt) · [23차 기능·한계](../docs/versions/23차.md#reading-level-1) · [직전23차와의 실제 비교](../docs/revision-audit/최종.md)

기존 매크로가 주 기능이고 AI는 기본 꺼짐입니다. 시범 OCR 기반584→32→K F64 MLP의 실제 학습·자동 동작·이식 상태 보존을 제한된 전용 환경에서 확인했습니다. 자연어 Transformer는11/64, 17.18%(소수 둘째 자리까지 버림; 원값17.1875%)로 실패했고 assets0입니다. 다른 설치·SAF 파일 선택창·모든 게임·24시간 운용과 화면 응답 시간 초과의 추가 원인 해결은 검증 완료로 표시하지 않습니다.
