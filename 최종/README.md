### LEVEL 1 · 현재 공개 안내가 가리키는 납품본

이 원격 안내의 최종본은 **23차 공용 APK와 사용 안내 두 파일**입니다. 로컬 최종 폴더의 `PXE_23차_v2.3_공용.apk`는 Android에 설치하는 앱 파일이고 `사용안내.md`는 설명 문서입니다. 한 APK로 ARM64 휴대전화와 x86_64 기반 64비트 Android 에뮬레이터에서 같은 앱 기능을 사용합니다. CPU 종류를 나타내는 ARM64/x86_64와 지원 운영체제 조건을 함께 확인하십시오. Android API30 이상이 필요하고 ARM32는 포함하지 않습니다.

먼저 [사용 안내](사용안내.md)를 읽고, 직접 빌드할 때는 [23차 소스와 빌드 안내](../23차/source/빌드방법.txt)를 확인합니다. [23차의 기능·한계](../docs/versions/23차.md#reading-level-1)와 [직전23차 비교](../docs/revision-audit/최종.md)도 연결했습니다. 새 24차 개발·시험 기록이 있다는 이유로 이 23차 납품 안내를 새 제품의 완료 결과로 바꾸지 않습니다.

### LEVEL 1 · 파일 크기와 다운로드 범위

APK 크기는 **78,457,218바이트**이고 SHA-256은 `d95dfd884da3d44dd35f5df31e7a92c1710059b754b8c5c4c736c86b3d0111ad`입니다. 해시는 파일이 같은지 대조하는 식별값이며 앱 성능 점수가 아닙니다. 파일당 64MiB 공개 상한을 넘어서 APK를 Git 저장소에 올리지 않았습니다. 로컬 납품과 크기·해시를 제공하며 별도의 Release 업로드도 하지 않았습니다.

### LEVEL 1 · AI가 하는 일과 아직 확인하지 않은 일

주 기능은 기존 매크로이고 **AI는 기본 꺼짐**입니다. 선택형 모델은 사용자가 보여 준 시범의 OCR 글자 특징을 사용하는 584→32→K F64 MLP입니다. 숫자는 입력·중간·출력 층의 크기를 나타내며 F64는 계산값의 저장 정밀도입니다. 제한된 전용 환경에서 실제 학습, 자동 동작, 내보내고 불러올 때의 상태 보존을 확인했습니다. 이 결과가 모든 화면을 이해하는 모델의 완성을 뜻하지는 않습니다.

자연어 Transformer 실험은 64개 중 11개, 원값 17.1875%로 실패했습니다. 원문에 있는 17.18%는 소수 둘째 자리까지 버린 당시 표시입니다. 새 요약은 소수 첫째 자리 반올림인 **17.2%**로 읽되 원값과 실패 판정은 그대로입니다. 언어모델 자산은 assets0, 즉 앱에 포함된 자산 0개입니다.

다른 설치 간 이식, Android 파일 선택창인 SAF의 실제 조작, 모든 게임, 24시간 운용, 화면 응답 시간 초과의 추가 원인 해결은 검증 완료로 표시하지 않습니다. 제한된 시험과 미확인 사용 환경을 구분하십시오.

### LEVEL 2 · 최종 폴더와 차수 자료의 관계

현재 원격 최종 안내는 23차 납품을 가리킵니다. 로컬 최종 폴더는 `PXE_23차_v2.3_공용.apk`와 `사용안내.md` 두 파일이며, 기능과 검증 근거는 [23차 설명](../docs/versions/23차.md#reading-level-2), 재현 입력은 [소스·빌드 안내](../23차/source/빌드방법.txt), 사용 흐름은 [사용 안내](사용안내.md), 차이는 [직전23차 비교](../docs/revision-audit/최종.md)로 연결합니다. 후속 개발 자료와 현재 납품본은 별개입니다.

공용 APK는 ARM64와 x86_64 기반64비트 Android 환경에서 같은 기능을 제공하는 한 파일입니다. Android API30 이상을 요구하고 ARM32는 제외합니다. 지원 CPU 종류와 운영체제 최소 조건은 각각 충족해야 하며 해당 목록이 모든 기기의 실측 성공을 뜻하지는 않습니다.

### LEVEL 2 · 식별 정보와 공개 정책

파일 크기 78,457,218바이트와 SHA-256 `d95dfd884da3d44dd35f5df31e7a92c1710059b754b8c5c4c736c86b3d0111ad`는 납품 파일 동일성을 연결합니다. **64MiB 상한 초과로 Git에 APK를 포함하지 않았고 별도 Release도 업로드하지 않았습니다.** 로컬 납품과 재현 소스·크기·해시 제공을 원격 바이너리 배포와 구분합니다.

### LEVEL 2 · 두 모델의 목적과 결과를 분리하기

기존 매크로가 중심이고 선택형 AI는 기본 꺼짐입니다. 시범 OCR 글자 특징을 입력받는 584→32→K F64 MLP의 학습·자동 행동·이식 상태 보존은 제한된 전용 환경에서 확인했습니다. 글자 관측에서 행동을 선택하는 정책과 자연어를 해석하는 Transformer는 다른 평가 대상입니다.

자연어 실험은11/64, 원값17.1875%로 실패했고 언어모델 assets0입니다. 원문17.18%는 당시 소수 둘째 자리 버림이며 최신 기본 요약은 **17.2%(소수 첫째 자리 반올림)**입니다. 표시법 변경이 원값이나 실패를 바꾸지는 않습니다. 다른 설치·SAF 파일 선택창·모든 게임·24시간 운용·화면 응답 시간 초과의 추가 원인 해결은 확인 범위 밖입니다. 한 계층의 통과를 이 미확인 범위의 성공으로 연결하지 않습니다.
