# PXE 15차 사용 안내

기존 PXE를 삭제하지 않고 PC용 APK를 덮어 설치합니다. 휴대전화에는 노트10플러스용 APK를 사용합니다. 실행 중이면 먼저 중단한 뒤 설치하고, 업데이트 후 접근성 연결 상태를 확인합니다.

1. 탐지 화면의 글자·매크로 설정에서 찾을 글자와 목록 인식 방식을 고릅니다.
2. 화면 정보는 대상 앱이 접근성으로 제공하는 글자를 읽습니다. 이미지나 게임 화면 글자는 한글 OCR 또는 자동을 사용합니다.
3. 동작 화면에서 저장 매크로의 글자 동작을 편집하면 검색 방식이 기본 화면에 보입니다. 목록 설정과 개별 동작 설정은 각각 적용됩니다.
4. 글자가 나올 때까지 대기하려면 해당 글자 동작의 계속 기다리기를 켭니다. 인식 후 추가 대기 없이 다음 동작을 켜면 사용자가 저장한 완료 후 대기를 생략하며, 글자 터치는 터치 전 재확인도 생략합니다. 실제 화면 읽기와 캡처 보호 간격까지 0초가 되지는 않습니다.
5. 목록의 글자·매크로 설정 → 세부 설정 → 인식 즉시 들어가기는 기본 꺼짐입니다. 켜면 목록 글자의 터치 전 재확인을 생략합니다. 화면이 빠르게 바뀌거나 잘못 누르면 끄고 사용합니다.
6. 시작 전·들어간 뒤·반복 사이·뒤로가기 전후·새로고침 후 대기는 동작 사이 대기에서 설정합니다. 기존 값은 업데이트로 자동 축소하지 않습니다.
7. 순위 영역은 글자 전체가 보이도록 정하고 다른 버튼과 겹치지 않게 합니다. 같은 글자 순번과 1~6순위 동작은 유지합니다.

화면 정보에 텍스트가 없으면 그 방식으로 읽을 수 없습니다. 대상 앱이 OS에 화면 캡처를 제한한 경우 OCR도 읽을 수 없으며, PXE는 제한을 우회하거나 읽지 못한 위치를 임의로 누르지 않습니다. 오류 기록에는 실제 실행 단계와 요청/실제 인식 방식을 구분합니다.

이번 차수는 사용자 블루스택을 조작하지 않고 별도 소유 Android 시험 장치에서 검증합니다. 블루스택 5개 동시 실행의 실제 속도나 장시간 무중단 동작을 보장하는 결과는 아닙니다.
