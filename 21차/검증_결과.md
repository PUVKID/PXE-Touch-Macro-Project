# 21차 · 검증 결과

전용 Android 12(API 31) 시험기기의 PC용 APK에서 새 기능 28개와 기존 회귀 120개를 실행해 모두 통과했습니다. 추가 정지·재시작 집중 검사 8개도 통과했습니다. 이 156회는 중복 실행을 포함한 검사 실행 수이며 서로 다른 기능 156개라는 뜻이 아닙니다. 새 집중 검사 28개는 공유 상한 300초 안에 152.031초가 걸렸습니다. 이는 검사 묶음의 시간이며 실제 매크로 15회 처리 시간과 다릅니다.

단위 검사 115개는 실패·오류·건너뜀 0개였고 린트 지적 0건, 엄격 UTF-8 검사를 통과했습니다. 같은 검사 소스의 전후 해시가 일치했습니다. 실제 키보드를 연 저장·취소, 320dp 작은 화면, 잘못 진입한 화면 복귀, 복귀 중 일시정지, OCR 복구 후 확인 시간, 새 글자로 다시 시작과 이전 결과 폐기를 확인했습니다.

기존 진행창 정지 회귀에서 발견한 정지 후 표시 복원 실패를 수정했습니다. 원래의 실제 정지·다음 동작 취소·진행창 복원 단언을 유지한 채 최종 APK에서 재검사했습니다. 과거 실패를 지우거나 통과로 바꾸지 않았습니다.

PC용과 노트10+용 APK 모두 앱 ID·PXE 이름·21/2.1.0 버전·기존 인증서·지원 ABI·ZIP CRC를 대조했습니다. 전용 시험기기에 설치된 PC용 APK와 납품본 SHA-256이 같고, 기존19차에서21차로 업데이트하는 검사 2개를 통과했습니다. 노트10+ 실기기에서 실행한 검증은 아니며 폰용 APK는 패키지·서명 검사 범위입니다. 기존19차 소스·APK 160개 항목을 원문·해시로 보존했습니다.

사용자의 블루스택·게임·실제 휴대전화는 조작하지 않았습니다. 24시간 시험과 추가 성능 비교는 실행하지 않았으며 정확도99%·실제 처리 시간·장시간 무오류를 보증하지 않습니다.

이전 19차 제품과 20차 시험 기록을 보존했습니다. 사용자 요청으로 중단한 24시간 시험은 재개하지 않았습니다. 개인 실행 원문과 서명 자료는 공개하지 않습니다.
