# PXE 21차 · 설치와 사용

기존 화면 배치를 유지하고 블랙·화이트와 파란 포인트색으로 정돈했습니다. 기존 앱 위에 같은 서명으로 업데이트할 수 있습니다. 앱을 삭제하면 저장한 매크로·설정이 지워질 수 있으므로 기존 앱을 삭제하지 않고 설치합니다.

1. 블루스택·LD플레이어에는 `PXE_21차_v2.1_PC용.apk`, 노트10+에는 `PXE_21차_v2.1_노트10플러스.apk`를 설치합니다.
2. 기존처럼 목록에서 찾을 글자·1~6순위 영역·매크로·반복 횟수를 정합니다.
3. 홈의 **진입 화면 확인**을 열어 **진입 화면을 확인한 뒤 실행**을 켭니다. 들어간 화면에 있어야 할 글자와 확인 시간을 초 단위로 설정합니다. 필요하면 목록과 별개인 확인 영역을 지정합니다.
4. 선택 항목인 되돌아갈 글자를 넣을 수 있습니다. 예를 들어 확인 글자는 `배`, 되돌아갈 글자는 `사과`로 정합니다. 둘 다 보이면 되돌아갈 글자를 우선합니다.
5. 저장하고 시작합니다. 확인 글자가 보이면 등록한 매크로를 실행합니다. 정상적으로 읽은 화면에 확인 글자가 정한 시간 동안 없거나 되돌아갈 글자가 보이면 뒤로 가서 목록 1순위부터 다시 확인합니다. 잘못 들어간 항목은 완료 횟수와 완료 후 쉬는 시간에 포함하지 않습니다.

**일시정지 / 계속 실행**은 현재 위치에서 멈추고 이어갑니다. 글자를 바꾼 뒤 **시작**을 누르면 새 설정으로 1순위부터 시작하므로 먼저 정지를 누를 필요가 없습니다. 잘못된 새 설정은 실행 전에 안내합니다.

진입 확인은 기본 꺼짐이라 기존 프로필의 동작을 유지합니다. OCR·화면 조회 오류는 글자 부재와 구분하며, 대상 앱·권한·보안 경계를 유지합니다. 새로고침 주기, 완료 후 쉬는 시간, 중복 방지와 기존 녹화·동작 편집을 그대로 사용할 수 있습니다.

PC와 기기 성능에 따라 인식·실행 시간은 달라집니다. 이번 검증은 전용 시험 환경의 기능 확인이며 실제 게임의 24시간 운용이나 특정 처리 시간·정확도를 보증하지 않습니다.
