# PXE 28차 · 2.8.4

28차 2.8.4는 재생·정지 크기와 동작 칸의 불균일을 수정하고 파란색을 제거했습니다. 따뜻한 회백색·차콜과 저채도 회녹색으로 색상을 맞췄습니다. 재생·일시정지·정지는 같은 24dp 그림 영역과 48dp 버튼을 사용하며, 동작 목록은 제목·설명을 각각 두 줄로 맞추고 긴 내용은 편집창에서 확인합니다.

| 디자인 요소 | 2.8.4 기준 | 적용 범위 |
|---|---|---|
| 색상 | 라이트 #F3F3EF / #FBFCF8 카드, 다크 #181C19 / #232924 카드 | 파랑 제거·입력·팝업·위젯 |
| 포인트 | 라이트 #505C52 / 다크 #BCCDBB | 낮은 채도·선택/포커스/주요 동작 |
| 글자 | 제목24sp·주요 입력20sp·일반 선택 14sp·동작제목15sp/설명13sp | 시스템 선택창 글자도14sp |
| 동작 칸 | 전체 너비·최소112dp·제목/설명 각 2줄·더보기 64dp | 긴 내용은 줄임표, 편집창 전체 내용 유지 |
| 제어 아이콘 | play/pause/stop 24dp 중심 배치·같은48dp 버튼 | 폰트 기호 대신 벡터·공통 색상 |
| 로고 | 차콜 바탕·밝은 회백색의 둥근 P | 런처·상단·접힘·알림 동일 형상 |
| 하단 창 | 1/15·화살표·이동·글자 변경·단축키 유지 | 하단 pause/stop 없음 |

현재 제품은 입력한 글자와 인식 결과의 원문 완전 일치만 사용합니다. `Adobe`와 `어도비`, `ADOBE`, `Adobe Pro`, 앞뒤 공백이 붙은 문구는 서로 다릅니다. 저장된 포함·정규식·공백/대소문자 무시 옵션도 실행 시 적용하지 않습니다. OCR은 낱말 일부 대신 한 줄 전체를 비교하고, 화면 정보는 접근성 설명(contentDescription) 대신 text만 비교합니다. text를 제공하지 않는 화면은 OCR을 사용하세요. OCR이 잘못 읽은 글자 자체를 완벽히 구별한다고 보장하는 기능은 아닙니다.

찾을 글자와 영역을 정해 반복 터치를 실행하는 Android 앱입니다. 이번 수정은 **26차의 단순한 배치를 기준으로 내부 화면을 정돈하고, 하단에서 글자를 바로 바꾸는 기능**을 추가했습니다. 28차 번호를 유지하며 이전 설치 파일과 소스는 별도로 보존했습니다.
