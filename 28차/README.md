# PXE 28차 · Astryx 네이티브 화면

16차의 매크로·탐지 기본 설정을 유지하고, 모든 탭의 일시정지·계속 실행·정지와 글자 변경 후 재시작을 정리했습니다. 긴 한글이 들어갈 공간을 확보하고 3D 장식을 제거했습니다. 한글 OCR은 유지하며 학습형 행동 AI는 포함하지 않습니다.

**28차는 변경 영향 기기 검사 11개 방법을 통과한 수정본입니다.** 제품 빌드·단위 102개·린트 오류0/경고0과 전용 Android12 설치는 확인했습니다. APK는 `PXE_28차_v2.8_공용.apk`, 32,718,940바이트입니다. 실제 UI·메인 제어·위젯·OCR 기기 검사 11개 방법은 통과했습니다. 기존 기능 전체를 새로 전수 실행한 결과는 아니며 독립 내용·명세 검토와 소스 ZIP 원문 대조를 마쳤습니다. 원격 반영은 게시 커밋과 별도 확인 기록으로 확인합니다.

Rust는 Windows에서 색상 리소스를 만드는 실제 빌드 경로에 연결했습니다. Android에서 매크로나 OCR을 Rust로 실행하도록 바꾼 것은 아닙니다. 색상값은 기존 팔레트와 같으며 새로운 속도 향상 수치는 측정하지 않았습니다. 화면의 3D 장식 제거는 AI 모델 제거와 별개입니다. 논문·가짜 실험 화면은 추가하지 않았습니다.

## 이번 사용 방식

| 화면·조작 | 28차 동작 | 확인 상태 |
|---|---|---|
| 앱의 네 탭 | 실행 중 일시정지·계속 실행·정지 표시 | 실제 전 탭 제어·1.3배 글꼴 검사 통과 |
| 글자·탐지 설정 변경 | 새 설정 검증 뒤 새 실행으로 교체 | 잘못된 입력이면 기존 실행 보존 |
| 작은 하단 위젯 | 기본 104×44dp, 1/15 같은 현재 반복 표시와 펼침 화살표 | 숫자 부분을 끌어 이동, 상세 너비 280dp |
| 화면 위 컨트롤 설정 | 하단 위젯 불투명도 40~100%, 기본 95% | 기존 컨트롤 불투명도와 별도 저장 |
| 읽기 편한 배치 | 긴 문구 줄바꿈·유동 높이·좁은 화면의 세로 버튼 | 두 테마 1.3배 글꼴 검사 통과, 모든 화면·입력 전체 보장은 아님 |

16차·26차·현재 28차의 `WatchConfig`, `Step`, `Macro`, `CapturePacer` 네 파일은 직접 SHA-256 대조에서 동일했습니다. 이는 설정·동작 정의와 캡처 간격 기준을 유지했다는 근거이며 전체 실행 속도가 동일하다는 실측은 아닙니다. **28차는 이번 변경 범위의 검사를 마친 수정본이며 이전 26차 최종 폴더는 보존합니다.**
