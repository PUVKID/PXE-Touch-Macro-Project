# PXE 28차 소스 · 2.8.2

기존 터치 매크로·내장 한글 OCR을 유지하고 자동 스크롤, 26차 기반 내부 배치, 등록 글자 가로 단축키와 하단 글자 변경을 정리했습니다. 하단 일시정지/정지는 제거하고 상단/메인 제어는 유지합니다. 새 기능 연결·실제 결과는 차수의 사용 안내·검증 결과를 따릅니다.

| 경로 | 역할 |
|---|---|
| app | Android 네이티브 화면·접근성·MLKit OCR·실행과 검사 |
| theme-engine | Windows에서 실제 색상 XML을 만드는 Rust 엔진 |
| tools | 팔레트 생성·원본 대조·빌드 사본 동기화 |
| docs | 이번 구현 계획과 보존한 이전 기반 명세 |

[빌드 방법](빌드방법.txt) · [현재 계획](docs/28차_Astryx_계획.md) · [현재 검증](../검증_결과.md)

Rust 색상 생성 뒤 Gradle release/단위/린트를 실행합니다. 키·캐시·운영 기록은 소스 묶음과 공개 대상에서 제외합니다. 사용자 블루스택이나 기본 ADB 서버를 검사 도구가 임의 조작하지 않습니다.


이번 2.8.2는 입력한 글자와 인식 결과의 원문 완전 일치만 사용합니다. `Adobe`와 `어도비`, `ADOBE`, `Adobe Pro`, 앞뒤 공백이 붙은 문구는 서로 다릅니다. 저장된 포함·정규식·공백/대소문자 무시 옵션도 실행 시 적용하지 않습니다. OCR은 낱말 일부 대신 한 줄 전체를 비교하고, 화면 정보는 접근성 설명(contentDescription) 대신 text만 비교합니다. text를 제공하지 않는 화면은 OCR을 사용하세요. OCR이 잘못 읽은 글자 자체를 완벽히 구별한다고 보장하는 기능은 아닙니다.
