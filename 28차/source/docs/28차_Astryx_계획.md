|---|---|---|

노란 선 해 아이콘은 Orbit 참고 분위기의 상태 장식입니다. 새 학습 엔진·3D·React 컴포넌트를 추가하지 않습니다. MacroService는 새 재시작·반복 수 공급을 위해 변경됐으며 서비스 전체가 불변이라는 초기 문구는 현재 적용하지 않습니다.

초기 단위106개·린트 경고12는 이전 입력의 근거입니다. 미사용12색을 정리했고 장식 참조 전용검사 실패 원문과 제거한 장식 소스/검사를 별도 보존했습니다. 남은 102개 단위·최종 린트 오류0/경고0·Android12 설치 및 새 기기 검사 11개 방법이 통과했고 독립 종합 검토·패키지·공개 상태는 별도 차수 검증 문서에서 확인합니다. fixture 상태 확인을 제품 모든 화면의 상태 검증으로 확대하지 않습니다. 기존 최종26·준비본27·27차 중단 이력을 보존하며 새 장기 검사 성공이나 속도 개선을 주장하지 않습니다.

현재 상태는 [검증 결과](../../검증_결과.md), 사용자 조작은 [사용 안내](../../사용안내.md), 재현 환경은 [빌드 방법](../빌드방법.txt)을 따릅니다. 공개 소스에서는 Rust를 먼저 빌드한 뒤 실행 파일을 복사해야 합니다.
