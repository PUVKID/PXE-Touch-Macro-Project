# PXE 28차 사용 안내 · 2.8.3

28차 2.8.3은 기존 기능을 유지하면서 내부 화면과 화면 위 창의 색상·간격·로고를 통일한 수정본입니다. 밝은 화면은 연회색 바탕과 흰 카드, 어두운 화면은 짙은 회색 바탕과 카드로 구분하고 파란색은 주요 동작·선택 상태에 사용합니다.

| 디자인 요소 | 현재 기준 | 적용 범위 |
|---|---|---|
| 색상 | 라이트 #F6F7F9 / 흰 카드, 다크 #101216 / #1A1D24 카드 | 앱·입력·팝업·화면 위 창 |
| 포인트 | 라이트 #245CE2 / 다크 #90B4FF | 실행·선택·포커스·체크박스 |
| 글자 | 나눔고딕700, 제목24sp·주요 입력22~23sp·본문14sp | 큰 제목 축소·설명 대비·줄 간격 |
| 선·모서리 | 1dp 구분선, 입력/버튼12dp·카드14~16dp | 행·폼·팝업·탐지 영역 선택 |
| 로고 | 파란 사각형과 흰 P | 런처·헤더·접힌 단축창·알림(단색) |
| 작은 진행 창 | 1/15와 화살표, 드래그·글자 변경·단축키 유지 | 하단 일시정지/정지 없음 |

현재 제품은 입력한 글자와 인식 결과의 원문 완전 일치만 사용합니다. `Adobe`와 `어도비`, `ADOBE`, `Adobe Pro`, 앞뒤 공백이 붙은 문구는 서로 다릅니다. 저장된 포함·정규식·공백/대소문자 무시 옵션도 실행 시 적용하지 않습니다. OCR은 낱말 일부 대신 한 줄 전체를 비교하고, 화면 정보는 접근성 설명(contentDescription) 대신 text만 비교합니다. text를 제공하지 않는 화면은 OCR을 사용하세요. OCR이 잘못 읽은 글자 자체를 완벽히 구별한다고 보장하는 기능은 아닙니다.

## 하단에서 글자 바꾸기

| 목적 | 조작 | 실행 중 동작 |
|---|---|---|
| 직접 입력 | `1/15` 옆 화살표 → 글자 변경 → 입력 → 적용 | 탐지/단독 글자 모드는 새 글자로 처음부터 실행 |
| 취소 | 글자 변경 창에서 취소 | 원래 실행 중이었고 같은 실행이 유지된 경우 이어감 |
| 잘못된 입력 | 빈 글자 입력 | 창에서 오류를 표시하고 기존 설정·실행 보존 |
| 이동 | 반복 숫자를 끌기 | 위치 저장, 화면 경계 안으로 제한 |
| 접기 | 화살표를 다시 누르기 | 반복 수만 작은 크기로 표시 |
| 불투명도 | 설정 → 화면 위 컨트롤 → 하단 위젯 불투명도 | 40~100%, 기본 95% |

**하단 진행 창에는 일시정지·정지가 없습니다.** 앱 안 또는 상단 컨트롤의 Ⅱ/▶·■를 사용합니다. 위젯 바깥 터치는 통과시키고 자동 터치 위치와 위젯이 겹치면 실행 제스처 동안 숨깁니다.

## 자주 쓰는 글자

1. 글자 또는 탐지 탭의 `등록 · 관리` → `새 글자 등록`에서 입력하고 등록합니다.
2. 등록한 글자가 가로 단축키로 표시됩니다. 좌우로 밀어 다른 글자를 확인합니다.
3. 단축키를 누르면 글자 모드와 첫 탐지 글자를 함께 바꿉니다. 실행 중 탐지/단독 글자 모드는 새 글자로 처음부터 재시작합니다. 정지 중에는 설정만 저장합니다.
4. 하단 화살표를 펼쳐도 같은 단축키를 사용할 수 있습니다. 직접 글자 편집 때 `자주 쓰는 글자로 등록`도 선택할 수 있습니다.
5. 삭제는 `등록 · 관리` → `삭제 · 글자`를 사용합니다. 같은 글자를 중복 등록하지 않으며 최대 30개입니다. 일반 매크로 동작 목록의 글자를 일괄 치환하지 않습니다.

## 이동과 인식

자동 목록 하강과 글자 미인식 뒤 스크롤은 0.9초 동안 화면 높이의 22.5%를 이동합니다. 아래로 당겨 새로고침은 기존 거리 45%를 유지하면서 0.9초로 이동합니다. 직접 녹화한 스와이프의 시간·거리는 변경하지 않습니다. 인식 방식과 탐지 영역은 원래 설정을 유지하며, 글자 비교는 기존 옵션과 관계없이 원문 완전 일치만 사용합니다.

화면 읽기 미응답은 글자 없음으로 바꾸지 않습니다. 새 글자로 바꿀 때 이전 조회가 남아 있으면 끝날 때까지 취소 가능한 대기 후 새 요청을 보냅니다. 실제 플랫폼 응답이 장시간 오지 않으면 미응답 안내가 발생할 수 있으며 영구 무중단을 보장하지 않습니다.

현재 검사 결과와 APK/ZIP 지문은 [검증 결과](검증_결과.md)와 [파일정보](파일정보.json)를 따릅니다. 장기 무중단·모든 기기 무오류·게임의 15회 완료 시간은 측정하지 않았습니다.
