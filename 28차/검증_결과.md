현재 최종 APK에서 고유6개 기기방법을 실행했습니다. 처음 두방법 후 ADB exit255가 발생했고 후속에서 검사도구 정보와 제품 코드 경로 부재를 확인했습니다. 원문을 보존하고 같은 전용 장치에 현재APK/검사APK를 다시 설치하여 남은4방법을 실행했습니다. 설치 정보 소실 원인은 확정하지 않았으며 연속 무중단 검사로 세지 않았습니다. 전용 Android12/API31 x86_64 AVD·ADB5047을 사용했고 사용자 블루스택·게임·기본ADB5037은 조작하지 않았습니다. [현재 실제 화면28장](화면_확인/2.8.4/README.md)을 저장했고 부모가 기본/큰글꼴 동작 목록·제어·글자·설정 화면을 직접 열어 검토했습니다. 이전 차수의 화면을 현재 증거로 세지 않았습니다.

실행/OCR 엔진10파일은 직전2.8.3과 바이트 동일이며 완전일치·느린스크롤·등록글자·재시작·매크로 기능을 유지합니다. Graphify 로컬 Java AST의 controlIcon→build/updatePlay 연결을 실제 소스와 대조했습니다. XML/바이너리와 일부Gradle은 분석기 지원 밖이며 그래프를 성능 근거로 사용하지 않습니다.

이 검사는 모든 기기·모든 보조 팝업·최대글꼴·모든 반투명배경의 전수검사나 장기무중단 보장이 아닙니다. 사용자 실기기·블루스택·게임15회시간·장기운용은 이번에 검사하지 않았습니다. 색상은 채도를 낮추고 대비를 확인했습니다.
