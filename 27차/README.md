# PXE 27차 · 캡처 대기와 상태 표시 정리

기존 매크로와 오프라인 한글 OCR을 유지하고, 겹칠 수 있는 캡처 대기와 같은 상태 문구의 불필요한 갱신을 줄였습니다. 흑백과 차분한 파란 포인트로 라이트·다크 화면의 간격·선택·연결 표시를 정리했습니다.

APK와 전체 패키지 ZIP은 로컬 27차 폴더에 준비본으로 제공합니다. 60분 종료 판정은 미완료이며 최종 폴더의 26차는 유지합니다. 설치 전에 중요한 매크로를 내보내 보관하고 기존 앱 위에 업데이트하세요.

별도 행동 AI는 포함하지 않으며 내장 한글 OCR은 인터넷 없이 작동합니다. 대상 앱이 불명확할 때는 터치하지 않고 확인을 기다리는 정책을 유지합니다. 실제 확인 기간을 넘는 무중단과 모든 환경의 정확도를 보장하지 않습니다.
