# 27차 · 속도와 연속 운용

| 항목 | 구현 | 확인 조건 |
|---|---|---|
| 기반 기능 | 26차의 16기반 매크로·오프라인 한글 OCR·6영역·반복·중복 방지·정지/일시정지 유지 | 기존 근거와 변경 영향 대조 |
| 캡처 대기 | 덮개 제거 150ms와 실제 응답 기준 캡처 간격 대기를 중첩 | API30 1100ms/API31+500ms 유지, 오류 후 후퇴·늦은 콜백 보존 |
| 화면 갱신 | 동일 문자열 setText 및 동일 visibility 호출 생략 | 내용 변경·일시정지·정지 표시 확인 |
| 디자인 | 기존 배치 기반 흑백/슬레이트 블루, 색상 리소스 통일, 선택/연결 상태 표시 | 라이트/다크·설정·글자 화면 실제 확인 |
| 운용 | 별도 Android12에서 60분 연속 OCR목록진입·15회·뒤로·새로고침 | 같은 PID/서비스/boot·실제횟수·메모리 기록 |

오류 숨김, 대상 앱 확인 우회, OCR 이미지 축소, 모델 제거, 새 AI/의존성 추가는 하지 않습니다. 캡처2/OCR1의 동시 작업 제한과 오래된 결과 폐기 경로를 보존합니다. 크기 감소를 속도 개선으로 간주하지 않고 같은 조건의 측정값으로만 비교합니다. 실제 결과는 차수 검증 문서에서 분리해 기록합니다. 60분 결과를 모든 기기나 수년 동작 보장으로 확대하지 않습니다.
