# PXE 14차 디자인 대조 — 부모 관찰

참조 방식: Build Web Apps의 시안→토큰→구현→실제 화면 대조, ImageGen 시안, Product Design의 근거별 수정. EXE의 Orbit 금속 링을 복제하지 않고 흰색·먹색·청록색 PXE를 구현했습니다.

| 확인 항목 | 실제 관찰과 적용 |
|---|---|
| 탐지 홈의 우선순위 | 찾을 글자가 가장 크고 탐지 영역은 민트 행, 나머지는 얇은 구분선으로 정리됨 |
| 라이트·다크 | 순백/먹색 배경, 청록 강조, 기존 나눔고딕 Bold700 유지 |
| 설정·동작·글자 | 공통 열린 행·입력·버튼, 실제 편집과 실행 설정 팝업에도 같은 색 체계 |
| 하단 표시 | 실제 서비스 단계·한 바퀴·전체 시간 값, 고정 예시 통계 없음 |
| 화면 위 제어 | 작은 아이콘/제어 버튼과 정지 ■ 유지, 번호점과 영역 선택도 청록으로 정리 |
| 키보드·긴 문구 | 키보드 표시 상태의 탐색과 긴 문구 스크롤 검사를 실제 기기로 실행 |
| 터치 영역 | 제어창·안내·번호점·영역 버튼과 체크박스·슬라이더의 기본48dp를 실제 bounds로 보완 |
| 모션 | 네이티브180ms 진입, 시스템 애니메이션 꺼짐 존중, 상태 갱신 callback 해제 검사 |

시안과의 의도된 차이: 실제1080×2280 화면에는 홈의 미리보기·다시 설정과 설정 하단이 스크롤 아래에 있습니다. 화면 위 제어창은 폭을 줄이려고 PXE 글자 대신 같은 앱 아이콘을 사용합니다. 다크 주 버튼 글자는 대비를 위해 먹색이며, 표면은 더 평평하게 정리했습니다. 기존 단축창 진입은 유지합니다. 저장 설정과 동작 개수는 실제 값이므로 시안 예시와 다릅니다.

이 문서는 부모의 화면 관찰 기록입니다. 독립 판정과 최종 검사 범위는 별도 검증결과 및 영수증을 따릅니다. 시안 이미지를 실제 앱 화면으로 붙여 구현하지 않았습니다.
