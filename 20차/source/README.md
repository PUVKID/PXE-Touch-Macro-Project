## 단계와 현재 범위

준비 단계는 소스·서명·고정 APK·전용 장치를 확인합니다. 사전 시험은 최소 300초와 정확한 15회 사이클 3개를 충족한 뒤 완료 경계에서 종료하며 전체 상한은 480초입니다. 본 시험은 실제 86,400초 이상을 유지하고 완료 경계에서 종료합니다. 그 전의 실행·OCR 성공·사전 PASS는 본 시험 PASS가 아닙니다.

최초 사전 시험은 instrumentation 시작이 기존 접근성 프로세스를 끊은 뒤 연결 준비에 실패했습니다. 두 번째 사전 시험은 실제 OCR과 여러 사이클을 실행하고 계측 성공 표식을 남겼으나, 호스트가 정상 계측 종료 뒤에도 앱 PID를 요구하여 실패했습니다. 당시 최종 장치 원문은 보존되지 않아 이 실행을 성공으로 재판정하지 않습니다. 두 실패와 별개로 종료 경계·원문 보존·장기 프로세스 수명을 수리하고 새 사전 시험을 준비합니다. 최종 판정은 실제 장치 상태와 계측 종료 결과를 함께 확인합니다.

세 번째 사전 시험은 2026-11-02 실제 장치 392.176초·호스트 396.36초, 완료 사이클 4개·반복 60회·OCR 486회로 완료됐습니다. 최종 장치 원문과 정상 계측 종료를 수집했으며 PID·부팅·매크로 세대의 연속성을 확인했습니다. 최초 오류 일지는 기존 기록을 포함하지만 이후 관측 변화와 추가 줄은 0개였습니다. 이 소스 안내는 사전 시험 완료 시점에 동결했습니다. 이후 본시험 기동은 [시험 시작 안내](../시험_시작안내.md)에 따로 기록합니다.

## ▶️ 실행

이 컴퓨터에 설치한 Python·PowerShell7·JDK17·Gradle·Android SDK의 실제 절대경로를 사용합니다. 공개 문서에는 개인 사용자 경로와 서명 원문을 넣지 않습니다. 아래 `Python실행파일`은 해당 로컬 절대경로를 뜻합니다.

```powershell
& 'Python실행파일' -B -X utf8 tools/prepare_build20.py
& 'PowerShell7실행파일' -NoProfile -File tools/build_test.ps1
& 'Python실행파일' -B -X utf8 tools/setup_device.py
& 'Python실행파일' -B -X utf8 tools/test_soak_runner.py
& 'Python실행파일' -B -X utf8 tools/check_contract.py
& 'Python실행파일' -B -X utf8 tools/verify_text.py
& 'Python실행파일' -B -X utf8 tools/start_background.py preflight --run-id 고유한영문실행ID
```

소유 AVD가 꺼져 있을 때만 `tools/start_background.py emulator --run-id 고유한기동ID`로 기동합니다. 기존 serial이 실행 중이면 중복 기동하지 않습니다. 사전 시험과 독립 계약 검토가 통과한 뒤에만 `preflight` 대신 `main`으로 본 시험을 시작합니다. 사용한 실행 ID와 폴더는 재사용하지 않습니다. 장기 자식의 Windows 작업 그룹 분리를 실제 확인하지 못하면 기동을 성공으로 보고하지 않습니다.

장기 프로세스는 로컬 WMI로 숨김 실행하며 생성된 자식의 동일 사용자 SID와 작업 그룹 외부 여부를 직접 확인합니다. 실행 래퍼는 대상 스크립트 폴더를 모듈 검색 경로에 넣고 UTF-8 표준 출력·오류 파일 객체를 명시합니다. 생성 직후 자식이 종료해도 생성 API의 PID와 반환값을 보존합니다. 같은 폴더 모듈 import와 한국어 출력 회귀를 포함한 22개 검사는 통과했고, 새 소유 AVD supervisor의 작업 그룹 분리도 실제 확인했습니다. 이는 24시간 지속 성공의 증거는 아닙니다.

## 관측과 중단

고정 `work/20차_24시간검증/status.json`은 최신 상태 요약입니다. 고유 run 폴더에 시작·예정 종료·PID/boot/세대·host 실제 경과·30초 heartbeat·실제 OCR/완료 횟수·자원 추세·원문 로그를 따로 남깁니다. 독립 조회 전에 장치 원문을 저장하고 조회 이력은 제한된 회전 기록으로 보존합니다. 실행 중에는 살아 있는 동일 PID를 요구합니다. 정상 종료 뒤에는 최종 장치 상태·기존 PID/boot 연속성·실제 정지 관측·정상 계측 종료를 함께 검증합니다. 운영 파일과 개인 로컬 경로는 공개 소스에 포함하지 않습니다. host는 자기 프로세스에서만 일시적인 SYSTEM_REQUIRED를 요청하고 finally에서 해제하며 전역 전원 설정을 변경하지 않습니다.

중단하려면 소유 PXE19 제어창의 정지 버튼을 누르거나, 확인한 SDK의 adb 실행파일로 다음 명령을 사용합니다. 시험은 연속 성공으로 처리하지 않으며 원문과 중단 상태를 보존합니다. 다른 serial이나 기본 ADB5037을 사용하지 않습니다.

각 관측에서 오류 일지 원문·해시·관측 시각을 제한된 회전 기록에 보존하고 첫 원문과 최신 원문을 별도 저장합니다. 최초 기준은 실행 시작 후의 첫 관측이므로 그 이전에 생긴 오류를 새 오류로 분류하지 않습니다. 이후 변화·추가 줄 수는 관측 간 차이이며 관측 사이에 회전해 사라진 모든 기록을 복원하는 값은 아닙니다. 기존 복구 경고나 새 일지 변화는 경고로 표시하고 연속 실행 판정과 구분합니다. 일지 수집 실패는 근거 단절로 실패하며, 연속 PASS를 오류 0 보장으로 확대하지 않습니다.

```powershell
& 'SDK의adb실행파일' -P 5043 -s emulator-5598 shell am force-stop kr.yunseok.touchmacro
```

사용자 실제 게임·플레이어·휴대폰은 이번 시험 대상이 아닙니다. [상세 시험 계약](docs/2026-11-02_24시간_실제OCR_시험계획.md)의 완료·정체·수면·시간 기준을 유지합니다.
