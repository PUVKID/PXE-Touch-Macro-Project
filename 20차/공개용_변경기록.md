# 20차 · 24시간 시험 도구와 초기 기동

19차 납품 APK를 대상으로 장시간 시험을 준비하고 실제 기동을 기록한 별도 차수입니다. 새 APK를 제작한 차수가 아닙니다. 계측 시험 fixture 범위의 기동 기록이며 블루스택 실게임 24시간 검증이나 24시간 시험 통과가 아닙니다. 최종 결과는 실제 확인 후 별도로 추가할 계획입니다.

[시험 시작 안내](시험_시작안내.md) · [기동 요약](검증_기동요약.json) · [시험 도구](source/) · [직전 차수 전체 비교](https://github.com/PUVKID/PXE-Touch-Macro-Project/blob/main/docs/revision-audit/20%EC%B0%A8.md)

이전 19차는 그대로 보존합니다. 19차 제품 보관 폴더와 20차 시험 도구 폴더의 목적 차이로 나타나는 파일 부재는 제품 기능 삭제를 뜻하지 않습니다. 실제 공개 파일별 차이와 크기·해시는 전체 비교를 참조합니다.

시험 소스는 사전 시험 완료 시 동결했습니다. 소스 README의 기동 전 상태 기록과 이후 시작 안내의 실제 본시험 기동을 구분합니다.

개인 실행 원로그, 서명 원문, 인증정보와 APK 바이너리는 공개하지 않습니다.
