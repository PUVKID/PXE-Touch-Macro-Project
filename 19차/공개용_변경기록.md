# PXE 19차 · 1.9.0

대상 앱 창 조회가 취소될 때 실제 실행 정지와 구별해 복구하고, 응답 대기를 하단에서 확인할 수 있게 보강했습니다. 기존18차와 이전 산출물을 보존합니다.

## 대상 창 확인과 복구

16차에는 창 조회의1.5초 지연이 종료로 이어지는 경로가 있었습니다. 17·18차는 이미 해당 시간초과와 진행 중 조회를 단일 조회·무터치 복구로 처리합니다. 이번에는 실행 세대와 서비스 연결이 유효한 창 조회 취소를 별도로 재현하고 보강했습니다. 사용자 과거 설치 버전과 오류 원문이 없어 이 후보를 실제 과거 원인으로 확정하지 않습니다.

복구 중에는 오래된 좌표를 누르거나 뒤로가기·스크롤·중복 차단 해제를 임의로 실행하지 않습니다. 늦은 응답은 새 확인과 구분하고 실제 대상 앱을 다시 확인합니다. 사용자의 정지·서비스 연결 해제·전체 최대 실행 시간과 실제 권한 오류는 계속 적용합니다. 모든 예외를 무한 재시도하거나 중단 문구만 삭제한 변경이 아닙니다.

## 현재 상태와 반복 보존

하단 진행창에서 실제 창 복구 대기와 정지 가능 상태를 구분합니다.15회 중7회가 끝나고8회째에서 응답을 기다린 경우 앞선7회를 다시 실행하거나 완료 수를 초기화하지 않습니다. 복구 후 원래 흐름을 계속합니다. 기존 작은 접이식 창·시간·상세 실행 기록·글자 인식·우선순위·반복·녹화·중복 방지를 유지합니다.

오류 기록에는 빌드 버전을 구분할 수 있는 비식별 진단을 추가합니다. 기존 운영 기록은 보존하며 화면·새 개인 본문을 수집하지 않습니다.

## 관측한 창 전환과 입력 허가

전체 회귀 검사에서 실제 활성 창이 바뀌었는데 창 변경 이벤트 세대는 아직 그대로인 경계 실패를 확인했습니다. 이전 차수와 같은 보호 코드였으며, 새 취소 복구 수정의 회귀라고 단정하지 않습니다. 별도 진단에서는 새 창 메타를 확인한 시점과 서비스 이벤트 처리 사이 약57밀리초의 공백을 관측했습니다. 진단의 통과로 최초 실패를 삭제하지 않습니다.

실제로 수락한 활성·초점 창 식별이 바뀌면 이전 전달 허가도 폐기하도록 보강합니다. 취소되거나 기한이 지난 결과는 관측 갱신에 사용하지 않습니다. 메인 스레드에 동기 창 조회를 추가하지 않습니다. 아직 관측하지 못한 모든 운영체제 전환까지 원자적으로 차단한다는 보장은 아닙니다.

기존 전달 경계 검사는 `activePackage()`로 새 창 활성을 확정하며, 이 조회도 수정 후에는 수락된 관측으로 세대를 갱신합니다. 따라서 해당 통과는 새 관측으로 이전 허가를 폐기하는 동작을 확인한 결과입니다. 마지막 조회 뒤 전환하고 추가 조회와 이벤트가 모두 도착하지 않은 모든 틈까지 검증한 결과로 확대하지 않습니다.

## 연결 없는 실제 빌드

바로가기·정션·심볼릭 링크를 새로 만들거나 삭제된 연결을 복원하지 않습니다. 기준 소스와 실제 프로젝트 내부의 ASCII 빌드 사본을 파일·해시로 대조합니다. 기존 실제 SDK·JDK·Gradle과 개인 서명을 사용하며 키는 복사·공개하지 않습니다.

## 실제 검사와 한계

별도 검증자가 최종 소스와 납품 APK로 기존114개와 새 집중6개, 총120개 기기 검사를 직접 통과했습니다. 단위109개·20클래스·실패/오류/생략0, 린트0건을 확인했습니다.

장기 지연·개별 조회 취소 복구·실제 하단 복구 상태·15회 중간 진행 보존·타앱 무터치·권한 오류와 전체 실행 기한을 구분했습니다. 실제18→19 업데이트, 같은 개인 서명과 앱 ID, 두 APK의 ABI·압축 및 이전18차153항목 보존을 확인했습니다.

사용자 과거 오류 원문과 실제 설치 버전이 없어 과거 원인을 확정하지 않았습니다. 사용자 블루스택·게임·실제 노트10+·24시간 무중단과 이번 차수15회 처리속도는 검증하지 않았습니다.


## 기존 공개 서명 설정 정리

기존 공개 보관 자료의 서명 설정에서 인증값 후보를 발견해 새 공개 사본에는 주석 안내만 남겼습니다. 관련 기본·1차 비교 자료도 정리한 양쪽 공개 사본으로 다시 생성해 삭제 줄에 인증값을 재복사하지 않습니다. 값이나 로컬 키는 공개하지 않았고 실제 APK·로컬 서명은 변경하지 않았습니다.

과거 Git 커밋 이력은 그대로 남습니다. 해당 값의 현재 유효성은 확인하지 않았으며, 유효한 비밀번호였다면 별도로 교체해야 합니다. 새 공개 트리 정리가 과거 노출을 회수했다는 뜻은 아닙니다.

## 공개 범위

앱·검사·빌드 소스와 글꼴/OFL, 사용법과 변경 설명을 보관합니다. 개인 프로필·대화·서명 키·인증값·실행 원문·로컬 운영 기록·캐시는 공개하지 않습니다. APK는 로컬에 제공하고 파일명·크기·SHA-256을 기록합니다. 이번 앱 수정에는 학술 원고가 없습니다.
