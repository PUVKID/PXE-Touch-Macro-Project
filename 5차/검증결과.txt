Android 12 가상 기기 검사: 2개 통과 (73.389초)
1. WatchPresetTest
   - 지정 영역에서 선택한 글자를 실제 터치해 상세 화면으로 들어감.
   - 선택한 이름의 매크로를 정확히 15회 실행.
   - 원본 전체 반복도 15회인 상황에서 225회로 곱해지지 않음.
   - 자동 뒤로가기 후 10초가 지나기 전 재진입하지 않음.
   - 새로고침 후 다시 들어가 정확히 15회 더 실행 (총 30회).
   - 저장한 원본 매크로의 전체 반복 및 시작 번호가 바뀌지 않음.
2. WatchFlowTest
   - 영역 밖의 글자 제외, 영역 안 한글 OCR, 매크로 실행 및 자동 뒤로가기.
   - 새로고침 반복, 선택적인 즉시 재탐지.
   - 일시정지/정지 후 지연 실행 취소.
   - 실패 시 뒤로가기 없이 탐지 중단.

화면 확인
- 탐지 첫 화면과 쉬운 설정 화면에 기본 15회 / 10초 / 글자 눌러 들어가기 표시 확인.
- 실제 편집 화면에서 0.5초 입력, 저장, 다시 열기 확인.
- 저장된 동작 시간은 내부 500으로 올바르게 변환되며 기존 완료 후 대기 500도 유지됨.
- 초 단위 입력 화면과 설정 화면을 PNG로 저장.
