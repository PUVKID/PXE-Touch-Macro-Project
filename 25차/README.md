# 25차 · 차수별 안내 정리

문서 정리 차수입니다. **앱은 24차 · 2.4.0을 유지**하며 APK를 다시 빌드하지 않았습니다.

| 정리 대상 | 적용 내용 |
| --- | --- |
| 첫 화면 | 현재 앱·사용법·기능·결과를 먼저 표시 |
| 각 차수 | 해당 차수 설명만 유지하고 이전 차수는 비교에서 연결 |
| 최종 안내 | 24차 파일과 현재 사용법으로 통일 |
| 읽기 수준 | LEVEL 1~5를 유지하고 과거 결과의 반복 본문 분리 |
