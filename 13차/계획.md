# PXE 13차 OCR 멈춤 수정 계획

목표: 기존 기능을 보존하면서 일시적인 인식 지연이 실행 종료로 전파되는 경로를 고치고 복구 상태를 알립니다.
구조: MacroService의 캡처·인식 수명과 실행 토큰을 분리하여 오래된 결과를 버립니다. 요청 적체와 다른 앱 터치를 막는 기존 경계는 유지합니다.
기술: Android 접근성 서비스, ML Kit 한국어 인식, Java 17, Gradle.
명세: ../요구사항.txt

## 공통 제약
이전 12차와 사용자 블루스택 설정은 보존합니다. 새 산출물은 13차에만 저장합니다. 앱 ID와 개인 서명은 유지합니다. 추가 기능과 무관한 디자인 수정은 하지 않습니다.

- 중단·일시정지·다른 앱 전환 중 잘못된 터치 금지

- 이전 설정과 반복·우선순위·새로고침·로그 유지
