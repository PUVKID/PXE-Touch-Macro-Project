PXE 1.2.0 · 12차 소스 빌드

source 폴더의 빌드.ps1은 JDK 17 / Gradle 8.13 / Android SDK 35로 휴대전화/PC APK와 단위/lint 검사를 실행합니다.
같은 Desktop 프로젝트 안의 work\build12 연결 경로와 코드\NEXTools, 코드\NEXSigning, work\tools를 사용합니다.
서명 키는 소스에 포함하지 않습니다. 기존 설치 위에 업데이트하려면 같은 서명 키가 필요합니다.
PC용은 같은 빌드 환경에서 Gradle :app:assembleRelease -PNEX_PC=true --project-cache-dir work/.gradle 로 빌드합니다.
PC용 ABI는 arm64-v8a와 x86_64이며, 휴대전화 기본 릴리스는 arm64-v8a입니다.
두 빌드 모두 결과 위치는 work\build\app\outputs\apk\release\app-release.apk입니다.
휴대전화 빌드 결과를 먼저 별도 저장하고 PC용을 빌드해야 합니다.

검사: :app:testDebugUnitTest :app:lintDebug
소스 회귀 검사: Python -B -X utf8 tools/check_regression.py (정상 Gradle 의존성 준비 후 호출별 빈 출력 폴더, javac/JUnit)
텍스트 검사: Python tools/check_utf8.py (UTF-8 엄격 디코딩 및 대체 문자)
소유한 NEX12 AVD의 12차 설치 확인 후 기기 검사: Python -B -X utf8 tools/check_device.py
추가 기기 회귀: Python tools/check_device.py WatchFlowTest PriorityFlowTest ReaderResponsivenessTest CaptureRecoveryTest FloatingPlayTest
기기 검사는 127.0.0.1:5557 / 전용 ADB 서버 5042를 사용합니다. 사용자 LDPlayer를 조작하지 않습니다.
기존 JSON의 내부 시간 단위는 호환을 위해 그대로 유지하고, 화면에서는 분/초로 변환합니다.
