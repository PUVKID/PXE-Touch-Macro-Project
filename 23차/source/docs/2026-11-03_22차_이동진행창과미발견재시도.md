# 22차·이동 가능한 터치 통과 진행 창과 글자 미 발견 재시도

확인 일: 2026-11-03. 기준 제품은 21차/2.1.0이며 기존 차수·프로필·기존 매크로 기능을 보존한다. 새 결과는 22차/source와 실제 work/build22/source를 사용한다. 새바로가기·정션·심볼릭링크와키원문 읽기/복사·새키 생성은 금지한다.

## 요구와 확인한 원인

RunHud 전체가 clickable이고 FLAG_NOT_TOUCHABLE이 없어 본문 위의 수동 터치를 가로챈다.

위치는 BOTTOM/CENTER에 고정, alpha .96 고정이다.

FloatingController.updatePlay가 일시 정지/계속 실행 문구를 갱신하고 MainActivity dock도 문구를 쓴다.

Step의 BACK_RETRY/RETRY/SCROLL_RETRY는 최대 3회 기 본 뒤 중단하며, waitForever는 정상 부재를 반환하지 않아 BACK_RETRY와 동시 선택 시 의미가 다르다.

사용자 실 기기 오류를 재현했다고 주장하지 않는다.

## UI와 터치 계약

- 승인된 21차 흑백·파란색·나눔 고딕 Bold·기존 화면 배치를 유지한다. 앱/접힌 제어 창의 pause/resume은 Ⅱ/▶로 표시하고 한 국어 contentDescription과 실제 상태를 유지한다. 녹화 완료/정지 버튼 동작은 그대로다.
- 진행 본문은 TYPE _ACCESSIBILITY _OVERLAY +FLAG_NOT_TOUCHABLE 로뒤의앱에수동탭·스크롤을 통과시킨다. 가짜터치재주입·전체 화면 touchable 영역·숨겨진 API를 쓰지 않는다. 작은 이동 손잡이만 48dp 조작 영역을 갖는다. 손잡이 drag로 본문과 같이 이동, 짧게 누르면 기존 접기/펼치기, 이동으로 접기가 오발하지 않는다.
- 위치와 접기 선택을 저장하며 새 실행/서비스 재생성에도 보존하고 작은 화면·크기 변화·화면 밖 저 장 값에서 손잡이가 사라지지 않게 clamp한다. 기본 위치는 기존 하 단이다. 위치 초기화 조작을 제공한다.
- 설정에서 진행 창 불투명도 0~100%를 바로 바꾼다. 기본은 기존 96%, 상단제어창 기존 opacity와 별도 저장. 0%에도 손잡이는 찾을 수 있게 남긴다. 손잡이만 터치를 받는다고 간단히 설명한다.
- 캡처/녹화/충돌제스처시본문·손잡이 모두 기존가 드대로 숨기고 맞는 generation에서 복원한다. 정지와 새 시작의 수리 9 가드·대상 앱 확인·접근성·실제 취소·전체 기한은 약화하지 않는다. 상단 정지를 손잡이가 가로막지 않게 배치 회피하거나 명확한 최소 대책을 구현한다.

## 개별 글자 동작의 if/else

- 글자 찾아 터치 편집에서'글자가 없으면'을 세부 설정 안에 숨기지 않고 쉽게 설정한다. 기존 STOP/SKIP/BACK_RETRY/RETRY/SCROLL_RETRY 저장 의미와 기본은 보존한다.
- 재시도 정책에'찾을 때까지 계속 재시도'를 선택할 수 있다. 매 시도는 설정 검색 시간 동안 정상 프레임을 읽은 뒤에만 실패 정책을 실행한다. 기존 waitForever와의 충돌을 직관적으로 안내·편집하여 뒤로 가기/새로 고침이 영원히 실행되지 않는 조합을 막는다. 과거 프로필을 임의로 다른 동작으로 이주하지 않는다.
- 새로 고침을 위한 아래로 쓸기 정책과'지정 동작 실행 후 다시 찾기'를 추가한다. 지정 동작은 현재 매크로에 있는 좌표/스와이프/뒤로가기/대기/입력/앱 실행 등 비분기 일반 동작을 이름으로 고를 수 있게한다. 재귀 TEXT 계열/GOTO/STOP을 복구 동작 안에 중첩해 스택/흐름을 망가뜨리지 않고 기존 STOP은 실패 정책으로 남긴다. 선택한 동작의 반복·동작 후 대기 설정도 존중한다. 선택 대상 비활성/삭제/잘못된 참조는 실행 전 검증한다. 번호 변경 시 기존 Goto와 동일한 주의를 간단히 표시한다.
- 복구 동작은 완료 반복 수를 늘리지 않고 원 글자 동작으로 돌아온다. 인식성 공시 정확히 한 번 터치하고 기존 정상 다음 동작/반복 흐름으로 간다. 설정한 전체 실행 시간·명시 정지·일시 정지·새 글자로 시작·대상 앱 보호는 모든 재시도/복구 중에도 유지한다. OCR/창조 회 실패를 정상 글자 부재로 바꾸거나 보안 경계를 해제하지 않는다.
- 진행 창에 무엇을 못 찾았고 무슨 복구 행동을 몇 번째 하는지 간단한 실제 진행 상태를 보인다. 재시도 횟수 0/계속재시도·유한재시도종료·정지·pause·새 시작/늦은 callback을 검사한다.

## AI 범위

AI 화면 판단을 연결하는 것은 가능하다고 답변했으나 모델/로컬 PC·앱 내·외부 서비스/키가 정해지지 않았다. 이번 확정 APK는 OCR +조건 분기이며 실제 AI 모델 통합·미구현 AI 버튼·AI가 있다는 표시는 넣지 않는다. 무제한 자율·어떤 화면이든 무오류·99%·24시간 연속성을 보증하지 않는다.
