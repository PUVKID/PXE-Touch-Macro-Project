# 선택형 시범 기반 글자 행동 학습

기존 매크로가 주 기능이며 AI는 기본 꺼짐입니다. 켠 작업에서 사용자가 직접 보여 주고 확인한 OCR 화면 상태·직전 행동·다음 행동 관계를 작은 자체 신경 정책으로 학습합니다. 자체 언어 모델과 별개이며 OCR 엔진을 재학습하지 않습니다.

TEXT_TAP은 저장 좌표 대신 실행 시점의 OCR 원문 글자 위치를 찾습니다. BACK/WAIT_TEXT/FINISH/SCROLL_UP/SCROLL_DOWN도 지원하며 모호한 같은 글자나 대상 불일치에서는 입력 없이 기다립니다. 전달 완료를 업무 성공 라벨로 자동 확정하지 않으며 사용자 확인·교정만 replay와 학습에 반영합니다.

정책은584입력·32은닉·동적 append-only K출력의 F64 MLP이며 파라미터는18,720+33K개입니다. 실제 SGD 가중치 갱신과 시범 보관을 구분합니다. 가중치·행동 사전·시범·교정·RNG·완료 SGD 상태를 개인 ZIP으로 이식하고 이후 학습을 이어갈 수 있게 구성합니다. 개인 자료는 공개하지 않습니다. 합성 검사 통과는 실제 UI·다른 기기·사용자 작업의 성공을 보증하지 않습니다.

중단·일시정지·서비스 및 대상 앱 경계를 유지하며 자기 예측을 새 정답으로 자동 학습하지 않습니다. 화면 글자와 시범 단서·신경망의 판단이 함께 맞아야 하며 softmax 확률을 신뢰 보증으로 표시하지 않습니다.
