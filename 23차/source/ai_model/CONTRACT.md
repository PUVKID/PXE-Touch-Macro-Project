# 명령 모델의 공개 기술 계약

입력은 명령 원문과 point/gesture/region/macro/app/action의 등록 참조 목록입니다. 원문 codepoint의 반열린 구간을 보존하며 정규화·unescape로 문구를 바꾸지 않습니다. 인용 전체는 원문 side table로 복원하고 숫자 COPY는 기존 엄격 단위 변환을 적용합니다. 인용 안 동사는 새 명령으로 실행하지 않습니다.

입력 길이는535 기존 codec과540 literal-slot codec 각각1024토큰, 출력은고정72종·최대512토큰입니다. 문자 중간 UTF-8 경계·인용 중간·문맥 교차 COPY는 거절합니다. teacher end mask는 정답 start, 추론 end mask는 예측 start에 같은 전체 구간 커널을 적용합니다. 잘린 출력과 잘못된 계획은 부분 실행하지 않습니다.

NN의 명시 REJECT, compiler invalid, 잘못된 ready, 구조 일치, anchor·raw COPY·AST 일치를 구분합니다. Python 의미 AST의 ready만으로 Android 실행을 승인하지 않으며 등록 snapshot·Macro/Watch·개별 동작 검증을 거쳐야 합니다. 참조 없는 여기·저기와 불명확한 참조를 임의 좌표로 바꾸지 않습니다.

기존22종 동작의 대응 범위는 `schema.py`, `tokens.py`, Android의 명령 컴파일러 소스를 기준으로 확인합니다. 스키마 존재·합성 학습 자료 존재·실제 학습 정확도·컴파일 가능 여부는 각각 다릅니다. 원시 GOTO/ACTION_RETRY 및 임의 모든 한국어 표현을 학습 완료로 주장하지 않습니다.

표현·이름·숫자·복합 의미 분할의 원 자료를 유지하고 개발 자료만 모델 선택에 사용합니다. 시험·독립 정답을 학습·역치 조정에 사용하지 않습니다. 개발11/64의 품질 부족과 이전 훈련 실패를 보존하며 현재 추가 명령 모델 훈련은 보류 상태입니다. 이 문서는 기술 설명이고 독립 검증 영수증이나 모델 납품 승인서는 아닙니다.
