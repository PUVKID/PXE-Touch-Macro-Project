현재 선택형 모델은 시범 OCR 글자 특징을 사용하는 **584→32→K 구조의 F64 오프라인 MLP**입니다. 기존 **매크로**가 주 기능이며 AI는 기본 꺼짐입니다.

과거 한국어 자연어 Transformer 실험은 개발 평가11/64, 17.18%(소수 둘째 자리까지 버림; 원값17.1875%)로 실패했고 언어모델 자산은 앱에 포함하지 않았습니다(assets0). 현재 행동 MLP의 통과를 LLM 전체 완성으로 표시하지 않습니다.

전용 Android 시험에서 실제 시범 2회, 학습 192단계, OCR 관측 17회, 다른 UID 시험 앱의 자동 터치 1회와 FINISH 뒤 추가 입력 0을 확인했습니다. 같은 설치의 별도 저장소와 새 작업 식별자로 가져온 뒤 추가 64단계를 학습했고, 원복 30개 항목과 관리 대상 잔류 0을 확인했습니다. 실제 단일 기기 검사와 원복은 통과했고 별도 독립 대조도 통과했습니다.

다른 설치·휴대전화 간 이식, Android 파일 선택창(SAF)의 실제 조작, 모든 게임·사용자 작업·24시간 연속 운용은 검증하지 않았습니다. 중단된 장기 시험은 재개하지 않았습니다. 전체 실행207.468초에는 설치·증거·복원이 포함되므로 매크로 사이클 속도가 아닙니다.

공개 빌드 스크립트는 일반 폴더 확인·연결 경로 거절과 상대 경로·환경 인터페이스를 유지하며 `-PNEX_PC`를 포함한 한 호출로 공용 제품과 검사 APK를 빌드하고 공용 제품만 한 번 복사합니다. 개인 키·시범·OCR 원문·가중치·내부 운영 기록은 포함하지 않습니다. 기존 라이선스와 제삼자 고지를 유지하며 새 라이선스를 부여하지 않습니다.
